# 기존 표 제약 강화)을 막는다. 사람이 '이전 앱이 깨지지 않는다'고 확인한 문장만 여기에 적어 넘긴다.
#
# 형식: <위치>/<파일> <문장 번호> <문장 해시 12자> | 승인: <사람> <날짜> | 사유: <근거>
#   - 위치는 마이그레이션 디렉터리 이름(core · realtime), 문장 번호는 검사기 출력의 '문장 N'
#   - 해시는 주석 · 공백 · 문자열 값을 뺀 문장(대문자)의 sha256 앞 12자. 승인 뒤 문장이 바뀌면 다시 걸린다
#   - 새 줄을 더하는 PR은 리뷰어 승인을 받는다. 이미 적용된 파일은 Flyway 체크섬이 수정을 막는다
