# U12 새 연습 흐름 — 성능 시험 지침

> 해당 없음(이번 시험 전략에서는 만들지 않는 종류). 입력: `code-generation-plan.md`의 Testing Contract(전략 Standard)와 요구사항의 NFR 목록.

## 적용 여부

- Standard 전략은 통합 시험까지만 요구한다. 이 작업 기록의 NFR(NFR1 ~ NFR9)에는 지연 · 처리량 · 가용성 같은 수치 목표가 없다. 성능 시험 대상인 측정 목표 목록은 비어 있다.
- 그래서 부하 시험 · 벤치마크 명령은 만들지 않는다. 임의로 수치를 지어내지 않는다.

## 참고로 이미 있는 증거

- `verify.sh` P2 단계가 `LATENCY_TURN` 로그 줄 3개를 확인했다(존재 확인이며 지연 목표 판정이 아니다).
- 실공급자 · 실제 제브의 응답 지연은 아직 측정한 적이 없다. 제브 연습 모드를 실제 키로 연결한 뒤 `performance-validation` 같은 후속 확인이 필요하면 별도 작업으로 연다. 이 계획의 실행 범위에는 그 단계가 없다.
