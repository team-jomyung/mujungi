## 2. 문구 출처 규칙

- 화면 글은 copy 모듈에서만 가져온다(ESLint `react/jsx-no-literals`, team.md Code Style). 새 문구(RP-3 C.S-17.72.5b)는 문구표 개정 뒤 copy 모듈에 더한다.
- 아이에게 들리는 고정 문구(역할 전환 · 휴식 받아 주기 · 다시 묻기)는 화면 문구표가 아니라 승인 콘텐츠(B §4 · §8.5)에서 버전으로 관리한다(FR10).
- Luna가 만든 글(목표 이름 · 근거 문구 · 칩 글)은 copy 모듈 밖의 데이터다. 금지 표현 검사와 길이 한도를 통과한 것만 표시한다.
