## Assumption Confirmation

아래는 위 답과 정본 문장 · 코드 사실로 바로 정해지는 것들이다. 한 묶음으로 확인한다.

1. 제브(JEV)는 GPT-Live가 새로 만든 발화만 검사한다. 재생 전에 검사해 `ALLOW`일 때만 재생하고, `BLOCK` · `REVIEW` · 시간 초과 · 잘못된 JSON · 정책 버전 불일치면 재생하지 않는다. 늦게 온 `ALLOW`는 무효로 한다. 승인 원문과 글자까지 같은 재생은 제브를 생략한다. Luna 생성물(상황 · 결과 · 리포트)은 제브로 보내지 않고, U6는 기존 `classify` · `OutputChecker`를 유지한다. (C §0 · §2 · §3.4, Q1)
2. 제브 호출 주소 · 모델 버전은 A §5.7 값을 설정 기본값으로 둔다(`POST https://api.typesafe.ai/v1/systemone`, `jev-latest` 금지). 제한 시간은 설정값으로 두고 기본 800ms(A §13)로 한다. 서버 내부 결과 형식은 C §3.1(`ALLOW/BLOCK/REVIEW` · 범주 7개 · `policyFlags` · `reasonCode` · `policyVersion`)로 하고, 공급자의 실제 응답은 어댑터에서 이 형식으로 바꾼다. 실제 응답 필드는 실호출로 확정한다. (A §5.7, C §3.1 · §3.5, Q8)
