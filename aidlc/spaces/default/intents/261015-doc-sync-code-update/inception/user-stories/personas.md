# 페르소나

> 이번 작업의 스토리는 아이와 보호자 두 페르소나로 쓴다(Q1-B). 운영 · 개발 쪽 요구(공급자 연결, 설정, 실호출 · 실기기 검증)는 스토리로 쓰지 않고, 요구사항 FR1 · FR10 · FR11 · FR12와 비기능 요구사항으로 추적한다.

## P1. 아이 — "민준"(대표 예시 이름)

| 항목 | 내용 |
|---|---|
| 역할 | 무중 기기로 무중이와 음성으로 이야기하고 연습하는 6~12세 아이 |
| 목표 | 무중이와 재미있게 이야기하기. 친구 역할놀이에서 하고 싶은 말을 전하기. 쉬고 싶거나 그만하고 싶을 때 바로 그렇게 되기 |
| 불편 | 대답을 '틀렸다'고 느끼게 하는 고정된 도움. 같은 질문을 계속 듣는 것. 무슨 상황인지 모르는데 표현부터 고쳐 주는 것. 상처가 되거나 단정하는 말 |
| 기술 친숙도 | 낮음. 화면을 거의 보지 않고 말로만 쓴다 |
| 이용 빈도 | 주 몇 회, 한 번에 수 분 ~ 10분 남짓 |
| 이번 작업에서 바뀌는 경험 | 연습이 자연스러운 대화처럼 이어진다(되묻기 · 필요할 때만 도움 · 선택적 변형). 무중이가 새로 만든 말은 안전 검사를 거친 뒤에만 들린다. 쉬기 · 그만하기가 바로 반영된다 |

## P2. 보호자 — "지은"(대표 예시 이름)

| 항목 | 내용 |
|---|---|
| 역할 | 아이의 계정 · 동의를 관리하고, 활동 결과 · 리포트를 보고, 다음 연습 목표를 고르는 부모 |
| 목표 | 아이가 실제로 한 말과 장면을 근거로 결과를 이해하기. 아이에게 맞는 연습 목표를 고르기. 아이 자료가 안전하게 다뤄지고 지울 때 확실히 지워지기 |
| 불편 | 점수 · 진단처럼 들리는 결과 문장. 하지 않은 장면을 '실패'로 보여 주는 결과. 근거 없는 추천. 과거 기록이 바뀌어 보이는 것 |
| 기술 친숙도 | 보통. 스마트폰 앱(보호자 앱)을 쓴다 |
| 이용 빈도 | 활동이 끝날 때마다 결과 확인, 가끔 리포트 · 목표 선택 |
| 이번 작업에서 바뀌는 경험 | 결과 칩에 '되묻기 뒤 전달'이 생기고, 장면 수가 고정되지 않는다. 연습 목표 후보를 Luna가 아이 기록에서 근거와 함께 새로 만든다. 아이 삭제 때 지식 그래프 자료도 함께 지워진다 |

## 관계와 우선순위

- 아이(P1)가 1순위다. 대화 안전과 연습 경험은 아이에게 직접 닿고, 실패하면 아이가 바로 겪는다.
- 보호자(P2)는 아이의 활동을 시작 · 관리하고 결과를 해석한다. 보호자가 고른 목표가 아이의 다음 연습 상황을 정한다(US4.6 → US3.1).
- 화면과 문구는 화면 설계 v1.5j를 따른다(아동 기기 D0 · T19, 보호자 화면 17 · 18 · 27 · 28 등).
