## Q1. 페르소나 범위

A. 아이 · 보호자 + 운영 · 개발 담당(검증 · 설정을 맡는 사람) 세 페르소나 (추천)
B. 아이 · 보호자만. 운영 쪽 요구는 비기능 요구사항으로만 다룬다
X. Other (please specify)

[Answer]: B. 아이 · 보호자만. 운영 쪽 요구는 비기능 요구사항으로만 다룬다

## Q3. 인수 기준의 깊이

요구사항 검토에서 "인계서 C §8의 회귀 · 인수 시험 항목이 요구사항에 1:1로 대응되지 않는다"(R-03)와 "일부 기준이 합격/불합격으로 판정되지 않는다"(R-04)는 지적이 있었습니다.

A. C §8.1~§8.3 항목을 인수 기준으로 1:1 옮기고, 모호한 값(확률 하한 · 최근 맥락 턴 수 등)은 설정 기본값을 적어 시험이 쓸 수 있게 한다 (추천)
B. 스토리마다 대표 사례 3~6개만 쓰고, 나머지는 Build and Test 계획에서 다룬다
X. Other (please specify)

[Answer]: A. C §8.1~§8.3 항목을 인수 기준으로 1:1, 모호한 값은 설정 기본값을 적음

## Q4. 운영 안전 기본값 (요구사항 검토 지적 R-02)

제브 검사를 끄는 '비활성 · 대역 모드'가 운영 성격 환경(demo · prod)에서 켜지면, GPT-Live 새 발화가 검사 없이 재생될 수 있습니다. Luna · 제브 실제 연결을 기본으로 켤지도 정해지지 않았습니다.

A. 제브 실검사는 demo · prod 프로필에서 필수다. 꺼져 있거나 키가 없으면 아동 서비스가 시작을 거부한다. 대역 · 비활성 모드는 dev · test · ci 프로필에서만 허용한다. Luna · 제브 실제 어댑터는 키가 설정돼 있을 때만 켜진다 (추천)
B. 운영에서도 끌 수 있지만, 꺼져 있으면 GPT-Live 새 발화를 모두 막고 승인 문구 · 고정 대본만 재생한다
C. 실제 어댑터는 기본 꺼짐이고, 운영자가 설정으로 명시적으로 켠다. 켜지 않으면 A의 '시작 거부'를 따른다
X. Other (please specify)

[Answer]: A. demo · prod에서 제브 실검사 필수(꺼짐 · 키 없음이면 아동 서비스 시작 거부), 대역 · 비활성은 dev · test · ci만, 실제 어댑터는 키가 있을 때만 켜짐

## Q5. (모브 검토 — 판단 필요) 보호자 화면 27의 장면 결과 칩

디자이너 지적: 화면 설계 v1.5j의 27(활동 기록 상세)은 연습일 때 "판정 글 없음"으로 정한다(원래 기록 261008의 G15도 같은 결정). 그런데 지금 코드와 계약은 27에 장면 칩 5종을 그린다(`RecordDetail27.tsx` → `SceneChip`, `contracts/ai-io.md` 6.2). US4.1의 '되묻기 뒤 전달' 칩을 어디에 둘지 정해야 한다.

A. 이번 작업에서는 27 표시를 바꾸지 않는다. 칩 값('되묻기 뒤' 포함)은 API · 리포트 집계에만 더하고, 27의 칩 표시가 화면 설계와 어긋나는 문제는 편차로 기록해 화면 설계 개정 여부를 따로 정한다 (추천)
B. 화면 설계를 먼저 고쳐 27에 칩(새 칩 포함)을 정식으로 넣고, 그다음 코드를 맞춘다
C. 화면 설계대로 27에서 칩을 뺀다(판정 글 없음)
X. Other (please specify)

[Answer]: A. 27 표시는 바꾸지 않고 칩 값은 API · 리포트 집계에만 더한다. 27 칩 표시와 화면 설계의 어긋남은 편차로 기록

## Q6. (모브 검토 — 판단 필요) 제브가 막은 말을 대신할 아이 쪽 안내

디자이너 지적: 제브가 GPT-Live 새 발화를 막았을 때 아이에게 대신 들려줄 승인 문구가 화면 설계 문구표에도, AI 동작 명세 §4의 승인 문구에도 없다. 그래서 AC2.1.8의 "승인된 안내"는 가리킬 원문이 없다.

A. 새 말을 만들지 않는다. GPT-Live에 같은 다음 행동을 1회 다시 지시하고, 그것도 막히면 그 장면을 정리하고 다음 단계로 간다. 기기는 그동안 '생각 중'을 유지한다. 대체 문구 추가는 화면 설계 · 문구 개정의 열린 항목으로 남긴다 (추천)
B. 대체 승인 문구(예: "잠깐만, 다시 생각해 볼게")를 새로 정해 문구표 · 승인 콘텐츠에 넣고 그 문구를 재생한다
C. 막히면 아무 말 없이 다시 듣기 상태로 돌아간다
X. Other (please specify)

[Answer]: A. 새 말 없이 같은 다음 행동을 1회 다시 지시, 또 막히면 장면 정리. 기기는 '생각 중' 유지. 대체 문구는 문구 개정 열린 항목
