# 사전 표현 연습과 상황극 분리

2026-10-28 · 사용자 요청: 연습 지침을 서비스 코드에 이식하고 PR로 제출한다. 이 기록은 변경 범위와 검증을 설명하며, 별도 AI-DLC 단계 승인이나 배포 승인을 대신하지 않는다.

## 문제와 동작

기존 유연 대화는 아이의 일부 전달·상황 이해 어려움이 반복되면 상황극 중 코칭을 제안했다. 상대역과 코치가 번갈아 말해 아이의 질문에 답하기 전에 표현 예시가 끼어들 수 있었다.

이번 변경은 목표마다 다음 순서를 사용한다.

1. 참여 안내 뒤, 안내하는 무중으로 목표 행동 설명·다른 맥락의 예시 하나·작은 표현 요청 하나를 제시한다. 아이의 응답을 기다리며 최대 두 번 시도한다.
2. 상상 상황과 상대역을 알리고 기본 상황극을 진행한다. 필요한 경우 뜻을 되묻거나 자기 말을 다시 설명하되, 부족한 답만으로 코칭을 시작하지 않는다.
3. 아이가 동의하면 변형 장면 하나를 진행한다. 기본·변형을 합쳐 목표별 최대 두 장면이다.
4. 역할극이 끝났음을 알리고 안내하는 무중으로 확인된 수행 범위만 정리한다.

명시적인 설명·도움 요청은 무시하지 않는다. 상황극을 멈췄음을 알리고 기존 도움 절차를 사용한 뒤 상대역 복귀를 알린다. 중단·쉬기·안전 경로와 생성 출력의 Jev 검사는 유지한다. 현재 Jev 정책의 탐지 범위를 확대하거나 검증했다고 주장하지 않는다.

## 코드 경계

- 기본 지침: `practice-system.v2.txt`. 목표 후보 생성 프롬프트에 연습 진행 규칙을 넣지 않는다.
- 진행: `PracticeConversation`이 사전 연습과 역할극을 분리한다. `PracticeInstructions`는 해당 차례의 요청만 만들며 500자 상한을 유지한다.
- 짧은 답: 단어 목록으로 수행을 배제하지 않고 목표·문맥으로 판단한다. 진행 방법 질문은 성공 판정으로 오인되어도 도움 요청으로 처리한다.
- 기록: 예시를 들은 사실·사전 표현 시도와 상황극 안 되묻기·코치 도움을 구분한다. 사전 연습 뒤의 수행은 교육 전 독립 능력이나 장기 향상의 증거가 아니다.
- 범위: `scenario-script.v1` 유연 대화 경로가 대상이다. 기존 레거시/명시적 비유연 전이표는 유지한다.

## 검증 원칙

실제 아동·실제 모델 품질 평가는 이 PR의 자동 테스트와 구분한다. 모의 공급자로 단계 순서, 발화 대기, 두 번 시도 상한, 도움 오인 방지, 짧은 동의, 역할 내 재설명, 정상 미관찰 종료, 중단·늦은 응답, 기존 출력 차단, 기록·결과 해석을 검사한다. 실제 OpenAI·Jev API 호출은 하지 않는다.

DB를 포함한 실행 결과와 환경 제약은 PR의 검증란에 명시한다. 미실행 검사를 통과로 표기하지 않는다.

검증 결과:

- 연습 흐름·모의 공급자·결과 해석·계약·ArchUnit 대상 검사 통과. 사전 표현 연습 23건과 유연 역할극 회귀를 포함한다.
- 사전 연습 이력의 다음 연습 전달 검사 통과.
- 마이그레이션 정적 검사, 유료 API 테스트 격리 검사, 서비스 배포 파일의 테스트 클래스 미포함 검사 통과.
- 로컬에는 Docker 엔진과 테스트용 PostgreSQL이 없어 관련 실행에서 DB 검사 19건이 건너뛰어졌다. 전체 `check`는 DB 초기화 불가와 뒤따른 teardown 오류로 실패했다. DB 검사는 저장소 CI의 Docker PostgreSQL 환경에서 확인해야 한다.
- 실제 음성 출력, 실제 OpenAI·Jev 응답, 아동 대상 효과는 미검증이다.

## 검토에서 반영한 교훈

- 안내 수용과 목표인 동의는 같은 짧은 말로 나타날 수 있다. 단어 기반 배제 대신 판정 문맥과 반대 사례를 함께 검사한다.
- 목표 미관찰은 중도 종료와 다르다. 정상 종료한 연습을 끝까지 하지 못했다고 안내하지 않는다.
- 예시를 듣고 따라 한 전사가 결과 분석에 섞이지 않도록 상태·시간 경계를 입력과 기록에 함께 전달한다.
- 변형 놀이의 수락·거절은 목표 수행 발화가 아니다. 장면 종료 후 선택을 기록할 때 최초 종료시각을 늘리지 않는다.
- 새로운 준비 사실은 기존 DB enum 배열을 바꾸지 않는 별도 표에 보관해 구 앱의 읽기 호환성을 유지한다.
