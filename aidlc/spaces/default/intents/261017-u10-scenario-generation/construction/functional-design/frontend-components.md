# U10 프런트엔드 범위

## Applicability

U10은 Core 상황 생성 단위다. 화면·프런트 컴포넌트 변경은 없다. 이 파일은 Unit DAG 없는 단계 출력 목록의 적용 여부를 명시한다.

## Compatibility

기존 보호자 오류 분기·문구·기기 재생 코드를 변경하지 않는다. 새 대본은 내부 계약의 선택 필드이며 기존 필수 응답을 유지한다. U12 소비 상태 기계와 실제 기기는 범위 밖이다. 상위 근거는 `../../inception/requirements-analysis/requirements.md` FR3·Constraints·Out of scope다.
