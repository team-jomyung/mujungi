# U10 성능·마감 검증 지침

## Targets and source

요구사항 NFR1·FR5.2, Testing Contract 및 contracts/timing.md의 최초 전체 15초, 그래프 작업 합계 2초, 기술 재시도1·내용 수정1·최대6호출을 유지한다. 실제 공급자의 지연·나이 적합성·의미 판단 품질은 NFR5에 따라 자동 대역 근거와 분리한다.

## Execution

integration-test-instructions.md의 u10 한정 실행과 전체 verify.sh가 기존 제어 시계/가짜 공급자의 마감·늦은 응답·취소 무시·실제 DB 저장 지연 및 커밋 전 경계를 실행한다. 같은 명령을 성능 지침 때문에 중복 실행하지 않는다. 별도 준비 READY의 마감 보호 누락 R-06은 사용자가 위험으로 수용했으며, 이를 시험 통과로 바꾸지 않는다.

## Live observation boundary

실제 API 호출은 하지 않는다. RUNBOOK 단계4/R-F15 준비 확인이 없고 실제 키·아동 자료를 읽지 않는다. 실호출 합성의 15초 지연과 실제 모델 판단 품질은 미검증으로 보고한다. 이 작업의 뒤에 performance-validation 단계가 없으므로 나중 단계가 성공시킬 것이라고 표시하지 않는다. 자동 대역 성공은 실제 공급자 성능 성공이 아니다.

## Evidence

각 자동 대조의 실제 XML, 그래프 예산과 호출 수 입력/출력 검증 및 DB 롤백 대조를 기록한다. 전체 15초 보장을 입증하지 못하는 준비 완료 경계는 목표 표에서 잔여 위험과 구분해 명시한다. 실제 관측이 예산을 넘으면 시간 값을 늘리는 대신 사전 생성·캐시의 버전·권한·삭제 영향을 별도 검토한다.
