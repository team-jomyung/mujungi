## P1 — 자유대화에 참여하는 아이

- **역할/우선순위**: AI 인형과 대화하는 아이. 주 역할이며 선택권과 정확한 이해를 우선한다. 실존 인물·가상 임상 진단·새 연령 제한을 만들지 않는다.
- **목표**: AI와 기록/보호자 열람 사실을 이해한 뒤 참여를 선택하기, 말하고 싶은 이야기를 하기, 정정·휴식·종료 의사를 존중받기.
- **불편**: 안내를 받기 전에 시작되는 대화, 매번 붙는 새 질문, 이해하지 못한 척하는 확인, 쉬거나 그만두겠다는 말에 이어지는 만류.
- **맥락/기술 숙련도**: 기존 바인딩된 기기의 음성 경로를 사용하며 설정·모델·판정 용어를 이해할 필요가 없다. 숙련도나 이용 빈도는 검증된 수치가 없어 가정하지 않는다.
- **권한 경계**: 아이의 음성 요청만으로 보호자 권한·저장·삭제 정책이나 기기 동작이 바뀌지 않는다. 보호자 동의와 아이 참여는 별개다.

## P2 — 같은 계정의 보호자

- **역할/우선순위**: 기존 계정으로 아이 정보를 관리하고 활동 기록을 확인하는 보호자. 보조 역할이며 새로운 공동 보호자/전문가 계정은 추가하지 않는다.
- **목표**: 서비스가 기록·열람·공유·삭제에 관해 실제 기능만 설명하기, 아이가 거절한 활동을 정상 활동으로 꾸미지 않기, 기존 연습과 기록 흐름이 유지되기.
- **불편**: 미완료 작업을 완료로 약속하는 발화, 다른 아이/숨긴 정보 노출, 정책 교체로 기존 연습이나 검수가 약해지는 것.
- **맥락/기술 숙련도**: 기존 보호자 웹·권한을 사용한다. 새 조작 화면·결과 평가·음성 재생 기능을 가정하지 않는다. 숙련도/이용 빈도는 미확인이다.
- **권한 경계**: 기존 계정의 권한만 유지하며, 아이의 참여 선택을 대신하지 못한다. 외부에 공유된 PDF 사본의 삭제까지 보장받는 역할이 아니다.

## 관계와 범위

P2의 서비스 동의와 바인딩을 전제로 P1에게 매 세션 안내/참여 선택을 제공한다. P1의 거절·종료는 보호자 관심 정보 수집보다 우선한다. 사용자 스토리의 역할은 고객 가치 표현이며, 새 API 역할이나 권한을 도입하지 않는다. 운영·개발 품질 조건은 별도 추적한다.
