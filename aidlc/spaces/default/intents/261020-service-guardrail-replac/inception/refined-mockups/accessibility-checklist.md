## 기준과 증거 한계

변경되는 화면·상태·문구를 WCAG 2.1 AA 기준으로 점검하는 설계 목록이다. 아래 체크박스는 구현 후 확인할 항목이며 현재 합격/측정/실제 기기·보조기기 시험을 뜻하지 않는다. 기존 서비스 전체의 준수나 장애별 사용성을 인증하지 않는다. 시간값 변경은 승인 범위 밖이므로 기존 접근성 한계가 발견되면 별도로 기록한다.

## 지각 가능성

- [ ] 아이 안내의 승인 텍스트/음성 버전이 일치하며 보호자 화면에 표시한 글이 실제 청취 완료를 대신하지 않는다.
- [ ] 음성/기록 안내를 기술 용어·모델/정책 ID 없이 쉬운 한국어로 전달한다.
- [ ] 정상 글 4.5:1, 큰 글/필요한 비문자 조작 3:1 대비를 실제 배경 조합에서 확인한다. 색 외 글/상태 설명을 함께 사용한다.
- [ ] 긴 한국어·이름·확인된 인용·200% 확대에서 줄바꿈하며 버튼·상태·기기 끄기가 가려지지 않는다.
- [ ] 장식 캐릭터는 기존 aria-hidden을 유지하고 상태 의미를 텍스트로 제공한다. 고정 원문을 아이가 실제 말한 것처럼 대체하지 않는다.

## 조작 가능성

- [ ] 기존 시작/끝내기/확인/취소/홈/기록/탭·기기 켜기/끄기를 키보드로 조작할 수 있다. visible focus를 지우지 않는다.
- [ ] 보호자 P-01의 취소 기본 초점, 팝업 열림/닫힘 초점 이동·복귀와 중복 요청 방지를 유지한다.
- [ ] 보호자 확인 팝업을 아이의 명확한 음성 종료/즉시 음소거에 적용하지 않는다.
- [ ] 보호자 조작 44px, 기기 조작 72px 이상 및 겹침 없는 위치를 유지한다.
- [ ] 끼어들기·끄기·종료 후 지난 음성/후속 질문을 다시 재생하지 않는다. reduced-motion 설정을 유지한다.
- [ ] 기존 대기·재연결·기기 확인의 만료를 표현할 때 완료를 거짓 선언하거나 아이를 재촉하지 않는다. 음성/종료 조작의 실제 반응과 대역 시험을 구분한다.

## 이해 가능성

- [ ] 명확한 거절/무응답/안내 기술 실패가 다른 원인으로 설명된다. 기술 실패를 아이가 대답하지 않은 탓으로 돌리지 않는다.
- [ ] RP-1 안내는 저장·열람·수동 공유·선택권을 실제 사실에 맞춰 말한다. 비밀/삭제/연락 완료를 확인 없이 약속하지 않는다.
- [ ] loading/empty/error/partial/성공과 마무리/기기 미확인이 구분된다. 확인되지 않은 시각·표현·인사 재생을 채우지 않는다.
- [ ] 자유대화 정책을 연습의 훈련/판정 화면에 일괄 적용하지 않는다. 새 지시가 화면의 기존 역할을 바꾸지 않는다.

## 의미와 보조기기

- [ ] 실제 button/제목/목록 의미를 유지하며 ARIA로 중복 설명을 만들지 않는다.
- [ ] 상태 변화는 적절한 role=status/polite로 한 번 알리고 매 폴링마다 같은 상태나 전체 전사를 반복 낭독하지 않는다.
- [ ] 변경된 P-03 제목이 팝업의 접근 가능한 이름에 연결되고 확인 뒤 초점/이동이 기존 규칙을 따른다.
- [ ] RP-3/4의 줄이 생략되어도 종료 원인·현재 마무리·기기 확인 상태의 의미가 남는다.
- [ ] 기존 한국어 페이지 언어·문자 이스케이프·장문 표시를 유지하고 원문을 HTML로 실행하지 않는다.

## 검증 인계

| 방법 | 대상/후속 단계 |
|---|---|
| 컴포넌트/상태 대역 시험 | Code Generation/Build and Test: RP 사유 선택·줄 노출·팝업 초점·중복/지난 결과 |
| 브라우저 키보드·확대·폭 경계 점검 | Build and Test: 기존 독립 검증 환경에서 실행, 수동 스택 변경 없음 |
| 스크린 리더/대비/실제 기기 음성 | 실제 수행한 도구·환경·결과를 별도로 기록. 정적 코드나 대역 합격으로 대체하지 않음 |
| R-01 종료 판단 요청 검증 | 후속 Functional Design/Build and Test. 접근성 시안만으로 해소됐다고 하지 않음 |

## Assumptions & Open Questions

화면의 기존 기능을 재설계하지 않으며 변경 표면에서 발견한 실제 문제를 근거로 조정한다. 새 접근성 기능/시간 조절이 제품 결정을 요구하면 사람에게 범위 변경을 확인한다. 체크박스는 시험 전까지 비워 둔다.
