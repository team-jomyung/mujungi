## 디자인 범위

새 페이지·메뉴·정책 대시보드 없이 기존 화면을 사용한다. Ideation 시안이 없는 classic 기록이므로 화면설계 v1.5j 번호와 현재 코드를 뼈대로 삼는다. 아래 시안은 기존 화면의 배치/토큰을 사용한 상태별 명세이며, 앱 구현·실제 기기 캡처·접근성 인증 결과가 아니다.

| 화면 | 배치/크기 | 이번 변경 |
|---|---|---|
| S-08 자유대화 준비 | 기존 제목·보호자 입력·시작 버튼·하단 탭 | 기술 시작 실패를 미참여 탓으로 보이지 않는 기존 실패 카드 연결 |
| S-12 참여 대기/진행 | 상단 제목/상태/시간, 본문 대화, 끝내기 버튼, 하단 탭 | RP-1의 실제 안내 및 안내/참여 완료 전 일반 출력 보류 |
| P-01 보호자 끝내기 | 기존 확인 팝업·취소 기본 초점 | 유지. 아이의 음성 종료에 이 팝업/반복 확인을 붙이지 않음 |
| P-02/P-03 | 기존 작은 안내 팝업과 확인 버튼 | RP-2로 거절·무응답·기술 실패 구분 |
| S-17 마무리/끝 | 제목·시간·사유 카드·기기 미확인 줄·기록/홈·탭 | RP-3의 확인된 표현만 인용, RP-4의 실제 인사 여부에 맞춘 설명 |
| D-19 기기 상태 | 캐릭터 중심, 28px 상태 라벨, 구석 끄기 버튼 | 새 동의 버튼 없이 승인 안내 음성·기존 표정/상태 사용. 기술 오류/연결 상태를 침묵으로 꾸미지 않음 |

## S-12 — 참여 안내와 대화

보호자 화면은 기존 최대 480px 한 열, 제목 20px, 본문 16px, 보조 14px, 카드 반경 12px, 4px 간격 단위를 유지한다. 버튼은 최소 44px, 본문은 가변 높이이며 긴 안내가 버튼을 밀어 가려도 스크롤로 접근 가능해야 한다.

```text
S-12                 [existing one-column layout]
Header               자유대화
Status               무중이 {아이}에게 말을 걸고 있어요
Time                 [확인된 시작 시각/경과가 있을 때]
Transcript           [실제 확인 가능한 대화 항목]
                     [안내 내용은 아래 RP-1]
Action               [이야기 끝내기]
Navigation           홈 | 자유대화 | 연습 | 기록
```

텍스트 대안: 기존 제목 아래 진행 상태와 확인된 시각, 중앙의 대화 목록, 그 아래 끝내기, 화면 아래 탭을 배치한다. 안내 음성과 보호자 화면 내용은 같은 승인 자원 버전을 따른다.

| 변형 | 보이는 것/들리는 것 | 금지되는 오해 |
|---|---|---|
| loading/준비 | 기존 준비 상태·로딩 표현, 임의 시작 시각 없음 | 안내를 들었다/참여했다고 표시하지 않음 |
| 안내 재생 | 승인된 RP-1 음성, 일반 모델 대화 보류 | 리소스/말풍선 존재를 청취 완료로 취급하지 않음 |
| 안내 완료·참여 대기 | 같은 세션의 참여 의사를 기다림, 기존 끝내기 유지 | 모델이 안내/질문을 중복하거나 조기 수락만으로 ACTIVE가 되지 않음 |
| ACTIVE | 기존 대화 목록과 현재 상태 | 첫 관심사 질문 강제·대화 재개 압박 없음 |
| empty | 아직 항목이 없으면 기존 빈 대화 영역/안내, 경과시간 조작 없음 | 무대답/실패를 정상 활동으로 표시하지 않음 |
| stale/offline/복구 | 기존 상태 확인 불가·마지막 확인/복구 줄 | 입력 장애를 아이가 말하지 않는 것으로 설명하지 않음 |
| 안내 실패 | 일반 대화 보류, 서버의 기술 실패 결과에 맞는 기존 실패 경로 | P-03의 ‘아이가 대답하지 않아’를 기술 실패에 쓰지 않음 |

대화 항목은 기존 API가 제공한 확인 범위만 표시한다. 안내 텍스트를 표시해도 실제 청취 완료의 증거로 사용하지 않는다. 확인되지 않은 안내를 ‘전달 완료’라고 표시하는 신규 UI는 만들지 않는다. 생성/거절 음성을 들은 대화처럼 새로 기록하는 것도 허용하지 않는다.

## D-19 — 음성 선택과 중단

```text
D-19                 [existing character-centered layout]
Center               [무중 캐릭터]
Label                대기 / 듣는 중 / 말하는 중 / 마무리
Connection           [필요할 때 기존 다시 연결 보조 줄]
Corner action        [끄기]
```

텍스트 대안: 캐릭터와 상태 라벨을 중앙에 두고 끄기 버튼은 구석에 유지한다. 재생될 안내는 RP-1, 명확한 거절/휴식/종료 반응은 승인된 대화 정책을 따른다. 아이에게 기술 상태명·정책 해시·내부 판정값을 보여 주지 않는다.

- 아이는 기존 음성 입력으로 참여/거절·정정·휴식·종료한다. 추가 음성 시험이나 따라 말하기를 요구하지 않는다.
- 거절/휴식은 재개 설득 없이 수용한다. 명확한 전체 종료는 한 번의 짧은 인사만 허용하며 즉시 음소거에는 인사가 없다.
- 끄기 버튼·마이크 권한 거절 안내·다시 연결 흐름은 유지한다. 현재 라벨/색/표정은 UI 표현이며 기기 종료 확인을 대신하지 않는다.

## P-03 — 참여하지 않은 경우

기존 제목+확인 버튼 배치를 유지하고 판정 결과만 구분한다.

| 결과 | 제목/행동 | 이후 |
|---|---|---|
| 명확한 참여 거절 | ‘아이가 시작하지 않기로 했어요’ + 확인 | 기존 홈 이동. 정상 활동으로 보이지 않음 |
| 기존 창 만료의 무응답 | ‘아이가 대답하지 않아 시작하지 못했어요’ + 확인 | 기존 홈 이동 |
| 안내/전송/재생 확인 실패 | 기존 기술 실패 카드/복구 가능한 오류 | 기술 실패로 분리. 아이의 거절/무응답으로 치환하지 않음 |

새 성공/확인 버튼은 없다. 연습의 기존 미참여 문구는 별도 요구 없이 자동 교체하지 않는다. 사유를 구분할 수 없는 기존 응답은 확신하는 제목을 임의 선택하지 않으며, 필요한 계약 변경을 Domain/Contract Design에 넘긴다.

## S-17 — 마무리/종료/기기 미확인

```text
S-17 CLOSING                    S-17 CHILD_STOP
오늘 자유대화를 마무리하고 있어요     오늘 자유대화가 끝났어요
[확인된 시간 범위]                 [확인된 시간 범위]
[인사 재생 확인 때만 인사 줄]        {아이}가 끝내자고 했어요
기기가 멈추면 기록을 정리해요.       [확인된 표현·시각만, 없으면 인용 생략]
[홈으로]                          [기기 미확인이면 별도 줄]
[기존 잠금 탭]                     [기존 기록/홈/탭]
```

텍스트 대안: 마무리 중은 진행형 제목과 실제 확인 대기만 보이고, 종료 후에는 종료 사유와 별도의 기기 확인 상태를 보여 준다. 종료 원인과 확인 여부를 하나의 값으로 덮지 않는다.

| 상태 | 표현 |
|---|---|
| 일반 종료·인사 실제 재생 확인 | 기존 인사 진행 설명을 확인된 재생 동안만 사용 |
| 즉시 음소거·인사 없음/미확인 | 인사 설명 줄 생략. 마무리 상태 및 기기 확인 대기 유지 |
| 자연어 CHILD_STOP·표현 확인 없음 | 아이 종료 사유와 확인된 시각만. 고정 기본 종료 문구를 말한 것처럼 인용하지 않음 |
| 실제 기본/추가 종료 표현 확인 | 확인된 표현만 기존 인용 스타일로 표시. 새 음성/전사 원문을 일반 로그에 남기지 않음 |
| 기기 종료 확인 30초 만료 | 기존 ‘기기 응답 없이 끝냈어요’/미확인 줄. 실제 멈춤 완료와 구분, 재시작 잠금 유지 |
| 연결 끊김 | 기존 연결 끊김 사유·복구 경로. 아이의 침묵/거절로 표현하지 않음 |

## 문구 개정 제안

질문 Q1-A로 다음 적용 방향을 선택했다. 이 표는 사용자 소유 문구표를 수정하지 않고 앱 적용 차이를 추적하는 RP 기록이다. 실제 적용 전 현행 서비스 사실과 승인 자원·기기 재생의 일치를 확인한다.

| ID | 대상/현재 정본 | 적용 방향 | 이유 |
|---|---|---|---|
| RP-1 | C.S-12.11.4의 짧은 초대 | D1 서비스 안내: ‘나는 AI 인형 무중이야. 우리가 하는 말은 글로 남고, 네 목소리도 저장돼. 보호자는 대화 글을 보고 다른 사람에게 보여줄 수도 있어. 말하기 싫은 건 안 해도 되고, 언제든 그만할 수 있어.’ 뒤 ‘지금 나랑 이야기해 볼까?’ | FR2/US1.2. 보호자 권한·저장 사실과 참여 선택을 알림. 실제 기능과 다르면 FR5.1에 따라 사실에 맞춰 차이를 기록 |
| RP-2 | C.P-03.15.1의 무응답 제목 | 명확한 거절에는 ‘아이가 시작하지 않기로 했어요’. 무응답은 기존 문구, 기술 실패는 기존 기술 실패 경로 | FR2.4/US1.3. 거절과 입력/안내 실패를 혼동하지 않음 |
| RP-3 | C.S-17.72.5의 고정 기본 종료 표현 | 실제 확인된 표현만 인용하고 확인 없으면 생략. 기본 문구로 채우지 않음 | FR4.1/FR5.1/US1.6/US2.1. 하지 않은 말을 사실처럼 표시하지 않음 |
| RP-4 | C.S-17.73.4의 고정 인사 진행 설명 | 승인 인사 재생이 확인된 동안만 노출, 즉시 음소거·없음/미확인은 줄 생략 | FR4/US1.6. 하지 않은 인사를 한다고 말하지 않음 |

## 반응형과 접근성

기존 보호자 한 열 최대 480px와 실제 CSS의 440px·560px 조건을 보존한다. 320/375/440/480/560px 및 긴 한국어·200% 확대에서 상태/버튼/탭의 겹침을 확인한다. 넓은 화면에 새 열·대시보드를 만들지 않는다. 기기는 가로/세로에서 캐릭터·라벨과 최소 72px 끄기 조작이 겹치지 않게 기존 CSS로 검증한다. 상세 점검은 accessibility-checklist.md에 있다.

## Assumptions & Open Questions

- 실제 안내 자원의 제작/버전·상태 사유·인사 재생 증거·확인된 표현을 어떤 내부 계약으로 전달할지는 다음 설계에서 정한다. 정보가 없으면 완료/실제 인사/실제 인용을 추정하지 않는 것이 기본이다.
- 이전 User Stories 검토 R-01은 열린 위험으로 승인됐다. 이 시안은 종료 판단 요청 경계 검사를 대신하지 않으며 interaction-spec.md의 후속 설계 인계로 명시한다.
- 시안은 구현·브라우저·스크린 리더·실제 기기 검증 결과가 아니다. 원본 화면설계·코드의 그 밖 기능은 재설계하지 않는다.
