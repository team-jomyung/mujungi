## Dependency Map

Bolt는 실행 가능한 결과까지 만드는 한 차례의 작업 묶음이다. 이번 통합 Bolt B1에서 외부 의존과 로컬 준비를 다음과 같이 구분한다. 담당 미정은 AI에게 자료 확보 권한이 주어졌다는 뜻이 아니다.

| 의존 | 담당/제공자 | 소요 시간 | 막는 부분 | 대응/지연 시 |
|---|---|---|---|---|
| 필수 서비스 사실을 포함한 승인 안내 텍스트·실제 음성/버전·기존20초한도 | U16 설계가 필요한 자원을 정의. 실제 제작/제공 사람 담당 미정 | 미확인 | B1 U16 안내 기능 완성, 최종 교체 완료/실기기 증거 | 첫 Functional Design에서 구체화. 자원 부재는 명시적 실패 보류. 톤/무음/가짜 COMPLETED로 실제 안내 성공을 주장하지 않음 |
| JDK21·Node22·Docker/Compose·테스트 DB·패키지 | 현재 로컬 환경, 실행 준비는 이 세션에서 확인 | 설치/다운로드 필요 여부 미확인 | B1 해당 검증 | 기존 설치/패키지/테스트 경로 사용. 권한이 필요한 설치는 실행 수단의 승인 절차를 따르고 미준비를 통과로 처리하지 않음 |
| GPT-Live/J1·J6/JEV 실제 공급자 가용성/키 | 기존 외부 공급자 | 이번 대역 시험에는 대기 없음 | 실모델 후속 품질 평가만 | 자동 검증은 가짜 공급자. 유료 실호출·새 키/공급자 연결 안 함 |
| 실제 기기/실제 아이 청취 | 별도 허가/기기와 평가 담당 미정 | 미확인 | 실제 서비스 청취·행동 품질 증거 | 서버/WS/화면 대역 근거와 별도 표시. 이번 자동 결과로 인증하지 않음 |
| 계획/검증 명령·코드 계획·적용 확인 | 사용자 | 응답 시점에 따름 | B1 해당 승인 지점 | 이미 승인된 결정은 다시 묻지 않음. 새 명령 선택/실패/범위 변경을 자동 수용하지 않음 |
| main 필수 검사·실제 demo 배포 | 기존 CI/운영 담당, 원격 현황 미확인 | 이번 범위 밖 | 이후 실제 병합/출시 | 현재 작업 완료와 배포 성공을 구분. 배포를 유발하는 main 병합을 임의 실행하지 않음 |

## Integration Handoffs

U16→U17은 외부 팀 대기가 아니라 같은 세션 안의 의존이다. 계약은 승인되어 있으며 실제 U16 구현·대표 응답/실패·null 자료가 U17에 필요하다. U17에서 서버 근거가 없는 사실을 채우는 우회로를 만들지 않는다.

## Assumptions & Open Questions

원본 문서/라이선스와 실모델 품질의 미확인은 상위 요구를 승계한다. 이번에는 외부 재배포·법률 검토를 추가하지 않는다. 음성 자원의 실제 확보는 아직 완료되지 않았으며 납기 추정에 숨기지 않는다.
