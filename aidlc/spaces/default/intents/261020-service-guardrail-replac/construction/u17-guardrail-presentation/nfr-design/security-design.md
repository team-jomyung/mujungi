## S1 — 인증과 세션 격리

기존 인증된 보호자 API 및 세션별 query 경계를 유지한다. 보호자 end POST는 기존 CSRF와 동일 requestId 의미를 사용한다. 인증/권한 거절·계정 삭제·로그아웃에서는 기존 이동/캐시 제거/취소와 로그인 세대 무효화를 함께 적용하여 이전 아이 응답을 다시 보여 주지 않는다. 다른 세션 ID 응답은 선택 facts 오류로 삼키지 않고 기존 응답 오류로 거절한다.

서버 소유 검증/참여 권한/원음 시작/기기 정지 판단은 서버에 남긴다. 브라우저는 이미 받은 현재 사실을 보여 주고 기존 명령만 전달한다. 운영 인증·암호화·보안 헤더 설정을 새로 만들거나 원격 가동 상태를 인증하지 않는다.

대응: NFR1.1, NFR1.3, NFR2.1, NFR6.2.

## S2 — 원문/오류/표시 경계

confirmedStopBubbleSeq의 현재 공개 CHILD 최종·확실 행만 안전한 텍스트로 렌더링한다. HTML 처리·문자열을 markup으로 삽입·다른 세션 캐시 조회·기본 종료 표현 대체를 하지 않는다. 인용 시각은 같은 행의 유효한 시각만 사용한다. 삭제/비공개/빈 원문은 생략한다.

새 진단 로그/URL/query key/웹 저장소에 전사·원음·토큰·정책 본문/해시를 넣지 않는다. 파싱 실패는 원문 덤프 대신 기존 고정 오류/미확인 처리만 사용한다. 선택 사실 객체의 형식 오류가 기본 응답 검증·인증 실패를 완화하지 않는다. unknown을 성공/거절/무응답/삭제 완료로 바꾸지 않는다.

대응: NFR1.2, NFR1.3, NFR2.2, NFR5.1.

## S3 — 접근성과 증거 보호

이름/인용/문구를 안전하게 전달한 상태에서 기존 접근 가능한 팝업 이름·확인/취소 기본 초점·복귀·키보드/낭독 경계를 유지한다. 전체 전사나 같은 상태를 매2초 새로 낭독하지 않는다. 색 외 상태 설명과 긴 문자열 줄바꿈을 사용한다. 브라우저 점검에서 민감한 실사용 데이터를 넣지 않는다.

모델·기기 대역은 합성 데이터만 사용하고 실제 유료 공급자·실제 아동 데이터/배포·수동 스택 작업을 하지 않는다. 기존 저장/삭제/공유·외부 사본 처리나 실제 기기 청취/이해를 새로 보장하지 않는다. 남아 있는 서버 참여 지적/실제 안내 음성 미준비는 인계에서 숨기지 않는다.

대응: NFR4.1, NFR4.2, NFR5.2, NFR6.2.

## 검증

파서/응답 역전·권한/세션 전환·인용 마크업/제어문자·로그 spy·기기 중단/종료·접근성 상태를 대역으로 검증한다. 실행하지 않은 브라우저/실기기 항목은 실행 성공으로 표기하지 않는다. 코드 생성/Build and Test에서 NFR1.1–NFR1.3 및 연관 행의 구체적인 시험 파일과 실행 결과로 연결한다.
