## 기존 결정 적용

| 주제 | 적용할 기존 결정 |
|---|---|
| 미참여 사유 | 확인된 REFUSED와 NO_RESPONSE를 구분하고 없으면 일반 미참여 문구. 기술 실패는 기존 실패 경로 |
| 종료 인용 | 같은 세션의 확실하고 가시적인 CHILD 최종 행만 인용. 없으면 생략 |
| 인사 재생 | 유효한 현재 PLAYING만 노출. 상태 CLOSING만으로 노출하지 않음 |
| 호환성 | 구버전·null·지원 밖 구조를 미확인으로 소비. 서버와 클라이언트를 함께 갱신 |
| 기기 | 실제 재생 표식과 현재 세션/연결의 종료 확인을 유지. 새 wire 없음 |
| 범위 | 기존 화면·copy·폴링·연습·저장 정책 보존. 배포·실호출 제외 |

## 추가 질문과 모호성 점검

새 제품 선택이 필요한 빈칸은 발견하지 않았다. 위 표는 새 답변이나 승인 기록이 아니라 기존 계약을 적용한 기록이다. 화면 문구의 세부 표현·순수 변환 함수 위치는 되돌릴 수 있는 구현 결정으로 다룬다. 한 객체의 구조 실패와 개별 미래 enum은 C1 계약대로 서로 다른 처리를 한다.

U16 code-generation의 R-01(안내 이전 전사 항목의 늦은 조각 재수락)은 서버 참여 경계의 미해결 지적이다. U17 표시 작업으로 이를 해결했다고 하지 않는다. 최종 Build and Test에서 실행기 회귀와 수정 필요성을 별도로 검증해야 한다. 실제 승인 음성 미준비도 성공으로 덮지 않는다.
