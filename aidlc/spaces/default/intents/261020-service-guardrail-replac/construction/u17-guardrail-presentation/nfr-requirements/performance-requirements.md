## 실패·자원·관측 경계

파싱/표시는 이미 받은 말풍선 범위에서 순번을 찾아 처리하고 추가 요청을 만들지 않는다. 기존 대량/부분 items 동작을 보존하며 새로운 비공개 전사 축적/고정 데이터 상한을 만들지 않는다. 네트워크 단절·권한 만료·상태/세션 전환은 기존 화면 경로와 사실 초기화를 적용한다. 출력 지연/단절을 아이 침묵이나 거절로 바꾸지 않는다.

브라우저 성능/기기 실제 음성 지연·운영 가용성에 대한 신규 SLA는 범위 밖이다. 기존 상태·오류·응답 순서 시험을 성능 수치처럼 부풀리지 않는다. 서버의 시한/상태 권한은 U16 소유다.
