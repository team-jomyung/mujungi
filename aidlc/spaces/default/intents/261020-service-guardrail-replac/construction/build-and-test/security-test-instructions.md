# 권한·개인정보 검증

## 적용 기준

U16 현재 소유/동의·내부 인증·정책 문맥 whitelist/이스케이프·최소 사실 수명, U17 현재 세션/인증·권한 거절 캐시 제거·텍스트 렌더링·민감 로그0을 검증한다. 기존 CSRF와 삭제/공유 의미를 보존한다.

## 실행과 증거

build-instructions.md의 기존 권한/계정 API 회귀·ServiceGuardrail·인용/기기 범위 명령을 사용한다. 같은 명령은 한 번만 실행한다. 전체 verify.sh의 A4/P2/P3가 비밀/로그 위생을 확인한다. 로그에 원문/토큰을 새로 출력하지 않는다. 권한 GET403 뒤 해당 세션 캐시/진행 요청의 폐기 여부를 별도 확인한다. 실제 유료 공급자·실아동·수동 스택·원격 배포/운영 migration은 사용하지 않는다.
