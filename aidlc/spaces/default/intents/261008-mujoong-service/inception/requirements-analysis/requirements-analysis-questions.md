## 2. 사람이 정해야 하는 질문

### Q1. 푸시 알림(FR-A10)을 이번 MVP에 넣습니까?

화면(D-17)은 '푸시를 누르면 04 재조회 → 12/17' 알림 진입을 유지하지만, ADR은 모바일 푸시를 채택하지 않았고 WBS에 행이 없으며 푸시 토큰 테이블도 빈칸입니다. 점검표 10은 "7일 안에 못 넣으면 11/5 뒤 백로그"를 제안합니다. 플랫폼이 Next.js 웹이라 넣는다면 웹 푸시(Android Chrome은 바로, iOS는 홈 화면 추가 뒤 16.4+)가 됩니다.

A. 포함 — 웹 푸시. core_push_token 추가, 문구 3종(음성 연결 문제 / 기기 상태 확인 불가 / 연결 문제로 활동 종료), Android Chrome으로 시연
B. 백로그 — 이번엔 알림을 보내지 않는다. 앱 재진입 시 최신 세션 재조회(04 → 12/17) 로직만 남긴다
C. 포함하되 축소 — '활동이 끝났어요(종료 확인됨)' 1종만 웹 푸시
D. 인앱 대체 — 푸시 없이 앱이 열려 있을 때 폴링으로 상단 배너만(백그라운드 알림 없음)
X. Other (please specify)

[Answer]: A - 웹 푸시 3종 포함하되 우선순위는 Should(Q6의 Must 경로 뒤). 시연은 Android Chrome에서 장애·미확인 1종만 보여도 됨. 7일 안에 못 넣으면 Delivery Planning에서 뒤로 민다

### Q2. 연습 세션에서 목표를 몇 개까지 고릅니까?

화면 18은 여러 개를 골라 시작하고 12 머리에 n/N을 표시합니다. 그러나 ADR result-pipeline과 ERD v1은 세션당 목표 1개(단일 Snapshot)이고, 점검표 15는 "7일 안에 벅차면 1개로 줄이는 건 사용자 결정"이라고 적었습니다. 여러 개면 세션-목표 연결 테이블과 목표 간 전환 로직(가중 랜덤 순서)이 추가됩니다.

A. 여러 개(화면대로) — 18에서 여러 개 선택, 12 머리 n/N, ★ 즐겨찾기 · 담은 순 가중 랜덤 순서, realtime_session_goal 연결 테이블 추가
B. 1개로 축소 — 18에서 하나만 고른다(단일 선택), n/N 표시 없음, ERD 그대로. 일정 우선
C. UI는 여러 개 선택을 유지하되 서버는 첫 목표만 이번 세션에서 실행하고, 다음 목표는 다음 세션 시작 때 자동으로 이어 받는다
X. Other (please specify)

[Answer]: A - 화면대로 여러 개. realtime_session_goal 연결 테이블 추가, 12 머리 n/N, 즐겨찾기·담은 순 가중 랜덤 순서

### Q3. 생성형 AI 사전 고지(FR-A04)는 보호자 화면 어디에 둡니까?

요구사항은 로그인·최초 동의 화면과 약관에 고지하라고 하지만, 화면 v1.5e에서 01의 AI 고지 글이 빠졌고 점검표는 "02-1 약관 시트에 고지가 남아야 함 → 확인 필요"로 남겨 두었습니다. 아이에게는 기기 시작 안내(FR-E01)로 알리는 것이 정해져 있습니다.

A. 02-1 약관 시트 각 항목 본문 안에만(화면 추가 요소 없음)
B. 02 동의 화면 상단에 고정 한 줄("무중은 생성형 AI와 대화하는 서비스예요") + 02-1 약관 본문
C. 01 로그인 화면 하단 한 줄 복원 + 02-1 약관 본문
D. 보호자 화면 고지는 없음 — 아이 음성 시작 안내(FR-E01)만
X. Other (please specify)

[Answer]: A - 02-1 약관 시트 각 항목 본문에 생성형 AI 고지 문장을 넣는다. 01·02 화면에는 추가 요소 없음(화면 v1.5e 결정). FR-A04의 '로그인·동의 화면 표시'는 '동의 약관 본문 표시'로 고쳐 적는다

### Q4. 계정 삭제(P7)는 어떻게 처리합니까?

화면은 「삭제」 → 기록 · 리포트 · 동의 · 기기 등록 삭제 요청 → 01입니다. ERD에는 core_data_deletion_request(접수)만 있고 ADR-008은 탈퇴 · 재가입을 TBD로 두었습니다. 아동의 음성 원음과 전사가 들어 있어 삭제 시점과 되돌릴 수 있는지를 요구사항으로 정해야 합니다.

A. 즉시 영구 삭제 — DELETE /api/me 응답 전에 DB 행과 원음 파일을 모두 지운다. 되돌리기 없음. 같은 구글 계정으로 다시 로그인하면 새 계정(02부터)
B. 요청 접수형 — 요청 즉시 접근 차단 · 로그아웃하고, 백그라운드 작업이 원음 포함 영구 삭제. 완료 전 재로그인 시 "삭제 처리 중" 표시. 되돌리기 없음
C. 유예형 — 요청 후 7일 보관(그 안에 재로그인하면 삭제 취소), 지나면 영구 삭제
D. 소프트 삭제만 — deleted_at 표시로 접근을 막고 물리 삭제는 제출 뒤 운영자가 수동
X. Other (please specify)

[Answer]: B - 요청 즉시 접근 차단·로그아웃, 백그라운드 작업이 원음 포함 영구 삭제(core_data_deletion_request), 완료 전 재로그인 시 '삭제 처리 중' 표시, 되돌리기 없음. 완료되면 같은 구글 계정으로 새 계정(02부터)

### Q5. 지원 브라우저와 기기를 정해 주세요. (select all that apply)

WBS는 "지원 브라우저 1종"이라고만 적었습니다. 마이크 권한은 HTTPS가 있어야 하고, PDF 공유는 Web Share API(iOS Safari 15+ · Android Chrome), 웹 푸시(Q1)는 iOS에서 홈 화면 추가 뒤에만 됩니다. 고른 조합이 Q1 · PDF 공유 · 통합시험 기기를 결정합니다.

A. 보호자 폰: Android Chrome
B. 보호자 폰: iOS Safari
C. 아이 기기: 데스크톱 · 노트북 Chrome
D. 아이 기기: Android 태블릿 · 폰 Chrome
E. 아이 기기: iPad Safari
X. Other (please specify)

[Answer]: A, C, D - 보호자 폰은 Android Chrome이 기준(통합시험 기기), iOS Safari는 핵심 화면만 깨지지 않게 하고 푸시·공유는 보장하지 않음. 아이 기기는 데스크톱·노트북 Chrome이 시연 기준, Android 태블릿 Chrome은 되면 좋음

### Q6. 11/5 시연에서 반드시 끝까지 보여 줄 경로는 무엇입니까? (select all that apply)

점검표 '어디에도 없는 것'에 "11/5 시연 경로 없음"이 올라 있습니다. 여기서 고른 경로가 요구사항의 Must 묶음이 되고, 나머지는 Should로 내려가 Delivery Planning에서 뒤로 밀 수 있습니다.

A. 처음 한 번 — 구글 로그인 → 동의 4항목 → 아이 정보 → 홈 → 아이 기기 코드 등록(05a · D0)
B. 자유대화 1회 끝까지 — 08 → 12 실시간 말풍선 → 끝내기 또는 "무중아 그만할래" → 17 → 27(대화 기록 · 생활 팁 · 목표 후보 담기)
C. 연습 1회 — 18에서 목표 선택 → 12 연습(상황 → 첫 반응 → Cue → 새 상황) → 17 → 27 고른 목표 표시
D. 기록 · 리포트 — 26 달력 → 27 → 28 범위 → 30 → PDF 저장 · 공유
E. 장애 경로 — P2 연결 끊김 복구 실패 → 17(사유: 연결 끊김), P3 아이 무응답, 공백 6분 자동 종료
X. Other (please specify)

[Answer]: A, B, C, D - 네 경로가 Must. E 장애 경로는 Should(P2·P3·자동 종료는 구현하되 시연 필수 아님)

### Q7. 시작 뒤 아이가 참여 질문에 답하지 않으면 몇 초 뒤에 P3(시작 못 함 · 기록 없음)로 갑니까?

화면 12 "참여 기다리는 중"에 N초가 비어 있습니다. ADR session-state는 무응답 60초 → CANCELLED, 점검표 6은 20초를 제안했습니다. 이 값이 FR-E02(참여 거부 처리)의 기준 시간이 되고 WBS 1.7.6 시간 계약에 들어갑니다.

A. 20초(점검표 제안)
B. 30초
C. 60초(ADR 원안)
D. 재안내 포함 — 20초 무응답 → 승인 문구로 재안내 1회 → 20초 더 기다린 뒤 P3
X. Other (please specify)

[Answer]: D - 20초 무응답 → 승인 문구로 재안내 1회 → 20초 더 → P3(DECLINED, 기록 없음). 합계 40초를 WBS 1.7.6 시간 계약에 넣는다
