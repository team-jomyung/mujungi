## 3. LANE 1 · 처음 한 번과 홈

### S-01 · 01 보호자 로그인 (US1.1)
- 목적: 구글 계정으로 들어온다. 로그인 상태 유지.
- 상태: 대기 / 인증 중 / 취소 · 실패.
- 그림(C.S-01.0): 로고 "무중", 부제 "아이의 이야기를 함께 살펴봐요", 단추 「구글로 시작」.

### S-03 · 03 아이 정보 (US1.3)
- 상태: 처음 등록(빈 입력 카드 · 뒤로 없음) / 보기(카드 + 기기 상태 줄) / 수정 중(카드 안) / 저장 실패(이전 값 유지).
- 그림: 처음 등록(C.S-03.40) 제목 "아이 정보를 알려 주세요", 칸 "이름 또는 별명" · "나이" · "관심사 (예: 공룡, 블록 놀이)", 「확인」. 보기(C.S-03.2) 머리 "← 아이 정보", 카드 "민준 / 7세 · 공룡, 블록 놀이 / 기기 · 안정", 「정보 수정」. 수정 중(C.S-03.36) 카드 안 입력 3개 + 「취소」 · 「확인」.
