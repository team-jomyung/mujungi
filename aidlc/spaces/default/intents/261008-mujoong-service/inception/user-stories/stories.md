## US1 · 처음 한 번과 홈 (LANE 1 · 1-1)

### US1.1 구글 로그인 — Must · 화면 01 · FR1.1
**보호자**로서, 구글 계정으로 들어와 로그인 상태를 유지하고 싶다. 그래야 매번 다시 로그인하지 않고 아이 활동을 바로 볼 수 있다.

수용 기준
- AC1.1.1 Given 01 대기 When 「구글로 시작」 성공 · 첫 로그인(동의 없음) Then 02로 간다
- AC1.1.2 Given 01 대기 When 「구글로 시작」 성공 · 동의 있음 · 아이 등록됨 Then 04로 간다
- AC1.1.3 Given 01 대기 When 「구글로 시작」 성공 · 동의 있음 · 아이 등록 안 됨 Then 03(처음 등록)으로 간다
- AC1.1.4 Given 01 인증 중 When 취소 · 실패 Then 인증되지 않은 상태로 01에 남고 다시 시도할 수 있다
- AC1.1.5 Given 02 · 03을 끝내지 않고 종료 When 다음 실행 Then 01부터 시작한다
- AC1.1.6 Given 로그인 유지 토큰 만료 When 재로그인 Then 04로 가고, 진행 중 활동이 있으면 지금 활동 칸에 보인다
- AC1.1.7 검증: 01에는 구글 외 로그인 · 회원가입 · 아이디/비밀번호 경로가 없다

INVEST: 독립(다른 스토리 없이 시험 가능) · 작음(화면 1장) · 시험 가능(분기 6개). 의존: 없음.

### US1.2 기록 · 동의 안내 — Must · 화면 02 · 02-1 · P5 · FR1.2 · FR1.3
**보호자**로서, 처음 한 번 무엇을 기록하고 누가 보는지 알고 네 항목에 동의하고 싶다. 그래야 아이 음성이 어떻게 쓰이는지 알고 시작할 수 있다.

수용 기준
- AC1.2.1 Given 02 첫 동의(네 개 다 체크 전) When 화면 표시 Then 「동의하고 계속」이 꺼져 있다
- AC1.2.2 Given 02 When 항목의 「자세히 보기」 Then 02-1 약관 시트(수집 · 목적 · 보관 · 거부 시 영향, 생성형 AI 고지 문장 포함)가 뜬다
- AC1.2.3 Given 02-1 When 「확인」 · 바깥 누름 Then 02 보던 자리로 돌아온다
- AC1.2.4 Given 02 When 네 항목 모두 체크 → 「동의하고 계속」 Then 항목별 동의 상태와 약관 버전이 저장되고 03(처음 등록)으로 간다
- AC1.2.5 Given 02 동의 전 When 「←」 · 뒤로가기 Then P5(동의 전 나가기)가 뜬다
- AC1.2.6 Given P5 When 「로그아웃」 Then 01로, 「계속 동의하기」 Then 02로 간다
- AC1.2.7 Given 02를 끝내지 않고 종료 When 다음 실행 Then 01 → 02다
- AC1.2.8 검증: 동의를 바꾸거나 거두는 화면 · 단추가 없다(거두려면 계정 삭제 US1.6)

INVEST: 작음 · 시험 가능. 의존: US1.1.

### US1.3 아이 정보 — Must · 화면 03 · FR1.4
**보호자**로서, 아이 하나의 이름 · 나이 · 관심사를 한 화면에서 등록하고 나중에 고치고 싶다. 그래야 대화가 아이에게 맞춰진다.

수용 기준
- AC1.3.1 Given 03 처음 등록(빈 입력 카드 · 뒤로 없음) When 이름 · 나이 · 관심사 넣고 「확인」 Then 04로 가고 기기 칸이 「기기 등록」을 안내한다
- AC1.3.2 Given 03 처음 등록 When 「←」 · 뒤로가기 Then 아무 일도 없다(등록을 마쳐야 넘어감)
- AC1.3.3 Given 03 보기 When 「정보 수정」 → 글자 수정 → 「확인」 Then 03에 바뀐 내용이 보인다
- AC1.3.4 Given 03 수정 중 When 「취소」 Then 원래 내용으로 돌아온다
- AC1.3.5 Given 03 입력 When 이름이 비면 Then 「확인」이 꺼진다; 나이가 6~12 밖이면 오류 글이 뜨고 입력 상태가 유지된다
- AC1.3.6 Given 03 When 저장 실패 Then 토스트가 뜨고 이전 값이 유지된다
- AC1.3.7 Given 03 보기 · 수정 중 When 「←」 Then 04로 간다(수정 중이면 「취소」와 같다)
- AC1.3.8 검증: 이름 또는 별명 1~10자(빈 값 · 11자 이상이면 「확인」 꺼짐), 나이 6~12 정수, 관심사 5개 이하 · 각 10자(초과 입력 막음) — 개발 명세 화면별 명세
- AC1.3.9 검증: 아이 선택 · 추가 · 삭제 단추가 없다. 수정으로 기존 활동 · 기록의 대상 아이가 바뀌지 않는다

INVEST: 작음 · 시험 가능. 의존: US1.2.

### US1.4 홈 — Must · 화면 04 · FR1.5 · FR2.3 · FR7.1
**보호자**로서, 홈에서 아이 · 대화 기기 · 지금 활동 세 구역을 한눈에 보고 시작할 수 있는지 알고 싶다. 그래야 기기가 안 될 때 헛되이 시작하지 않는다.

수용 기준
- AC1.4.1 Given 04 When 아이 구역 「수정」 Then 03으로 간다
- AC1.4.2 Given 04 대화 기기 안정(초록) When 화면 표시 Then 마지막 확인 hh:mm과 「기기 상태 보기 ›」가 보이고 자유대화 · 연습 탭이 열려 있다
- AC1.4.3 Given 04 대화 기기 불안정(노랑) · 끊김(빨강) · 응답 없음(회색) When 화면 표시 Then 각 상태 문구(안정될 때까지 시작할 수 없어요 / 전원 · 와이파이를 확인해 주세요 / 기기를 다시 켜 보세요 + 마지막 hh:mm)가 보이고 자유대화 · 연습 탭이 잠긴다
- AC1.4.4 Given 04 연결된 기기 없음 When 화면 표시 Then "기기를 등록해 주세요" + 「기기 등록」이 보이고 탭이 잠긴다; 「기기 등록」 Then 05a
- AC1.4.5 Given 04 When 대화 기기 칸 「기기 상태 보기」(어느 상태든) Then 05로 간다
- AC1.4.6 Given 04 지금 활동 없음 When 화면 표시 Then "진행 중인 활동 없음 · 자유대화 · 연습 탭에서 시작"이 보인다
- AC1.4.7 Given 04 지금 활동 진행 중(초록) When 화면 표시 Then "지호 · 자유대화 n분째" + 「진행 화면 보기 ›」가 보이고, 누르면 12로 간다
- AC1.4.8 Given 04 지금 활동 조회 실패 When 화면 표시 Then 마지막 확인 hh:mm · 미확인 + 「다시 확인」이 보이고 현재 상태로 단정하지 않는다
- AC1.4.9 Given 04 기기 안정 · 활동 없음 When 하단 「자유대화」 Then 08, 「연습」 Then 18로 간다
- AC1.4.10 Given 04 활동 진행 중 When 하단 「자유대화」 또는 「연습」 Then 새 시작 대신 12(해당 활동)로 간다
- AC1.4.11 Given 04 탭 잠김(기기 불안정 · 끊김 · 응답 없음 · 없음) When 하단 「자유대화」 · 「연습」 Then 이유 토스트 뒤 05로 간다
- AC1.4.12 Given 04 When 하단 「기록」 Then 26, 「⚙」 Then 설정 시트(US1.5)
- AC1.4.13 Given 04 When 재진입 Then 최신 세션을 조회해 진행 · 종료 확인 상태를 반영하고, 종료 확인 없는 세션을 종료 완료로 표시하지 않는다

INVEST: 가치 큼(허브) · 시험 가능(구역별 상태 표). 의존: US1.3 · US2.1 · US3.2.

### US1.5 설정 시트 · 로그아웃 — Must · 화면 SET0 · FR1.5
**보호자**로서, 홈에서 로그아웃하거나 계정 삭제로 들어가고 싶다.

수용 기준
- AC1.5.1 Given 04 When 「⚙」 Then 설정 시트(로그아웃 · 계정 삭제)가 화면 위에 뜬다
- AC1.5.2 Given SET0 When 「로그아웃」 Then 로그인 유지가 끝나고 01로 간다
- AC1.5.3 Given SET0 When 「계정 삭제」 Then P7로 간다
- AC1.5.4 Given SET0 When 「←」 · 바깥 누름 Then 04로 돌아온다

INVEST: 작음. 의존: US1.4.

### US1.6 계정 삭제 — Should · 화면 P7 · FR1.6 · NFR12
**보호자**로서, 아이의 기록 · 리포트 · 동의 · 기기 등록을 모두 지우고 계정을 없애고 싶다. 그래야 동의를 거두거나 아이를 바꿀 수 있다.

수용 기준
- AC1.6.1 Given P7 When 「삭제」 Then 기록 · 리포트 · 동의 · 기기 등록 · 원음 삭제 요청이 접수되고 즉시 로그아웃되어 01로 간다
- AC1.6.2 Given P7 When 「아니오」 Then SET0으로 돌아온다
- AC1.6.3 Given 삭제 요청 접수 · 진행 중 세션 있음 When 삭제 Then 세션에 종료 요청(사유 CONSENT_WITHDRAWN)이 먼저 가고 삭제가 이어진다
- AC1.6.4 Given 삭제 처리 중 When 같은 구글 계정으로 다시 로그인 Then "삭제 처리 중"만 보이고 어떤 데이터에도 접근할 수 없다
- AC1.6.5 Given 삭제 완료 When 같은 구글 계정으로 로그인 Then 새 계정으로 02부터 시작한다
- AC1.6.6 검증: 삭제 완료 뒤 DB · 파일 저장소에 그 계정의 원음 · 전사 · 기록 · 리포트 · 기기 행이 없고, 삭제 요청 뒤 늦게 도착한 자료는 저장되지 않는다. 되돌리기 없음

INVEST: 시험 가능(백그라운드 작업 포함). 의존: US1.5. 비고: 동의 철회의 유일한 경로이므로 Delivery Planning에서 앞쪽에 둔다.

### US1.7 알림으로 돌아오기 — Should · 푸시 · 04 · FR7.10
**보호자**로서, 앱을 닫아 두어도 음성 연결 문제 · 기기 상태 미확인 · 연결 문제로 활동 종료를 폰 알림으로 받고 눌러서 바로 현재 상태로 가고 싶다.

수용 기준
- AC1.7.1 Given 앱 닫힘 · 알림 허용(Android Chrome) When 서버가 음성 대화 장애를 확인 Then "대화 중 음성 연결 문제가 발생했어요." 웹 푸시가 1회 온다
- AC1.7.2 Given 앱 닫힘 When 서버가 기기 상태 수신 중단을 확인 Then "기기 상태를 확인할 수 없어요." 웹 푸시가 1회 온다
- AC1.7.3 Given 앱 닫힘 When 기술 문제에 의한 기기 종료가 확인됨 Then "연결 문제로 활동이 종료됐어요." 웹 푸시가 1회 온다
- AC1.7.4 Given 푸시 When 누름 Then 04가 최신 세션을 재조회해 진행 중이면 12, 끝났으면 17, 조회 실패면 04 지금 활동 칸 미확인으로 간다
- AC1.7.5 검증: 같은 사건의 중복 발송이 없고, 알림에 발화 원문 · 대화 내용이 없다. 앱 닫힘 · 앱 연결만의 장애로는 알림이 만들어지지 않는다. 알림 비허용 · 폰 오프라인은 실제 전달로 표시되지 않는다
- AC1.7.6 검증: 푸시가 없어도 앱 재진입(AC1.4.13)에서 같은 재조회가 동작한다

INVEST: 독립(재조회 로직은 US1.4에 이미 있음). 의존: US1.4 · US3.2. 비고: iOS는 보장하지 않음(NFR10). 7일 안에 못 넣으면 Delivery Planning에서 뒤로 민다.

## US2 · 기기 (LANE 2)

### US2.1 우리 집 기기 상태 — Must · 화면 05 · FR2.2 · FR2.3
**보호자**로서, 기기 등록과 네트워크 현황을 두 줄로 보고 "지금 시작할 수 있는지" 한 문장으로 알고 싶다.

수용 기준
- AC2.1.1 Given 05 기기 등록 없음 When 화면 표시 Then 등록 줄 「없음」, 네트워크 줄 비어 있음, 판정 카드 「기기 등록」, 탭 잠김
- AC2.1.2 Given 05 기기 등록 완료 When 화면 표시 Then 등록 줄 「완료 (코드 앞 4자리)」가 보인다
- AC2.1.3 Given 05 네트워크 안정(초록) When 화면 표시 Then "안정 · 지연 n초", 판정 "시작할 준비가 되었어요"
- AC2.1.4 Given 05 네트워크 불안정(노랑: 지연 1초 초과 또는 5분 안 끊김 2회) When 화면 표시 Then "불안정 · 끊김 n회 · 지연 n초", 판정 "지금은 시작할 수 없어요 + 공유기 가까이", 탭 잠김
- AC2.1.5 Given 05 네트워크 끊김(빨강: 40초 무응답) When 화면 표시 Then "끊김 · hh:mm부터", 판정 "지금은 시작할 수 없어요 + 전원 · 와이파이 확인", 탭 잠김
- AC2.1.6 Given 05 네트워크 응답 없음(회색) When 화면 표시 Then "응답 없음 · 마지막 hh:mm", 판정 "지금은 시작할 수 없어요 + 기기를 다시 켜 보세요", 탭 잠김
- AC2.1.7 Given 05 When 판정 카드 「기기 등록」(등록 전) Then 05a; 종료 표현 「설정」 Then SET-01; 「←」 Then 04
- AC2.1.8 Given 05 When 하단 「자유대화」 · 「연습」 Then 04와 같은 잠김 규칙(열림이면 08 · 18, 잠김이면 이유 토스트); 「기록」 Then 26
- AC2.1.9 검증: 보호자 폰 인터넷 줄은 없고 폰 인터넷 문제는 공통 오류 토스트로만 알린다. 판정 카드 규칙은 04 탭 잠금 규칙과 같다

INVEST: 시험 가능(상태 주입). 의존: US2.2 · US6.2.

### US2.2 기기 등록 — Must · 화면 05a · FR2.1
**보호자**로서, 아이 기기에 뜬 8자리 코드를 넣어 우리 집 기기로 묶고 싶다.

수용 기준
- AC2.2.1 Given 05a 입력 When 영숫자 8칸을 다 채움 Then 「등록」이 켜진다(덜 채우면 꺼짐)
- AC2.2.2 Given 05a When 등록 성공 Then 기기가 우리 집 기기로 묶이고(계정당 하나) 05로 간다; 기기 쪽은 「등록되었어요」(3초) 뒤 대기(US6.1)
- AC2.2.3 Given 05a When 없는 코드 · 이미 등록된 코드 Then 05a에 빨간 카드가 뜨고 코드를 다시 넣을 수 있다
- AC2.2.4 Given 05a When 「취소」 · 「←」 Then 05로 돌아온다
- AC2.2.5 검증: 기기 검색 · 페어링 · 기기 해제 단추가 없다. 등록된 기기만 기기 토큰으로 WSS 접속이 되고, 미등록 · 만료 토큰은 거부된다

INVEST: 작음 · 시험 가능. 의존: US6.1.

### US2.3 종료 표현 설정 — Should · 화면 SET-01 · FR2.4
**보호자**로서, 아이가 평소 쓰는 "이제 그만" 같은 말을 추가 종료 표현으로 등록하고 싶다. 그래야 아이가 자기 말로 끝낼 수 있다.

수용 기준
- AC2.3.1 Given SET-01 목록 When 화면 표시 Then 기본 표현 「무중아 그만할래」가 파란 카드로 고정되어 삭제 · 수정 단추가 없다
- AC2.3.2 Given SET-01 When 「+ 표현 추가」 Then 같은 화면에 입력 칸이 열린다; 표현 카드 누름 Then 그 칸이 수정 상태가 된다
- AC2.3.3 Given 입력 칸 When 「확인」 Then 목록에 반영된다(아직 저장 전); 「삭제」 Then 목록에서 빠진다
- AC2.3.4 Given SET-01 When 「저장」 Then 저장되어 05로 간다; 「취소」 · 「←」 Then 변경을 버리고 05로 간다
- AC2.3.5 Given 추가 표현 5개 When 화면 표시 Then 「+ 표현 추가」가 꺼진다
- AC2.3.6 검증: 2~20자 · 중복 금지 · 최대 5개를 어기면 오류 글과 「저장」 꺼짐. 저장 완료 · 실패를 구분하며 실패를 성공으로 표시하지 않는다
- AC2.3.7 검증: 저장한 표현은 다음 활동부터 종료 의도 인식(US6.4)에 보조 정보로 쓰이고 진행 중 활동에는 적용되지 않는다

INVEST: 작음. 의존: US2.1.

## US3 · 자유대화 · 활동 진행과 끝 (LANE 3, 연습도 12 · 17을 함께 씀)

### US3.1 자유대화 시작 — Must · 화면 08 · FR3.1 · FR2.3
**보호자**로서, 아이에 대해 아는 것을 네 칸에 적거나 비워 두고 바로 자유대화를 시작하고 싶다.

수용 기준
- AC3.1.1 Given 08 네 칸 전부 비움 When 「자유대화 시작」 Then 12로 간다(비워도 시작 가능)
- AC3.1.2 Given 08 일부 입력 When 「자유대화 시작」 Then 네 칸(알고 있는 내용 · 관련 상황 유형 · 정보 출처 · 궁금한 내용)이 세션 문맥(결과 구조화 입력)으로 저장되고 12로 간다
- AC3.1.3 Given 08 When 서술 칸 200자를 넘기면 Then 입력이 막힌다
- AC3.1.4 Given 08 요청 전송 중 When 화면 표시 Then 「자유대화 시작」이 꺼진다(중복 시작 방지)
- AC3.1.5 Given 08 When 탭 이동 Then 04 · 18 · 26으로 간다
- AC3.1.6 Given 08 When 시작 요청 Then 기기 안정 · 동의 완료 · 진행 세션 없음이 아니면 서버가 거절하고 이유가 보인다
- AC3.1.7 검증: 목적 선택 칸 · 확인 화면 · 녹음 첨부가 없다. 평가 · 판단을 유도하는 입력란이 없다. 네 칸 원문은 대화 모델에 전달되지 않는다

INVEST: 작음 · 시험 가능. 의존: US1.4 · US2.1.

### US3.2 활동 진행 보기 — Must · 화면 12 · FR3.2 · FR7.1 · FR7.8 · FR7.9
**보호자**로서, 아이와 무중의 대화를 실시간 말풍선으로 보고 상태(끊김 · 공백 · 미확인)를 구분해서 알고 싶다. 그래야 끼어들지 않고도 안심할 수 있다.

수용 기준
- AC3.2.1 Given 12 자유대화 · 대화 중 When 화면 표시 Then 머리에 "자유대화", 시작 시각 · 경과, 말풍선(아이 전사 + 승인된 AI 말)이 1~2초 폴링으로 갱신된다
- AC3.2.2 Given 12 연습 · 연습 중 When 화면 표시 Then 머리에 "연습 · n/N번째 목표"와 현재 단계가 보인다(US4.2)
- AC3.2.3 Given 12 처음 · 참여 기다리는 중 When 아이가 대답하지 않음(20초 → 재안내 → 20초) Then P3 → 04(기록 없음)
- AC3.2.4 Given 12 처음 When 기기 응답 없음(20초) Then 08 · 18로 돌아가 이유를 표시한다
- AC3.2.5 Given 12 연습 When 상황 생성 실패(재생성 포함 2회) Then 18로 돌아가 이유를 표시한다
- AC3.2.6 Given 12 When 「끝내기」 Then P1(US3.3)
- AC3.2.7 Given 12 When 아이 종료 표현 인식 Then 17(사유: 아이가 끝냄)
- AC3.2.8 Given 12 대화 중 When 공백 4분 Then "공백 4분 · 2분 경고" 상태가 보이고, 6분이면 자동 종료(SILENCE) → 17(사유: 말이 없어 자동 종료)
- AC3.2.9 Given 12 연습 When 목표 하나 끝 · 다음 목표 있음 Then 12(다음 목표); 마지막 목표 끝 Then 17
- AC3.2.10 Given 12 When 연결 끊김 Then 끊김 점선과 "대화 연결 복구 중"이 보이고, 40초 복구 실패면 P2 → 17(사유: 연결 끊김)
- AC3.2.11 Given 12 When 보호자 서버가 기기 상태를 받지 못함 Then "기기 상태 확인 불가" + 마지막 확인 시각이 보이고 대화 중단으로 단정하지 않는다
- AC3.2.12 Given 12 When 앱만 오프라인 Then "실시간 상태를 불러오지 못하고 있어요" + 마지막 확인 시각이 보이고, 복구 뒤 실제 기록으로만 갱신되며 임의의 중단 구간이 생기지 않는다
- AC3.2.13 Given 12 진행 중 When 하단 탭을 눌러도 Then 12가 유지된다
- AC3.2.14 Given 12 When 푸시 알림으로 다시 들어옴 Then 최신 상태를 재조회한다
- AC3.2.15 검증: 말풍선에는 출력 게이트를 통과한 AI 말만 올라간다. 실시간 발화 · 자막 · 부모 마이크 · 다음 질문 버튼이 없다. 침묵만으로 장애 · 거부 · 실패로 판정하지 않는다

INVEST: 가치 큼 · 시험 가능(상태 주입 · 시간 규칙). 의존: US3.1 또는 US4.1 · US6.2.

### US3.3 끝내기 — Must · 화면 P1 · FR3.3
**보호자**로서, 활동을 끝내고 싶을 때 한 번 확인하고 바로 끝내고 싶다.

수용 기준
- AC3.3.1 Given P1 When 「네, 끝낼게요」 Then 17 마무리 중으로 간다
- AC3.3.2 Given P1 When 「아니오」 Then 12 그대로다
- AC3.3.3 Given 17 마무리 중 When 서버 종료 요청 Then 기기가 일반 출력을 멈추고 승인된 마무리 인사 1회(1~3초)를 재생하고 멈춘다
- AC3.3.4 Given 17 마무리 중 When 기기 멈춤 확인 Then 정리 중으로 넘어간다
- AC3.3.5 Given 17 마무리 중 When 30초 안에 기기 확인 없음 Then 서버가 ENDED_UNCONFIRMED로 처리하고 17 사유 "기기 응답 없이 끝냄"이 보인다(보호자 조작 없음)
- AC3.3.6 Given 앱만 오프라인 When 「네, 끝낼게요」 Then "전송하지 못함"이 보이고 종료 요청됨으로 표시하지 않는다
- AC3.3.7 검증: 요청 중복 · 재시도 · 재연결 · 중복 응답으로 다른 세션이 종료되지 않는다. 종료 확정 뒤 이전 응답이 이어서 재생되지 않는다

INVEST: 작음. 의존: US3.2.

### US3.4 예상치 못한 종료 — Should · 화면 P2 · FR3.5 · FR5.7
**보호자**로서, 연결이 끊겨 복구되지 않았을 때 무슨 일인지와 기록이 어디까지 남았는지 알고 싶다.

수용 기준
- AC3.4.1 Given 12 연결 끊김 40초 복구 실패 When 화면 표시 Then P2(예상치 못한 종료)가 뜬다
- AC3.4.2 Given P2 When 「확인」 Then 17(사유: 연결 끊김 · 끊기기 전까지 기록)로 간다
- AC3.4.3 검증: 기기 종료 확인이 없으면 17 정리 끝으로 바꾸지 않는다. 앱 연결 장애 · 조회 불가를 아이 종료 · 대화 중단으로 표시하지 않는다

INVEST: 작음. 의존: US3.2 · US6.6.

### US3.5 아이 무응답 — Should · 화면 P3 · FR3.5 · FR5.2
**보호자**로서, 아이가 처음부터 대답하지 않아 시작되지 않았을 때 다그치지 않는 말로 안내받고 싶다.

수용 기준
- AC3.5.1 Given 12 참여 기다리는 중 When 20초 무응답 → 재안내 1회 → 20초 무응답 Then P3가 뜬다(DECLINED, 기록 없음)
- AC3.5.2 Given P3 When 「확인」 Then 04로 간다
- AC3.5.3 검증: 안내 문구는 아이를 다그치지 않고 재촉 · 만류가 없다(NFR2). 종료 사실 · 시각만 남고 원문은 저장되지 않는다

INVEST: 작음. 의존: US3.2 · US6.3.

### US3.6 활동 끝 — Must · 화면 17 · FR3.4 · FR3.3
**보호자**로서, 활동이 어떻게 끝났는지 한 줄로 알고 기록이 정리되면 바로 보고 싶다.

수용 기준
- AC3.6.1 Given 끝내기 · 종료 표현 · 자동 종료 · 연결 끊김 When 종료 Then 모두 17로 오고 머리에 활동 종류 + 종료 사유(보호자 끝냄 · 아이가 끝냄 · 자동 종료 · 연결 끊김 · 기기 응답 없이 끝냄)가 보인다
- AC3.6.2 Given 17 When 기기 멈춤 확인 Then 마무리 중 → 정리 중 → 정리 끝 · 「오늘 기록 보기」
- AC3.6.3 Given 17 정리 끝 When 「오늘 기록 보기」 Then 이 활동의 27로 간다(같은 날 여러 활동이어도 해당 세션)
- AC3.6.4 Given 17 정리 실패 When 「기록에서 다시 시도」 Then 27(정리 다시)
- AC3.6.5 Given 17 When 「홈으로」 Then 04; 하단 「홈」 · 「기록」 Then 언제든 04 · 26(정리는 서버에서 계속)
- AC3.6.6 Given 17 마무리 중 When 하단 「자유대화」 · 「연습」 Then 잠김 · 토스트 「끝나는 중이에요」
- AC3.6.7 Given 17 정리 중 · 정리 끝 When 하단 「자유대화」 · 「연습」 Then 08 · 18
- AC3.6.8 검증: 17에는 결과 · 해석 · 추천 · 판정이 보이지 않는다. 준비 중 기록은 준비 상태로 표시된다

INVEST: 시험 가능. 의존: US3.3 · US6.4.

## US4 · 연습 (LANE 4, 진행과 끝은 12 · 17 공통)

### US4.1 내 연습 목표 — Must · 화면 18 · FR4.1
**보호자**로서, 담아 둔 연습 목표에서 오늘 할 것을 여러 개 골라 시작하고, 즐겨찾기와 삭제로 목록을 정리하고 싶다.

수용 기준
- AC4.1.1 Given 18 목표 있음 When 화면 표시 Then ★ 즐겨찾기 묶음이 맨 위, 그 아래 담은 순으로 보인다
- AC4.1.2 Given 18 When 목표 줄 누름 Then 선택 ↔ 해제, 단추의 N 갱신, 0개면 「연습 시작」 꺼짐(18 유지)
- AC4.1.3 Given 18 1개 선택 When 「연습 시작」 Then 12(연습)
- AC4.1.4 Given 18 여러 개 선택 When 「연습 시작」 Then 12(연습 · ★ · 담은 순 가중 랜덤 순서로 차례로)
- AC4.1.5 Given 18 When 별 「☆/★」 누름 Then 즐겨찾기 토글(맨 위 묶음 · 연습 순서 가중치), 18 유지
- AC4.1.6 Given 18 When 목표 줄 오른쪽 「×」 Then 바로 삭제되고 토스트 「되돌리기」(3초); 「되돌리기」 Then 줄 복구
- AC4.1.7 Given 18 비어 있음 When 화면 표시 Then "먼저 자유대화를 해 보세요" + 「자유대화 하러 가기」 → 08
- AC4.1.8 Given 18 When 탭 이동 Then 04 · 08 · 26
- AC4.1.9 검증: 다른 목표 선택 화면 · 연령 기반 추천 목록이 없다. 즐겨찾기 · 담은 순서가 저장된다. 선택만으로 활동이 시작되지 않는다

INVEST: 시험 가능. 의존: US4.3(목표가 담겨야 비어 있지 않음).

### US4.2 연습 세션 진행 — Must · 화면 12(연습) · FR4.2 · FR4.3 · FR7.5 · FR7.6
**보호자**로서, 고른 목표들을 차례로 연습하는 동안 지금 몇 번째 목표의 어느 단계인지 보고 싶다. **아이**로서, 상황을 듣고 먼저 말해 보고 어려우면 도움을 받고 싶다.

수용 기준
- AC4.2.1 Given 연습 시작 요청 When 서버 수락 Then 선택 목표가 세션에 고정되고(realtime_session_goal) 상황 생성 → 자동 확인(목표 · 트리거 포함, 금지 표현)을 거친다; 실패 시 1회 재생성, 또 실패면 시작하지 않고 18로(이유 표시)
- AC4.2.2 Given 12 연습 When 목표 진행 Then 머리 "연습 · n/N번째 목표"와 현재 단계(상황 제시 · 첫 반응 · 도움 · 도움 후 반응 · 새 상황 · 마무리)가 실제대로 보이고, 고정 순서 표시나 부모의 다음 단계 · 건너뛰기 버튼은 없다
- AC4.2.3 Given 상황 제시 뒤 When 아이가 먼저 말함 Then 첫 반응이 기록되고 판정(functional · partial · none · uncertain)이 저장된다; 무반응은 NOT_PERFORMED
- AC4.2.4 Given 첫 반응이 목표 행동과 연결되지 않음 When 아이가 도움에 동의 Then Cue 1회가 제공 · 기록되고 도움 후 반응 1회가 기록된다; 거부하면 도움 없이 넘어간다
- AC4.2.5 Given 도움 후 반응(또는 도움 없음) When 다음 단계 Then 새 상황(같은 목표 · 다른 소재 · Cue 금지)이 제시되고 반응이 기록된다
- AC4.2.6 Given 목표 하나 끝 When 다음 목표 있음 Then 12(다음 목표, n+1/N); 마지막이면 17
- AC4.2.7 검증: 판정 LLM은 5초 예산 + 재시도 1회, 실패면 uncertain. 첫 반응 · 도움 · 도움 후 반응 · 새 상황 반응이 분리 저장되고 도움 후 반응이 첫 반응을 덮어쓰지 않는다. 미실시 단계는 null + 사유
- AC4.2.8 검증: 보호자 서버의 상태 미수신 · 앱 조회 불가를 연습 멈춤 · 단계 실패로 바꾸지 않는다. 개별 상황 본문은 보호자에게 미리 보이지 않는다. 판정값은 12 · 17 · 27 어디에도 노출되지 않는다

INVEST: 가치 큼 · 시험 가능(합성 아동 발화). 의존: US4.1 · US6.5. 비고: 단계 값 목록 · 판정 기준 · 프롬프트는 AI 입출력 계약(Contract Design)에서 확정.

### US4.3 연습 목표 후보 담기 — Must · 화면 27 → 18 · FR4.4 · FR7.4
**보호자**로서, 기록에서 서버가 제안한 연습 목표 후보를 골라 내 연습 목표에 담고 싶다. 그래야 아이에게 맞는 것만 연습한다.

수용 기준
- AC4.3.1 Given 27 연습 목표 후보 칸 When 화면 표시 Then 4요소(행동 정의 · 기회 조건 · 상황 생성 조건 · 판정 기준)를 갖춘 후보만 추천 이유와 함께 보인다; 없으면 "후보 없음"
- AC4.3.2 Given 27 When 「담기」 Then 18 목록에 쌓인다(화면 이동 없음), 단추가 「담김 ✓」으로 바뀐다
- AC4.3.3 Given 27 「담김 ✓」 When 다시 누름 Then 담기 취소 → 「담기」, 18에서도 빠진다
- AC4.3.4 검증: 후보 생성 · 등록은 자동이지만 18에 들어가는 것은 「담기」로만. 추천 근거는 실제 기록에 연결되고, 근거 없는 개인화 이유 · 지원되지 않는 목표가 노출되지 않는다

INVEST: 작음. 의존: US5.2.

## US5 · 기록과 리포트 (LANE 5)

### US5.1 기록 달력 — Must · 화면 26 · FR6.1
**보호자**로서, 달력에서 활동한 날을 찾아 그날의 활동을 고르고 싶다.

수용 기준
- AC5.1.1 Given 26 When 화면 표시 Then 달력에 활동한 날 점이 보인다; 「상담용 리포트 다운」 Then 28
- AC5.1.2 Given 26 When 날 누름 Then 그날 활동 목록(시각 · 종류)이 아래에 뜬다; 활동 없는 날이면 「활동이 없어요」 한 줄(26 유지)
- AC5.1.3 Given 26 그날 목록 When 활동 한 줄 누름 Then 27로 간다
- AC5.1.4 Given 26 When ‹ › Then 다른 달로 넘어간다
- AC5.1.5 Given 27 When 「←」 Then 26 보던 날이 유지된다
- AC5.1.6 Given 26 When 탭 이동 Then 04 · 08 · 18
- AC5.1.7 검증: 활동 종류 필터가 없다. 미참여(DECLINED) 세션은 종료 사실 · 시각만 보이고 27로 연결되지 않는다. 같은 날 여러 세션이 구분된다

INVEST: 작음. 의존: US3.6.

### US5.2 활동 기록 상세 — Must · 화면 27 · FR6.2 · FR6.3 · FR7.4 · FR7.7
**보호자**로서, 활동 하나의 대화 기록 · 생활 팁 · 연습 목표 후보를 한 화면에서 보고 싶다. 그래야 아이가 무슨 이야기를 했고 집에서 무엇을 해 볼지 안다.

수용 기준
- AC5.2.1 Given 27 When 화면 표시 Then 세 칸(대화 기록 · 생활 팁 · 연습 목표 후보)이 보이고, 연습 세션이면 맨 위에 18에서 고른 목표 이름만(판정 글 없음) 보인다
- AC5.2.2 Given 27 대화 기록 칸 When 화면 표시 Then 아이 전사 · 승인된 AI 말 인용, 보호자 입력 배경, 보호자 입력/아이 회상 출처 구분, 아직 확인되지 않은 내용이 보인다
- AC5.2.3 Given 27 생활 팁 칸 When 화면 표시 Then 승인된 지원 목록에서 목표 행동 · 적용 조건에 맞는 항목이 적용 조건 · 한계와 함께 보인다; 맞는 것이 없으면 '추가 관찰 필요'
- AC5.2.4 Given 27 정리 중 When 화면 표시 Then 정리 중 상태가 보이고 자동으로 갱신된다; 정리 실패면 「다시 시도」 → 팁 · 목표 다시 정리(같은 활동 결과는 한 번만 생성)
- AC5.2.5 Given 27 When 뒤로 Then 26 보던 날 유지
- AC5.2.6 검증: 모든 인용 · 출처 · 미실시가 실제 저장 기록과 일치하고 서버 집계에 없는 수치 · 판단 · 점수 · 성공률이 없다. 미승인 팁 · 검색 점수가 노출되지 않는다. 기록 수신 공백을 아이의 침묵 · 거부 · 실패로 쓰지 않는다. 기술 문제가 있었으면 종료 확인 여부와 확보 범위 · 미확인 구간이 따로 보인다

INVEST: 가치 큼. 의존: US3.6 · 서버 구조화(FR7.4).

### US5.3 리포트 범위 고르기 — Must · 화면 28 · FR6.4
**보호자**로서, 상담에 가져갈 기간과 활동을 골라 리포트를 만들고 싶다.

수용 기준
- AC5.3.1 Given 28 처음 When 화면 표시 Then 빠른 선택 「최근 2주」가 적용되어 달력에 칠해지고 아래 활동 목록과 단추 N이 갱신된다
- AC5.3.2 Given 28 When 「이번 달」 Then 1일~오늘; 「전체 · 직접」 Then 기록 첫날~오늘이 칠해지고 달력에서 날을 누르면 직접 고르기 시작
- AC5.3.3 Given 28 달력 When 첫 번째 날 누름 Then 그날만 칠해지고 「끝나는 날을 누르세요」, 빠른 선택 해제; 두 번째 날 Then 두 날 사이가 칠해진다(앞뒤 바뀌어도 됨); 세 번째 누름 Then 새로 시작
- AC5.3.4 Given 28 달력 When 드래그 Then 같은 결과, 달을 넘으면 ‹ ›로 이어짐, 미래 날은 못 누름; ‹ › Then 고른 기간 유지
- AC5.3.5 Given 28 활동 목록 When 줄 누름 Then 빠짐 ↔ 들어감, 단추 N 갱신; 진행 중인 활동은 목록에 없다
- AC5.3.6 Given 28 기간 안 활동 0건 When 화면 표시 Then 「이 기간엔 활동이 없어요」 + 단추 꺼짐(28 유지)
- AC5.3.7 Given 28 N ≥ 1 When 「활동 N개로 리포트 만들기」 Then 만드는 중(몇 초 · 화면 머무름) → 성공 시 리포트 id를 들고 30
- AC5.3.8 Given 28 만드는 중 When 「취소」 · 「←」 Then 중단하고 고른 범위 그대로 28
- AC5.3.9 Given 28 만들기 실패 When 「다시 시도」 Then 같은 범위로 만드는 중; 「범위 다시」 Then 28(범위 유지); 「←」 Then 26
- AC5.3.10 Given 28 범위 화면 When 「←」 Then 26(고른 범위 버림)
- AC5.3.11 검증: 날 토글이 없다. 생성은 60초 안에 READY, 실패는 3회 재시도 뒤 FAILED(NFR8)

INVEST: 시험 가능(날짜 · 활동 조합). 의존: US5.1.

### US5.4 PDF 저장 전 확인 · 저장 · 공유 — Must · 화면 30 · FR6.5
**보호자**로서, 만든 리포트의 기간 · 아이 · 건수를 확인한 뒤 PDF로 저장하고 상담사에게 직접 보내고 싶다.

수용 기준
- AC5.4.1 Given 30 확인 When 화면 표시 Then 기간 · 아이 · 대화 원문 건수가 보이고 AI 글이 없음을 안내한다
- AC5.4.2 Given 30 When 「PDF 저장」 Then 저장했어요 → 「공유하기」 · 「파일 열기」 · 「기록으로」가 보인다
- AC5.4.3 Given 30 저장 완료 When 「공유하기」 Then OS 공유 시트(Web Share API)가 뜬다; 「파일 열기」 Then 파일이 열린다; 둘 다 30 유지

INVEST: 작음. 의존: US5.3.

### US5.5 리포트 PDF 내용 — Must · R-PDF · FR6.5 · FR7.3
**보호자**로서, 아이 정보와 날짜별 대화 원문만 담긴 PDF를 받고 싶다. **전문가**로서, AI 해석 없이 원문을 보고 싶다.

수용 기준
- AC5.5.1 Given 리포트 생성 When 서버가 만듦 Then 머리(아이 이름 · 연령 · 관심사 · 기간 · 만든 날) → 날짜별 목차 → 날짜별 대화 원문(과거 → 최신) 순서다

- AC5.5.3 검증: 동의 범위 밖 전사 · 인용이 들어가지 않는다. 금지 표현(NFR1) 검사를 통과한다. 한글이 깨지지 않는다

INVEST: 시험 가능(템플릿 검사). 의존: US5.3.

## US6 · 아이 기기 웹 (LANE 6, /device)

### US6.1 처음 켜기 · 코드 — Must · 화면 D0 · FR2.1
**운영자**(준비) · **보호자**(등록)로서, 아이 기기를 처음 켜면 등록 코드가 보이고 보호자가 입력하면 우리 집 기기가 되길 바란다.

수용 기준
- AC6.1.1 Given /device 첫 실행(미등록) When 화면 표시 Then 서버가 발급한 8자리 코드가 크게 보이고 등록 대기 상태다
- AC6.1.2 Given D0 등록 대기 When 보호자가 05a에서 등록을 마침 Then 「등록되었어요」(3초) 뒤 T19 대기로 간다
- AC6.1.3 Given 등록된 기기 When 브라우저 데이터 삭제 Then 새 코드가 뜨고(D0) 보호자가 다시 등록해야 하며 옛 Device 행은 해제된다
- AC6.1.4 검증: 운영자 사전 시드 · 고정 ID 없이 서버 발급 코드로만 등록된다. 등록 뒤 기기 토큰이 기기 저장소에 남고 WSS 접속에 쓰인다

INVEST: 작음. 의존: 없음(US2.2와 양끝).

### US6.2 상태 화면 · 켜기 끄기 — Must · 화면 T19 · FR5.1
**아이**로서, 「켜기」만 누르면 무중이 들을 준비가 되고, 「끄기」로 끌 수 있길 바란다. **보호자**로서, 기기 화면만 봐도 지금 듣는지 말하는지 알고 싶다.

수용 기준
- AC6.2.1 Given T19 꺼짐 When 「켜기」 Then 마이크 · 소리 허용을 받고 기기 연결(WSS) 뒤 대기가 된다; 화면 켜짐 유지(Wake Lock)
- AC6.2.2 Given T19 When 마이크 · 소리 허용 거부 Then "마이크 허용 안 됨" 상태가 보이고 「켜기」를 다시 누를 수 있다(연결하지 않음)
- AC6.2.3 Given T19 대기 When 「끄기」 Then 기기 연결이 끊기고 꺼짐이 된다
- AC6.2.4 Given T19 대기 When 보호자가 활동 시작 Then 대기 → 듣는 중 → 생각 중 → 말하는 중이 실제 상태대로 바뀐다
- AC6.2.5 Given T19 활동 중 When 아이 종료 표현 · 보호자 끝내기 · 자동 종료 Then 마무리(승인 인사 재생) → 대기(자동)
- AC6.2.6 Given T19 When 연결 끊김 Then "연결 끊김 · 다시 연결 중"이 보이고 복구되면 대기(또는 진행 중 상태)로 돌아간다
- AC6.2.7 Given T19 When 탭이 뒤로 가거나 화면이 꺼짐 Then 연결 유지를 시도하고 끊기면 다시 연결 중
- AC6.2.8 Given T19 When 브라우저 데이터 삭제 · 다른 기기 Then D0(다시 등록)
- AC6.2.9 검증: 클릭 요소는 「켜기」 · 「끄기」뿐이다. `?debug=1`이면 상태 로그가 보인다. 승인된 음성만 재생된다(출력 게이트)

INVEST: 시험 가능. 의존: US6.1.

### US6.3 시작 안내와 참여 확인 — Must · (음성) · FR5.2 · FR7.2
**아이**로서, 활동이 시작되면 누구와 무엇을 하는지, 그만하고 싶을 때 뭐라고 말하면 되는지 듣고 내가 할지 말할 수 있길 바란다.

수용 기준
- AC6.3.1 Given 기기 대기 When 보호자가 자유대화 시작 Then 승인된 음성 문구로 AI와 대화한다는 사실 · 오늘 활동 · 기록과 보호자 열람 · "무중아 그만할래" 안내 뒤 참여 의사를 묻는다
- AC6.3.2 Given 기기 대기 When 보호자가 연습 시작 Then 자유대화와 다른 승인 문구로 안내하고 참여 의사를 묻는다
- AC6.3.3 Given 참여 질문 뒤 When 20초 무응답 Then 승인 문구로 재안내 1회; 다시 20초 무응답 Then 시작하지 않고 종료(DECLINED, 기록 없음) → 보호자 P3
- AC6.3.4 Given 참여 질문 뒤 When 아이가 명시적으로 거부 Then 다른 선택지를 1회 제안하고, 다시 거부하면 마무리(DECLINED)
- AC6.3.5 Given 참여 질문 뒤 When 아이가 특정 주제만 거부 Then 다른 주제를 제안하고 종료로 혼동하지 않는다
- AC6.3.6 Given 참여 질문 뒤 When 아이가 응함 Then 활동이 시작되고 보호자 12가 "대화 중"으로 바뀐다
- AC6.3.7 검증: 쉬기 · 건너뛰기 · 재개 명령은 안내하지 않는다. 재권유가 1회를 넘지 않는다. 무응답 · 쉬고 싶다는 말만으로 종료를 확정하지 않는다. 문구 버전은 세션 중 고정된다

INVEST: 시험 가능(합성 아동 발화 · 타이머). 의존: US6.2.

### US6.4 자유대화 · 종료 의도 · 마무리 — Must · (음성) · FR5.3 · FR5.4 · FR7.2 · FR7.3
**아이**로서, 무중이 내 이야기를 하나씩 물어 주고, 엄마가 뭐라고 했는지 아는 척하지 않고, 그만하고 싶다고 하면 바로 인사하고 멈추길 바란다.

수용 기준
- AC6.4.1 Given 자유대화 시작 · 배경 입력 없음 When 대화 Then 프로필 관심사 · 승인된 일상 질문으로 시작하고 마무리까지 진행된다
- AC6.4.2 Given 자유대화 · 배경 입력 있음 When 대화 Then 보호자 입력을 직접 언급하지 않고('엄마가 그러던데' 류 0건) 일상 질문 → 후속 질문으로 이어가며, 입력한 사건이 나오지 않아도 계속 유도하지 않는다
- AC6.4.3 Given 대화 중 When AI 응답 Then 한 번에 질문 하나, 과도한 칭찬 · 추궁 없음, 출력 게이트를 통과한 음성만 재생된다
- AC6.4.4 Given 대화 중 When 아이가 "무중아 그만할래" 또는 저장된 추가 표현 또는 그 밖의 명확한 종료 의도 Then 대기 응답을 취소하고 승인된 마무리 인사 1회를 재생하고 멈춘다(CHILD_STOP)
- AC6.4.5 Given 대화 중 When 종료 의도가 불명확 Then 종료라고 단정하지 않고 짧게 확인한다
- AC6.4.6 Given 대화 중 When 역할 속 대사 · 상대 발화 · 주제 거부 · 기기 재생 음성 Then 종료로 처리하지 않는다
- AC6.4.7 Given 아이 발화 When 저장 Then GPT-Live 전사와 원음이 세션에 저장되고 불확실 구간은 표시된다
- AC6.4.8 검증: 20회 시험에서 종료 표현 오인식 0 · 미인식 1 이하. 종료 확정 뒤 이전 응답이 이어서 재생되지 않는다. 대화 역할에 판정 기준 · 보호자 입력 원문 · 이전 판정이 전달되지 않는다(NFR3)

INVEST: 가치 큼 · 시험 가능(합성 세트). 의존: US6.3.

### US6.5 연습 음성 흐름 — Must · (음성) · FR5.5 · FR5.6
**아이**로서, 만들어진 상황을 듣고 먼저 말해 보고, 어려우면 "같이 살펴볼까?" 뒤에 힌트를 받고 다시 말하고, 새 상황에서 또 해 보고 싶다.

수용 기준
- AC6.5.1 Given 연습 시작 When 안내 Then 만들어진 상황임과 AI의 역할을 음성으로 알리고 상황과 상대 역할의 말을 들려 준다; 기회 트리거는 승인 대본으로 출력된다
- AC6.5.2 Given 기회 트리거 뒤 When 아이가 먼저 말하기 전 Then 힌트 · 정답 · 시범(Cue)이 나가지 않는다; 같은 말 반복 · 속도 조절은 요청하면 해 준다
- AC6.5.3 Given 첫 반응이 목표 행동과 연결되지 않음 When Then "같이 살펴볼까?"로 동의를 구하고, 동의하면 상대의 말을 다시 짚어주는 단서를 실시간으로 만들어 준다(5초 예산, 정답 문장 없음); 거부하면 이어가지 않는다
- AC6.5.4 Given Cue 뒤 When 아이가 다시 말함 Then 도움 후 반응 1회로 기록되고 재시도는 1회를 넘지 않는다
- AC6.5.5 Given 새 상황 When 제시 Then 소재만 다르고 목표 행동 · 상대 관계 · 기회 조건은 같으며 추가 도움이 없다; 같은 활동 안에서 같은 상황은 재사용되지 않는다
- AC6.5.6 Given 마지막 목표 끝 When 마무리 Then 승인 목록의 마무리 음성이 1회만 재생된다
- AC6.5.7 검증: 단서를 추가하지 않은 반복 · 속도 조절은 Cue로 집계되지 않고, 목표 단서가 추가된 설명은 도움으로 기록된다(FR5.6). 제공한 도움 내용과 동의 응답이 기록된다

INVEST: 시험 가능(합성 세트). 의존: US6.3 · US4.2.

### US6.6 연결 끊김 대응 — Should · (음성) · T19 · FR5.7 · FR7.9
**아이**로서, 잠깐 연결이 끊겨도 돌아오면 아까 하던 이야기를 이어가고, 안 되면 조용히 끝나길 바란다. **보호자**로서, 그 사이 무슨 일이 있었는지 미확인으로 남는 걸 알고 싶다.

수용 기준
- AC6.6.1 Given 활동 중 When 기기 연결 또는 음성 모델 연결 장애 확인 Then 기술적 일시 정지가 기록되고 보호자 12에 "대화 연결 복구 중" + 점선, 기기는 다시 연결 중
- AC6.6.2 Given 장애 중 When 40초 안에 복구 · 종료 요청 없음 · 상태 복원 가능 Then 재개하고 이전 응답 · Cue를 다시 재생하지 않는다
- AC6.6.3 Given 장애 중 When 40초 안에 복구되지 않음 Then 기술 종료(DISCONNECT) → 보호자 P2 → 17, 끊기기 전 기록 보존
- AC6.6.4 Given 복구 뒤 When 기록 보완 Then 확보 기록으로만 타임라인을 채우고 증거 없는 구간은 미확인으로 남긴다
- AC6.6.5 Given 정상 연결 When 아이가 4분 말이 없음 Then 공백 경고(기기 안내 1회 · 보호자 12 표시), 6분이면 SILENCE 자동 종료 → 마무리 → 대기
- AC6.6.6 검증: 앱만 오프라인 · 보호자 서버 상태 미수신 · 음성 장애 시간을 공백으로 합산하지 않는다. 종료 요청 중 · 종료된 세션은 복구만으로 재개되지 않는다

INVEST: 시험 가능(장애 주입). 의존: US6.4 · US3.2.

## INVEST 점검

- **Independent**: 화면 카드 하나가 스토리 하나라 각자 시험할 수 있다. 12 · 17 공통 화면은 자유대화 · 연습 두 스토리가 같은 화면을 쓰지만 수용 기준이 겹치지 않게 나눴다(US3.2는 공통 상태, US4.2는 연습 단계).
- **Negotiable**: 수용 기준은 분기표를 옮긴 것이라 화면 설계가 바뀌면 같은 줄을 고친다.
- **Valuable**: 모든 스토리에 보호자 또는 아이의 "그래야 ~"가 있다. 서버 기능(FR7)은 별도 스토리가 아니라 그것이 드러나는 스토리의 수용 기준에 들어 있다.
- **Estimable · Small**: 가장 큰 US3.2(15 AC) · US5.3(11 AC)도 화면 1장 범위다. 음성 스토리 US6.4 · US6.5는 AI 계약(Contract Design)이 정해져야 추정이 끝난다.
- **Testable**: 모든 AC가 Given/When/Then 또는 "검증:" 한 줄이고, 시간 규칙은 NFR6의 값으로 주입 시험한다.
