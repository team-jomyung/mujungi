## P1 · 보호자 — 지호 엄마

- **역할**: 6~12세 아이 한 명을 둔 보호자. 구글 계정 하나로 로그인한다. 한 계정에 아이 하나 · 기기 하나. 형제가 있으면 계정을 따로 쓴다(G2).
- **목표**
  - 집에서 아이가 상황에 맞게 말하는 연습을 꾸준히 하게 돕고 싶다.
  - 아이가 무중과 무슨 이야기를 했는지, 어떤 생활 팁과 연습 목표 후보가 나왔는지 보고 싶다.
  - 상담사에게 보여 줄 대화 원문 묶음(PDF)을 손쉽게 만들어 직접 전달하고 싶다.
- **불편 · 두려움**
  - 아이가 평가받거나 재촉당하는 느낌을 받을까 걱정한다 → 진단 · 점수 · 압박 문구가 어디에도 없어야 한다(NFR1 · NFR2).
  - 기기가 잘 되는지 모르는 상태에서 시작하고 싶지 않다 → 홈과 05에서 기기 상태를 한 문장으로 알려 준다.
  - 활동 중 폰을 닫아도 아이 활동이 끊기면 안 된다 → 앱 연결은 관찰용이고 활동은 기기와 서버 사이에서 이어진다.
- **기술 숙련도**: 중간. 폰 웹(Android Chrome 기준, iOS Safari 최선 — NFR10)을 쓴다. PWA 설치를 요구하지 않는다.
- **사용 빈도**: 주 2~3회, 한 번에 10~15분. 활동 뒤 기록 확인은 그날 또는 다음 날.
- **하지 않는 것**: 아이 여러 명 관리, 동의 항목 선택 · 철회, 기록 부분 삭제, 기기 해제, 활동 중 다음 단계 · 건너뛰기 조작. 아이를 바꾸려면 계정 삭제 뒤 새로.
- **주요 화면**: 01 · 02 · 02-1 · P5 · 03 · 04 · SET0 · P7 · 05 · 05a · SET-01 · 08 · 12 · P1 · P2 · P3 · 17 · 18 · 26 · 27 · 28 · 30.

## P2 · 아이 — 지호, 7세

- **역할**: 6~12세. 화면 없는 음성 기기(지금은 웹 /device로 대체)로 AI '무중'과 이야기한다. 계정이 없고 화면 조작은 「켜기」 · 「끄기」뿐이다(G19 · G22).
- **목표**
  - 재미있게 이야기하고, 어려우면 도움을 받아 다시 말해 보고 싶다.
  - 그만하고 싶을 때 바로 그만하고 싶다("무중아 그만할래").
- **불편 · 두려움**
  - 어른 말투로 추궁받거나 정답을 강요받는 것이 싫다 → 질문은 하나씩, 과도한 칭찬 · 추궁 금지, Cue는 정답 직접 제시 금지(FR5.3 · FR5.5).
  - 엄마가 뭐라고 했는지 AI가 아는 것 같으면 불편하다 → 보호자 입력을 직접 언급하지 않는다(FR5.3).
  - 참여 질문 뒤 다시 묻는 말이 재촉으로 들리면 싫다 → 재안내 1회 · 중립 톤의 승인 문구(NFR2 · AC6.3.9).
- **기술 숙련도**: 낮음. 음성만. 글 읽기에 의존하지 않는다 — 기기 상태는 캐릭터 표정 + 음성으로 전달되고 글 라벨은 보호자 · 운영자용이다(C.D-19.31.1 · AC6.2.4). 마이크 허용 팝업은 보호자가 도와 준다.
- **사용 빈도**: 보호자가 시작할 때. 한 활동 10분 안팎, 말이 없으면 4분 경고 · 6분 자동 종료.
- **보호 규칙**: 승인된 문구로만 시작 안내 · 재안내 · 마무리 인사, 생성 출력은 게이트를 거쳐 승인된 말만 재생(FR7.2 · FR7.8), 종료 의도는 정확 일치가 아니라 의미로 인식(FR5.4).
- **주요 접점**: D0(처음 켜기) · T19(상태 화면) · 음성 흐름(시작 안내 → 대화/연습 → 마무리).

## P3 · 운영자 — 팀(데모 준비)

- **역할**: 5인 팀(A 계정 / B 음성 / C 연습 / D AI / E 결과). 11/5 시연을 위해 EC2 1대에 배포하고 데모 시드(보호자 2 · 아이 2 · 기기 2 — A6)와 데모 기기를 준비한다.
- **목표**: 시연 네 경로(처음 한 번 · 자유대화 1회 · 연습 1회 · 기록 · 리포트)가 끊기지 않고 돌아간다. 문제가 나면 서버 로그와 기기 웹 `?debug=1`로 원인을 본다.
- **하지 않는 것**: 관리자 화면 · 운영 도구는 없다(G22). 기기 사전 시드 없이 서버 발급 코드로 등록한다(G6).
- **스토리에서의 위치**: 직접 스토리는 없다. US6.1(기기 처음 켜기)의 준비자이고 Infrastructure · Deployment 단계의 주체다.

## 전문가 (상담사) — 비사용자 이해관계자

- 보호자가 저장해 직접 건넨 PDF(아이 이름 · 나이 + 저장 기록으로 만든 10개 항목)만 본다. 서비스 계정 · 로그인 · 전송 · 수신 확인은 없다(FR6.5).
- PDF에는 진단 · 점수 · 성공률 · 향상 판단이 없고 "진단 결과가 아니에요"가 명시된다(NFR1). 인용은 저장 전사와 같고 출처(보호자 입력 / 아이 회상)가 붙는다.
- 인용을 읽고 찾아보는 용도라 글자를 선택 · 검색 · 복사할 수 있는 텍스트 PDF를 기대한다(AC5.5.6).

## 페르소나 관계

- 보호자가 시작 · 종료 · 기록을 주도하고, 아이는 음성으로만 참여한다. 둘은 같은 세션을 다른 접점(/parent · /device)에서 본다.
- 운영자는 두 접점이 돌아가는 바탕을 준비하고, 전문가는 결과물(PDF)만 받는다.
- 우선순위: 보호자 > 아이 > 운영자. 전문가는 PDF 내용 제한(NFR1)으로만 영향을 준다.
