"문구 미정"으로 표시한 것은 화면 설계에 상태는 있으나 문구표에 글이 없는 곳이다 — 제품 관리자가 AC 끝에 "(문구 미정 · 뒤 단계에서 확정)"을 붙이면 근거 없는 문구를 만들지 않고 넘길 수 있다.

### US1 · 처음 한 번과 홈

- **US1.1 · 추가 AC1.1.8** — Given 01 When 「구글로 시작」 누름 Then 인증 중 상태가 보이고 단추가 다시 눌리지 않는다 — 근거: S-01 상태 목록 "대기 / 인증 중 / 취소 · 실패" 중 인증 중이 AC에 없음.
- **US1.2 · 수정 AC1.2.2** — "02-1 약관 시트(수집 · 목적 · 보관 · 거부 시 영향 …)"를 항목별 실제 소제목으로: 음성 수집 = 수집하는 것 · 이용 목적 · 보관 · 동의하지 않으면(C.S-02-1.35.3~10), 보호자 열람 = 보는 사람 · 볼 수 있는 것 · 이용 목적 · 동의하지 않으면(41.3~10), 리포트 = 만드는 것 · 전달 · 보관 · 동의하지 않으면(42.3~10), 원음 = 보관하는 것 · 이용 목적 · 보관 · 동의하지 않으면(43.3~10). 또 "생성형 AI 고지 문장 포함"을 "네 항목 본문 모두에"로 명시 — 근거: FR1.3 완료 기준. 단, **문구표 02-1 네 항목(35 · 41 · 42 · 43)에 고지 문장이 없다** — 문구 미정으로 표시해야 한다.
- **US1.2 · 수정 AC1.2.5~1.2.6** — P5 제목 · 본문을 Given에: "동의하지 않으면 무중을 쓸 수 없어요" / "네 항목에 모두 동의해야 시작할 수 있어요. 나가면 로그아웃돼요."(C.P-05.64.1~2).
- **US1.3 · 추가 AC1.3.10** — Given 03 보기 When 화면 표시 Then 카드에 이름 · "n세 · 관심사" · **기기 상태 줄(「기기 · 안정」 등)** · 「정보 수정」이 보인다 — 근거: S-03 상태 "보기(카드 + 기기 상태 줄)", C.S-03.2.2~2.5. 기기 상태 줄이 AC 어디에도 없음. 기기 없음 · 불안정일 때 이 줄의 문구는 미정.
- **US1.3 · 수정 AC1.3.1** — 처음 등록 화면 문구를 Given에: 제목 "아이 정보를 알려 주세요", 칸 라벨 "이름 또는 별명" · "나이" · "관심사 (예: 공룡, 블록 놀이)"(C.S-03.40.1~4).
- **US1.3 · 수정 AC1.3.5 · AC1.3.6** — 나이 오류 글과 저장 실패 토스트는 문구표에 없음 → 문구 미정 표시. 접근성: 오류 글은 해당 칸 바로 아래에 글로 붙고 색(빨강)만으로 알리지 않는다.
- **US1.4 · 수정 AC1.4.2** — Then에 홈 제목 "{아이}의 오늘"(C.S-04.3.1)과 상태명 글자 "안정"(C.S-04.3.6)을 포함. 지금은 색(초록)과 hh:mm만 적혀 있어 색만으로 상태를 전하는 것으로 읽힐 수 있다.
- **US1.4 · 수정 AC1.4.4** — 기기 없음 문구가 05의 것과 섞였다. 04 대화 기기 칸은 "연결된 기기 없음" + "아이 기기에 뜬 코드로 등록해요." + 「기기 등록」(C.S-04.4.6~8)이다("기기를 등록해 주세요"는 05 판정 카드 C.S-05.6.5).
- **US1.4 · 수정 AC1.4.6 + 추가 AC1.4.14** — AC1.4.6의 "진행 중인 활동 없음 · 자유대화 · 연습 탭에서 시작해요."(C.S-04.66.10~11)는 **기기 안정일 때만**이다. 탭 잠김이면 지금 활동 칸이 "지금은 시작할 수 없어요" + 사유 한 줄로 바뀐다: 기기 없음 → "기기를 먼저 등록해 주세요."(C.S-04.4.10~11), 불안정 → "기기 네트워크가 불안정해요. 안정되면 자유대화 · 연습 탭이 열려요."(C.S-04.67.9~10). 끊김 · 응답 없음의 사유 문구는 미정. 분기표 구역 표에는 없고 문구표에만 있는 상태라 빠졌다.
- **US1.4 · 수정 AC1.4.7** — Then에 "hh:mm 시작"(C.S-04.3.12)을 추가. 예시 이름은 페르소나(지호)와 문구표(민준)가 달라도 되지만 한 문서 안에서는 하나로.
- **US1.4 · AC1.4.8 · AC1.4.11** — 조회 실패 칸 문구와 잠긴 탭 이유 토스트 문구는 문구표에 없음 → 문구 미정 표시.
- **US1.4 · 추가 AC1.4.15 검증** — 대화 기기 · 지금 활동 상태는 색 + 상태명 글자 + 사유 문구를 함께 쓰고 색만으로 구분하지 않는다. 잠긴 탭은 흐림만이 아니라 보조기기에도 잠김으로 읽히고, 누르면 이유가 글(토스트)로 나온다 — 근거: 화면이 모든 상태에 글자를 함께 쓰는 설계, WCAG 1.4.1.
- **US1.5 · 수정 AC1.5.1** — 시트 머리 "← 설정"(C.S-SET0.5.1).
- **US1.6 · 수정 AC1.6.1** — Given P7에 제목 "정말 계정을 삭제할까요?"와 본문 "{아이}의 기록 · 리포트 · 동의 · 기기 등록이 모두 지워지고 되돌릴 수 없어요. 남길 리포트는 먼저 저장해 두세요."(C.P-07.65.1~2)를 포함. "리포트를 먼저 저장"은 되돌릴 수 없는 작업 앞의 유일한 예방 문구라 AC에 있어야 시험된다.
- **US1.6 · AC1.6.4** — "삭제 처리 중" 화면은 화면 설계에 카드가 없다 → 문구 · 화면 미정 표시(새 화면이 아니라 01 위 안내인지 확인 필요).
- **US1.6 · 추가 AC1.6.7 검증** — 「삭제」는 파괴적 단추로 「아니오」와 시각 · 라벨로 구분되고, 팝업이 열릴 때 초점은 「아니오」 쪽에 있다 — 근거: 되돌리기 없음(AC1.6.6), 오류 예방 원칙.

### US2 · 기기

- **US2.1 · 수정 AC2.1.1** — "네트워크 줄 비어 있음"이 아니라 라벨 "기기 네트워크 현황 · 등록 뒤 표시"(회색, 값 없음)(C.S-05.6.4). 판정 카드 문구 "기기를 등록해 주세요" + "아이 기기에 뜬 8자리 코드를 넣어요." + 「기기 등록」(C.S-05.6.5~7).
- **US2.1 · 수정 AC2.1.4 · AC2.1.5** — 판정 사유를 실제 문장으로: 불안정 "기기 네트워크가 불안정해요. 기기를 공유기 가까이 두거나 와이파이를 확인해 주세요."(C.S-05.61.7), 끊김 "기기 연결이 끊겼어요. 기기 전원과 와이파이를 확인해 주세요."(C.S-05.62.7). 불안정 그림(61.5)은 "끊김 3회"만 보이고 지연 n초가 없다 — 분기표(끊김 n회 · 지연 n초)와 그림이 다르니 어느 쪽인지 확인.
- **US2.1 · AC2.1.6** — 응답 없음 판정 문장은 그림이 없음 → 문구 미정.
- **US2.1 · 추가 AC2.1.10** — Given 05 When 화면 표시 Then 종료 표현 구역에 "{아이}의 종료 표현" · 기본 표현 "무중아 그만할래" · 「설정」 · 등록된 추가 표현 요약("추가 표현 n개 · "…" · "…"")이 보인다 — 근거: C.S-05.7.7~10. 05의 종료 표현 입구가 AC에 조작(「설정」→SET-01)으로만 있고 표시 상태가 없다.
- **US2.1 · 추가 AC2.1.11** — 머리 "← 대화 기기 상태" · "마지막 확인 hh:mm"(C.S-05.6.1~2).
- **US2.1 · 추가 AC2.1.12 검증** — 두 줄 · 판정 카드는 색 + 상태명 + 사유를 함께 쓴다(AC1.4.15와 같은 규칙).
- **US2.2 · 수정 AC2.2.1** — 안내 "아이 기기 화면의 8자리 코드"(C.S-05A.8.2), 입력 칸은 D0처럼 4자리 · 4자리로 묶어 보인다(C.D-00.30.3 "7F3K · 92QD"와 대응). 칸 하나하나가 터치 영역 44px 이상.
- **US2.2 · 수정 AC2.2.3** — 빨간 카드 문구 "없는 코드예요"(C.S-05A.8.5). 이미 등록된 코드 문구는 없음 → 미정. 카드는 글이 있으므로 색만 아님 — 유지.
- **US2.2 · 추가 AC2.2.6** — Given 05a When 「등록」 누름 · 등록 중 Then 「등록」이 꺼지고 등록 중 상태가 보인다 — 근거: S-05A 상태 "입력 / 등록 중 / 완료 / 실패" 중 등록 중이 AC에 없음.
- **US2.3 · 수정 AC2.3.2** — 입력 칸 라벨 "새 표현" · 칸의 「확인」(C.S-SET1.63.5 · 63.8). 화면 수준 「취소」(63.7)와 혼동되지 않게 AC2.3.3은 "입력 칸 「확인」"으로.
- **US2.3 · AC2.3.6** — 오류 글 · 저장 실패 표시는 문구표에 없음 → 미정.
- **US2.3 · 추가 AC2.3.8 검증** — 기본 표현은 파란 카드 색뿐 아니라 삭제 · 수정 단추가 없다는 구조로도 구분된다(AC2.3.1이 이미 말함 — 접근성 근거로 한 줄 추가). "기본" 같은 글 라벨은 문구표에 없으니 요구하지 않는다.

### US3 · 자유대화 · 활동 진행과 끝

- **US3.1 · 수정 AC3.1.2** — 칸 이름을 문구표대로: "알고 있는 내용"(서술) · "관련 상황"(선택 칩: 친구 · 학교 · 가족 · 학원 · 기타) · "정보 출처"(선택 칩: 직접 봄 · 아이에게 들음) · "궁금한 내용"(서술)(C.S-08.10.2~14). "관련 상황 유형"은 문구표에 없는 말. 제목 "오늘 아이와 자유롭게 이야기해요"(10.1).
- **US3.1 · AC3.1.3** — "서술 칸 200자"는 두 서술 칸에만 적용됨을 명시(칩 칸은 해당 없음).
- **US3.1 · 열린 질문(지식)** — 관련 상황 · 정보 출처 칩이 하나만 고르는지 여럿인지 화면 설계에 없다. AC에 "(단일/복수 선택 미정)"으로 표시.
- **US3.1 · AC3.1.6** — 서버 거절 이유 표시 문구 미정.
- **US3.2 · 수정 AC3.2.1** — Then에 상태 한 줄(부제) 추가: 참여 기다리는 중 "무중이 {아이}에게 말을 걸고 있어요"(C.S-12.11.2), 대화 중 "{아이}가 이야기하고 있어요"(12.2), 연습 중 "{아이}가 연습하고 있어요"(19.2). 말하는 중인 발화는 "… (말하는 중)" 꼬리로 구분(12.8). 경과 "hh:mm 시작 · n분째"(11.3).
- **US3.2 · 수정 AC3.2.2** — 머리는 "연습 · n/N번째 목표 · {목표 이름}"(C.S-12.19.1). 목표 이름이 빠져 있다.
- **US3.2 · 수정 AC3.2.6** — 단추 라벨은 「끝내기」가 아니라 자유대화 「이야기 끝내기」(C.S-12.11.5 · 12.9 · 51.7), 연습 「연습 끝내기」(19.7). AC3.2.6 · AC3.3 · 분기표의 「끝내기」는 총칭이니 AC에서는 실제 라벨로.
- **US3.2 · 수정 AC3.2.8** — "'공백 4분 · 2분 경고' 상태"를 실제 문구로: 경과 줄 "hh:mm 시작 · n분째 · 4분째 말이 없어요"(C.S-12.51.3), 안내 "2분 더 말이 없으면 활동이 끝나요" + "아이가 다시 말하면 그대로 이어져요."(51.5~6). 보호자용 안내라 NFR2(재촉 금지)에 걸리지 않는다 — 좋은 문구.
- **US3.2 · 수정 AC3.2.10** — 두 상태로 나눈다: (a) 끊김 진행 중 — 점선 + "대화 연결 복구 중"(문구표에 없음 → 미정), (b) 복구 뒤 — 대화 흐름 안에 "hh:mm ~ hh:mm 잠깐 끊김" 구간 표시(C.S-12.12.7). (b)가 AC에 없다.
- **US3.2 · AC3.2.11 · AC3.2.12** — 두 문구는 요구사항에서 왔고 문구표에 없음 → 미정 표시(의미는 유지).
- **US3.2 · 추가 AC3.2.16 검증** — 말풍선의 발화자(아이 · 무중)는 위치 · 색만 아니라 보조기기가 읽을 수 있는 이름으로 구분되고, 폴링 갱신이 보호자의 초점 · 스크롤 위치를 빼앗지 않으며 새 말풍선은 조용히(aria-live polite 수준) 알린다 — 근거: 1~2초 갱신 화면의 WCAG 2.2.2 · 4.1.3.
- **US3.3 · 수정 AC3.3.1 · AC3.3.2** — P1 제목 "정말 끝낼까요?"(C.P-01.13.1), 단추 「아니오」 · 「네, 끝낼게요」(13.2~3).
- **US3.3 · 수정 AC3.3.3** — 17 마무리 중 문구: 머리 "오늘 자유대화를 마무리하고 있어요", 본문 "무중이 마무리 인사를 하고 있어요" + "기기가 멈추면 기록을 정리해요."(C.S-17.73.2~5). 이때 「오늘 기록 보기」(73.6)는 보이되 준비 전 상태.
- **US3.3 · 수정 AC3.3.5** — 사유 머리 "기기 응답 없이 끝냈어요", 본문 "기기가 30초 동안 멈춤을 알리지 않아 끝낸 것으로 처리했어요. 다음 시작 전에 기기 상태를 다시 확인해요."(C.S-17.58.4~5).
- **US3.3 · AC3.3.6** — "전송하지 못함" 표시 문구 미정.
