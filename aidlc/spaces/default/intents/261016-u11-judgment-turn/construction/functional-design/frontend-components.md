# U11 판정 턴 기반 — 프런트 구성 요소

U11은 프런트(`frontend/`) 코드를 바꾸지 않는다(요구사항 제약 "건드리지 않는 것: 프런트 · 기기 ↔ 서버 계약"). 범위 확장의 선 형식 정비도 서버와 공급자 사이만 바꾸고, 기기 ↔ 서버 음성 형식(PCM16 24kHz, 960바이트 프레임)은 그대로 둔다(BR11.8). 공급자 쪽 표본율이 16kHz가 되더라도 변환은 서버 `ProviderClient` 한 곳에서 한다.

- 기기 화면(`/device`)은 지금 받는 보기 값 `SESSION_STATE{view: THINKING}`(T19 '생각 중')을 그대로 쓴다. 판정 턴 동안 THINKING이 유지되는 것은 서버 쪽 규칙(BR3.6)이다.
- 보호자 화면(`/parent`)에는 판정 결과 · 확률이 나가지 않는다(BR2.2).
- 화면 17의 종료 근거 표시(따옴표 문구 대 사유 줄)는 지금 프런트가 상수 "무중아 그만할래"만 보이므로, `LUNA_J6` 근거를 화면까지 잇는 일은 이 단위 밖의 프런트 · 계약 작업으로 남긴다(`functional-spec.md` 열린 질문 3).
