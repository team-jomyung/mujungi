# U15 보안 검증

## 실행 경계

실제 아동 자료와 외부 유료 모델을 사용하지 않는다. 테스트의 SQL/Cypher는 파라미터로 범위를 한정하고 권한/동의/아동 격리, 개인정보·원문 4/5글자 겹침·Unicode 길이, ZIP 경로 탈출·크기·중복 충돌을 검증한다. 원문이나 거절한 AI 응답은 로그·생성 원장에 저장하지 않고 고정 검사 코드만 남긴다.

## 명령과 결과

전체 verify.sh와 U15 명령은 build-instructions.md와 동일하다. A4 패턴 검사/무시 규칙, P1 여섯 권한 거부(SQLSTATE 42501), P2 로그 비밀 값 0건, P3 추적·무시되지 않은 파일의 비밀 값 0건이 통과했다. 기본 Compose의 config/invariants/secret-env-files 정적 검사도 종료 코드 0이었다. 로컬 gitleaks 이력 스캔은 도구가 없어 CI secrets 작업 몫이며 실행했다고 표시하지 않는다. PR의 기존 보안/의존성 검사는 원격 CI에서 별도로 확인하고 통과 전 병합하지 않는다.
