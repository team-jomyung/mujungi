# U15 시간 경계 검증

## 적용 대상

이번 요구사항의 성능 목표는 NFR1 전체 그래프 조회 2초와 기존 계약의 AI 최초 마감·공유 재시도 예산이다. 운영 동시 사용자 수나 p95/가용성 목표를 새로 만들지 않는다. 후속 배포/성능 검증 단계는 이번 작업에 없으므로 필요한 로컬 경계를 이 단계에서 검증한다.

## 실행과 판정

build-instructions.md의 U15 필터가 조회 마감·취소 뒤 쓰기 없음·복구 후 재조회, 기술 재시도 1회/수정 1회/총 3회 및 최초 마감 시험을 포함한다. 전체 A1도 같은 시험을 실행한다. 모두 통과했다. 이것은 합성 지연과 실제 Testcontainers를 이용한 경계 시험이며 운영 부하 시험이나 실 AI 지연 측정이 아니다. 결과는 Target Verification Matrix의 NFR1/NFR3에 기록한다.
