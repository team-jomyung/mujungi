## 대조 결과와 설계에 넘기는 가정

- 원본 ZIP의 두 경로에 있는 skill_family_seeds.json 모두 실제 seeds 배열은 14개(S1~S10, X1~X4)다. 머리말의 X1~X3 표현은 배열과 다르므로 개수는 실제 배열을 검증한다. 원본은 수정하지 않는다.
- 생성 씨앗의 불변 문장은 기술명세서 §13의 60자 이내로 서버가 검사한다. U8 스키마의 200자는 최소 계약의 상한이므로 U15의 더 엄격한 업무 검사를 대신하지 않는다. 스키마 확장은 같은 작업에서 계약과 함께 반영한다.
- 생성 상한은 자유대화 활동당 2개, NEAR 전환 기준은 같은 씨앗·관계·자리 3회 노출이다. U15는 필요한 포트·검증을 제공하고 U14/U10이 호출 시점과 실제 노출 자료를 연결한다.
- 기존 공개 행동키 조회는 아동 정보를 읽지 않는 계약을 유지한다. 새 아동별 API에는 childId를 필수로 둔다.
- 기술명세서 §6.5에 따라 기록 삭제는 해당 기록에서 만든 씨앗을 지우고, 아동·계정 삭제는 해당 아동 그래프 전체를 지운다. 다른 기록·아동 데이터는 보존한다.
- 삭제 실패는 조회의 빈 응답과 구별하고 기존 삭제 재시도로 전달한다. 결과 삭제 순서 70 다음 그래프 삭제 80을 쓰되 FK와 출처 정리 순서를 설계에서 검증한다.
- DeletionCompleted는 상대 realtime 앱 완료 응답이다. core 그래프 삭제를 위해 그 이벤트의 counts를 확장하지 않는 방향으로 기존 코드와 대조한다.
- DB/그래프 간 부분 실패, 중복 요청, 생성과 삭제 경쟁, 끊긴 참조를 시험한다. 그래프 쓰기 실패를 생성 성공으로 처리하지 않으며 삭제된 데이터가 늦은 생성 완료로 되살아나지 않아야 한다.
- ZIP은 허용된 씨앗·어휘 파일만 읽으며 외부 평가셋/말뭉치를 적재하지 않는다. 경로 탈출·중복·손상·누락을 검증하고 실패한 적재를 완료 버전으로 표시하지 않는다.
- 기본 설정의 꺼짐과 개발·시험 메모리 대역을 구별한다. 원문·식별자·비밀은 그래프/외부 요청/로그에 유출하지 않는다. 실제 AI와 기기 검증은 이번 자동 시험의 성공 주장에 포함하지 않는다.
