# U14 시간·신뢰성 확인

## 적용 목표

별도 nfr-requirements/nfr-design 단계는 실행하지 않았다. 이 기록의 FR3.4는 총4회·5/15/30초 재시도를 요구하며 NFR5는 시간 설정의 대조를 요구한다. 신규 처리량·p95·실공급자 지연 목표는 정의되지 않아 부하 성능 합격 주장을 만들지 않는다.

## 실행과 판정

전체 backend check 및 U14 태그에 포함된 U14ResultRetryIT/U14TimingContractTest가 고정 Clock을 전진하여 재시도 수·간격·내부 중복 재시도 부재·lease를 검증한다. 장시간 실제 sleep이나 실AI 호출로 대체하지 않는다. 모듈·범위 커버리지80%는 별도 측정한다. Docker 한 턴 시간은 가짜 공급자 기준 관측이며 운영 지연 보장이 아니다.
