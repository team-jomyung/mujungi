# U13 제브 게이트 — 프런트 구성 요소

U13은 프런트(`frontend/`) 코드를 바꾸지 않는다(요구사항 범위 밖 "기기 · 프런트 변경"). 제브 검사는 서버(realtime-activity)와 외부 공급자 사이만 바꾼다.

- 기기 화면(`/device`)은 지금 받는 보기 값 `SESSION_STATE{view: THINKING}`(T19 '생각 중')을 그대로 쓴다. 제브 대기와 다시 지시 동안 THINKING이 유지되는 것은 서버 쪽 규칙(BR3.4)이다. 기기 ↔ 서버 계약(PCM16 24kHz)은 바꾸지 않는다.
- 보호자 화면(`/parent`) 12 말풍선 중계 · 27 대화 기록 · PDF는 서버가 `approved_for_display`로 걸러서 보내므로 화면 코드 변경이 없다(BR8.4). 제브 판정 · 사유는 보호자 화면에 나가지 않는다.
