# 사용자 시나리오 개정안 (요구사항 v0.8.2 반영, 2026-10-06, 워드 → 글)


음성 대화 서비스사용자 시나리오 개정안
요구사항 명세서 v0.8.2 반영  |  2026년 10월 6일
보호자가 앱에서 활동을 준비하고, 아동은 별도 음성 기기로 참여한다. 보호자는 활동 종료를 확인한 뒤 기록 메뉴에서 대화와 연습 결과를 살펴보고 다음 연습이나 전문가 상담에 활용한다.
6~12세 아동의 화용능력 지원을 우선하며, 향후 SCD 아동에게 맞는 지원으로 특화하는 방향을 유지한다. 이번 문서는 사용자 행동과 이용 흐름을 다룬다. 진단이나 치료효과를 판단하는 절차는 포함하지 않는다.

	이번 개정에 반영한 흐름

	목적 선택을 없앤다. 배경 정보와 생활 녹음은 모두 선택 사항이다.
	
결과 확인
	종료 안내에서 기록 보기 버튼을 누른 뒤 해당 활동의 기록 상세를 확인한다.
	
목표 선택
	기록 상세에서 추천으로 이동한다. 기록이 없어도 연령 기반 목표로 연습할 수 있다.
	
연습 분기
	첫 반응에 따라 도움을 생략하거나 동의 후 제공한다. 도움 후 재시도는 1회다.
	
아동 음성 제어
	종료 의도를 맥락으로 확인한다. 쉬기·재개는 적용 미정이며 건너뛰기 제어는 제공하지 않는다.
	
연결과 종료
	앱 조회 불가와 기기 대화 장애를 구분한다. 종료 요청 접수와 실제 기기 종료 확인도 구분한다.
	
일상과 상담
	생활 관찰 입력은 제외한다. 리포트는 10개 항목을 확인해 PDF로 저장하고 보호자가 직접 전달한다.
	

문서 사용 기준
화면 번호는 명세서의 01~30과 SET-01을 사용한다. 화면 13은 아동 쉬기 적용 여부가 정해지지 않은 참조 상태이며, 기술 장애 화면으로 쓰지 않는다. 정상 흐름 M01~M14, 이용 분기 B01~B09, 연결 분기 K01~K09, 보완 흐름 O01~O07을 서로 연결해 읽는다.
민준과 대화 내용은 가상 이용 사례다. 안내·기회 제시·마무리 문구는 실제 서비스의 승인 문구로 확정한다. 사례의 목표도 실행·판정 조건을 갖춘 지원 목표로 등록된 경우에만 제공한다.

1 이용자와 활동 준비
이용자
	접점과 목적
	
민준 9세
	초등학교 3학년. 경험을 문장으로 이야기한다. 별도 기기의 질문을 듣고 자신의 말로 답한다.
	
민준의 보호자
	자신의 스마트폰에서 준비·시작·상태 확인·종료·기록 열람을 한다. 학교 대화를 직접 보지 못해 아이의 설명을 듣고 싶다.
	
언어재활사
	보호자가 전달한 PDF에서 상황·반응·도움·제한사항을 확인하고 상담에 참고한다. 별도 전문가 계정은 사용하지 않는다.
	

M01  보호자가 로그인하고 아동을 선택한다
보호자는 카카오·네이버·구글 중 하나로 로그인한다(01). 처음 이용하면 아동의 이름 또는 별명, 연령, 관심사를 입력하고 확인·수정한 뒤 등록한다(02). 이미 등록했다면 이번 활동의 대상인 민준을 선택한다. 진단명이나 검사 결과는 입력하지 않는다.
민준의 등록 정보는 이후에도 02에서 수정할 수 있다. 수정하거나 다른 아동을 선택해도 기존 기록이나 진행 중 활동의 대상 아동이 바뀌지는 않는다.
연결 근거  FR-A01·A02·A04·F01 / 행동 P-01·P-02
M02  보호자가 기록과 열람 범위를 확인한다
최초 이용 시 생성형 AI 서비스 안내와 항목별 동의를 확인한다(03). 음성 수집과 전사를 위한 처리, 전사 저장, 보호자 열람은 필수다. 리포트 생성·외부 전달과 원음 보관은 선택 동의로 구분한다. 필수 항목에 동의하지 않으면 활동을 시작할 수 없다.
보호자는 “AI와 이야기하며, 이야기한 내용을 보호자가 나중에 확인할 수 있어”라는 취지의 짧은 안내를 읽고 아이에게 설명한다. 이후 스마트폰을 계속 보유하고 별도 대화 기기를 아이 가까이에 준비한다.
연결 근거  FR-A03~A05·E01 / 행동 P-23
M03  보호자가 현재 기기 상태를 확인한다
홈(04)에서 민준과 기기 상태를 확인하고 필요하면 기기 상태 화면(05·06)을 연다. 음성 대화, 기기 관리, 보호자 앱의 연결 상태와 마지막 확인 시각을 구분해 본다.
시작에 필요한 연결 준비와 이전 활동의 종료 여부가 확인되고 필수 동의가 갖춰져야 새 활동을 시작한다. 상태가 오래되었거나 확인되지 않으면 다시 확인하거나 준비를 취소한다. 이미 활동 중이면 그 활동의 상태로 이동한다.

2 자유대화를 준비하고 시작한다
시작 상황: 민준은 학교에서 돌아와 “오늘 친구가 나한테 그 얘기 그만하고 싶다고 했어”라고 말한다. 보호자는 실제 대화 순서나 친구의 생각, 그 뒤 민준의 반응은 아직 모른다.
M04  보호자가 아는 내용을 선택적으로 입력한다
보호자는 자유대화 메뉴에서 자유대화 시작하기를 누른다(07). 별도의 목적 선택 없이 배경 정보 입력으로 이동한다(08). 이번에는 학교에서 친구와 나눈 대화, 알고 있는 내용, 궁금한 내용과 정보 출처를 입력한다.

보호자는 입력한 내용과 출처를 확인하고 필요하면 수정·삭제한다. 모든 항목을 비워 두고 넘어가도 된다. “공감 부족” 같은 평가를 입력하도록 요구하지 않는다.
M05  녹음 첨부 여부와 시작 준비를 확인한다
생활 대화 녹음 추가(09)에서는 이번에 파일을 첨부하지 않고 건너뛴다. 시작 준비(10)에서 배경 정보, 녹음 미첨부, 기기 상태와 동의를 확인한다. 배경과 녹음이 모두 없어도 필수 시작 조건이 충족되면 시작할 수 있다.
시작을 요청하기 전에는 준비를 취소할 수 있다. 생활 녹음을 첨부하는 경로의 동의 조건과 출처 구분은 O02를 따른다.
연결 근거  FR-A03·A06·B04·B05 / 행동 P-06·P-08·P-25
M06  보호자가 시작하고 아동이 참여 의사를 말한다
보호자가 앱에서 시작을 요청한다. 앱은 요청이 접수된 상태와 기기에서 안내가 실제 시작된 상태를 구분한다(11). 확인 전에는 “시작 요청됨·실행 확인 중”으로 표시한다. 기기 안내가 확인되면 아동이 참여 의사를 표현한다.
AI: “안녕, 민준아. 나는 이야기를 나누는 AI야. 오늘은 일상에서 있었던 일을 이야기해볼 거야. 네 말은 기록되고 보호자가 나중에 볼 수 있어. 그만하고 싶으면 ‘끼리꼬야 그만할래’라고 말해줘. 지금 이야기해볼래?”민준: “응, 이야기할래.”
종료 표현은 안내용 예시이며 정확히 외워야 하는 암호가 아니다. 쉬기·건너뛰기·재개 명령은 시작 안내에 넣지 않는다. 참여하지 않는 경우는 B03으로 분기한다.
연결 근거  FR-B05·B06·E01·E02·E05·F02 / 행동 P-08·C-F-01~03
3 경험을 이야기하고 기록을 확인한다
M07  민준이 기기와 경험을 이야기하고 마친다
기기는 보호자 입력을 직접 언급하지 않고 일상 질문으로 시작한다. 한 번에 하나씩 묻고, 민준이 다른 이야기를 하더라도 특정 사건을 계속 추궁하지 않는다.
AI: “오늘 학교에서 기억나는 일이 있어?”민준: “친구가 발표를 망쳤다고 했어.”AI: “그 말을 듣고 너는 뭐라고 이야기했어?”민준: “다음에는 더 연습하라고 했어.”AI: “그다음에는 어떤 이야기를 했어?”민준: “친구가 너무 떨렸다고 했어. 그래서 연습하는 방법을 알려주려고 했어.”AI: “그랬더니 친구가 뭐라고 했어?”민준: “‘그 얘기 그만하고 싶어’라고 했어.”AI: “그 말을 듣고 너는 어떻게 했어?”민준: “왜 그러냐고 했어. 나는 도와주려고 한 건데.”
민준은 듣지 못한 말을 다시 요청하거나 천천히 말해 달라고 할 수 있다. 스마트폰 질문·자막·마이크 버튼은 사용하지 않는다. 보호자는 필요할 때 진행 상태와 확인 시각만 본다(12). 실시간 대화 원문이나 다음 질문 조작은 제공하지 않는다.
대화가 정상적으로 마무리되면 기기는 승인된 마무리 문구를 1회 들려준다. 먼저 그만하고 싶다면 민준이 말로 종료 의사를 표현할 수 있다(B06). 정상 종료가 확인된 뒤 보호자 앱에 종료 안내(17)가 표시된다. 이 화면에는 대화 요약이나 추천 목표를 바로 보여주지 않는다.

M08  보호자가 해당 자유대화 기록을 확인한다
보호자는 17의 오늘 자유대화 기록 보기를 눌러 기록 탭의 해당 세션 상세(27)로 이동한다. 기록 정리 중이면 준비 상태를 확인하고 나중에 다시 볼 수 있다. 기록이 준비되어도 상세 화면으로 자동 이동하지 않는다.
구분
	기록 상세에 표시할 예시
	
아동의 설명
	민준은 친구에게 연습 방법을 이야기했다고 설명했다. 친구가 중단을 요청했다고 회상하며 “나는 도와주려고 한 건데”라고 말했다.
	
출처
	보호자 입력: 아이에게 들은 내용. 활동 중 발화: 민준이 기기와 대화하며 회상한 내용.
	
미확인 내용
	실제 학교 대화 전체와 친구의 생각은 확인하지 못했다. 민준의 설명을 실제 학교 대화의 직접 녹음으로 취급하지 않는다.

4 별도 연습에서 목표를 선택한다
M09  보호자가 추천 근거를 보고 연습 목표를 고른다
보호자는 자유대화 기록 상세(27)에서 이 기록을 바탕으로 연습 목표 추천 보기를 눌러 연습 메뉴(18)로 이동한다. 예시 후보는 “상대의 중단 요청을 확인하고 반응 바꾸기”와 “상대가 원하는 도움을 물어보기”다. 추천 이유는 실제 기록의 발화·맥락과 연결된다.
보호자는 민준과 상의해 첫 번째 목표를 선택하거나 다른 목표 선택(19)에서 서비스가 지원하는 목표를 고른다. 추천을 반드시 따를 필요는 없고 선택을 보류할 수도 있다. 지원 조건이 갖춰지지 않은 목표는 목록에 나타나지 않는다.
목표를 선택해도 기기가 연습을 시작하지 않는다. 이번에는 자유대화만 마치고 돌아간다. 다음 이용 때는 별도 연습 메뉴에서 목표를 다시 확인·선택한 뒤 준비한다. 같은 목표를 반복할 때도 선택과 시작 절차를 거친다.
연결 근거  FR-C01·C02·D02·D04·F06·F19 / 행동 P-10~P-12·P-20
M10  연습 준비를 확인하고 기기의 안내를 듣는다
보호자는 연습 시작 준비(20)에서 선택한 목표, 필수 동의, 현재 기기의 시작 가능 상태와 이전 활동 종료 여부를 확인한다. 개별 연습 상황이나 대본을 읽고 승인하는 단계는 없다.
시작을 요청하면 기기 실행 확인과 안내·참여 확인(11)을 거쳐 연습 진행(21)으로 이어진다. 상황 준비가 실패해 제공 조건을 충족하지 못하면 시작되지 않고 안내를 확인한다(O03).
보호자는 필요하면 21의 타임라인과 확인된 현재 단계인 첫 반응, 도움·재시도, 새 상황, 마무리를 확인한다. 다음 단계·건너뛰기를 직접 조작하지 않는다. 타임라인의 색은 음성·연결 상태를 뜻하며 아동의 능력이나 목표 달성 여부를 평가하지 않는다.

9 연결 상태가 달라졌을 때

앱을 다시 열면 같은 아동·세션의 최신 상태와 실제 확보된 이력을 확인한다. 이미 종료됐다면 그 종료 상태를 보며 새 활동이 중복으로 시작되지 않는다.
