# 무중 화면 설계 v1.5j — 화면과 분기 (글 판)

그림은 같은 폴더의 무중_화면설계_v1.5j.pdf. 카드 머리의 S-xx가 화면 ID다. 차선(LANE)은 흐름 묶음이고 카드 아래 분기표가 단추마다 어디로 가는지다.

## LANE 1 · 처음 한 번과 홈
흐름: 01(S-01) → 02(S-02) → 03(S-03) → 04(S-04) → SET0(S-SET0)

### S-01 · 01 보호자 로그인
보호자가 구글 계정으로 들어온다. 로그인 상태는 유지한다.

상태: 대기 / 인증 중 / 취소 · 실패

**분기(단추 · 사건 → 어디로)**

| 단추 · 사건 | → |
|---|---|
| 「구글로 시작」 성공 · 첫 로그인(동의 없음) | 02 |
| 「구글로 시작」 성공 · 동의 있음 · 아이 등록됨 | 04 |
| 「구글로 시작」 성공 · 동의 있음 · 아이 등록 안 됨 | 03 (처음 등록) |
| 취소 · 실패 | 01 다시 |
| 02 · 03을 끝내지 않고 종료 | 다음 실행 01부터 |
| 로그인 유지 토큰 만료 → 재로그인 | 04 (진행 중이면 지금 활동 칸에 보임) |

### S-02 · 02 기록 · 동의 안내
처음 한 번 4항목 전부 필수 동의. 바꾸거나 거두는 화면은 없다(거두려면 계정 삭제).

상태: 첫 동의(4항목 전부 필수) / 네 개 다 체크 전(단추 꺼짐)

**분기(단추 · 사건 → 어디로)**

| 단추 · 사건 | → |
|---|---|
| 항목의 「자세히 보기」 | 02-1 약관 시트 |
| 네 항목 모두 체크 → 「동의하고 계속」 | 03 (처음 등록) |
| 02를 끝내지 않고 종료 | 다음 실행 01 → 02 |
| 「←」 · 뒤로가기 (동의 전) | P5 |

### S-03 · 03 아이 정보 (처음 등록 · 보기 · 수정)
아이 정보 한 화면. 계정당 아이 하나라 선택 · 추가 · 삭제가 없다. 처음엔 빈 입력 카드(등록), 그 뒤엔 보기 카드 + 「정보 수정」(카드 안 편집). 아이를 바꾸려면 계정 삭제(P7) 뒤 새로.

상태: 처음 등록(빈 입력 카드 · 뒤로 없음) / 보기(카드 + 기기 상태 줄) / 수정 중(카드 안에서) / 저장 실패(이전 값 유지)

**분기(단추 · 사건 → 어디로)**

| 단추 · 사건 | → |
|---|---|
| 처음 등록 · 이름 · 나이 · 관심사 넣고 「확인」 | 04 (기기 칸이 「기기 등록」 안내) |
| 처음 등록 · 「←」 · 뒤로가기 | 없음 (등록을 마쳐야 넘어감) |
| 「정보 수정」 → 글자 수정 → 「확인」 | 03 (바뀐 내용) |
| 「정보 수정」 → 「취소」 | 03 (원래 내용) |
| 이름 비면 「확인」 꺼짐 · 나이 6~12 밖이면 오류 글 | 03 (입력 상태 유지) |
| 저장 실패 | 토스트 · 이전 값 유지 (03) |
| 「←」 (보기 · 수정 중) | 04 (수정 중이면 「취소」와 같음) |
| 아이를 바꾸려면 | 설정 → 계정 삭제(P7) 뒤 새로 (아이 교체 없음 · 기록이 섞이지 않게) |

## LANE 2 · 기기 (등록 · 종료 표현)
흐름: 05(S-05) → 05a(S-05A) → SET1(S-SET1)

### S-05 · 05 우리 집 기기 (두 줄 + 판정 카드)
우리 집 기기. 서로 독립인 두 줄(기기 등록 · 기기 네트워크 현황)과 둘을 합쳐 한 문장으로 말하는 판정 카드, 종료 표현 입구. 조합은 행별 상태 표. 보호자 폰 인터넷은 따로 보이지 않는다(공통 오류 토스트).

상태: 두 줄은 서로 독립 · 조합은 아래 표 / 판정 카드 = 두 줄로 계산(04 탭 잠금과 같은 규칙) / 보호자 폰 인터넷은 따로 안 보임(공통 오류 토스트)

**구역별 상태**

| 구역 · 요소 | 상태 · 조작 | 보이는 것 · 결과 | → |
|---|---|---|---|
| 기기 등록 | 없음 | 기기 등록 · 없음 · 판정 카드에 「기기 등록」 · 탭 잠김 | 05a |
| 기기 등록 | 완료 | 완료 (7F3K) | — |
| 기기 네트워크 | 등록 뒤 표시(회색) | 등록 전엔 비어 있음 | — |
| 기기 네트워크 | 안정(초록) | 안정 · 지연 0.3초 · 판정: 시작할 준비가 되었어요 | — |
| 기기 네트워크 | 불안정(노랑) | 불안정 · 끊김 n회 · 지연 n초 · 판정: 지금은 시작할 수 없어요 + 공유기 가까이 · 탭 잠김 | — |
| 기기 네트워크 | 끊김(빨강) | 끊김 · hh:mm부터 · 판정: 지금은 시작할 수 없어요 + 전원 · 와이파이 확인 · 탭 잠김 | — |
| 기기 네트워크 | 응답 없음(회색) | 응답 없음 · 마지막 hh:mm · 판정: 지금은 시작할 수 없어요 + 기기를 다시 켜 보세요 · 탭 잠김 | — |
