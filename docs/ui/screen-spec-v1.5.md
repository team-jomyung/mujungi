# 화면 설계 최종안 v1.5 적용

기준: 사용자가 제공한 `무중_화면설계_최종안_v1.5 (1).html`의 `.phone` 내부 CSS.
시작점: main `76f7a931`, 작업 브랜치 `feat/ui-screen-spec-v1-5`.

## 적용 범위

- 공통 색상: 파랑 `#2f5bea`, 페이지 배경 `#f3f5f9`, 흰 카드, 선 `#e3e7ef`, 본문 `#1b1f2a`.
- 카드 12px, 버튼·입력창 10px, 팝업 16px, 바텀 시트 상단 22px와 그림자.
- 로그인 배치·AI 안내, 하단 탭 아이콘, 선택 칩, 목표 카드, 말풍선, 상태별 배경.
- 기록·리포트의 선택 탭과 달력. 기간 중간은 연한 파랑, 양 끝은 진한 파랑.
- 기록 장면 칩의 클래스 분리: 자유대화 입력 칩에 기록용 스타일이 섞이지 않도록 수정.
- 아이 기기의 상태 배경도 같은 토큰 사용. 기기 상태 처리·오디오·통신 로직은 유지.

문서의 주황색 설명 영역·상태 바·홈 인디케이터, 고정 300×640 크기와 축소 배율은 앱에 적용하지 않았다. 스마트폰 테두리는 아래의 반응형 데스크톱 프레임으로 별도 구현했다.
본문 16px·보조 14px, 보호자 터치 44px 이상·기기 터치 72px 이상, 글자 확대·키보드 초점·모션 감소 처리를 유지한다.
440px 이하의 등록 코드 입력은 4자리씩 두 줄로 배치해 터치 영역을 보존한다.

## 검증

Ubuntu의 별도 검증 사본에서 실제 키가 든 환경 파일을 복사하지 않고 실행했다.

- `npm run typecheck`, `npm run lint`, `npm run build` 성공.
- `npx vitest run --coverage`: 74개 파일, 994개 시험 통과. 줄 커버리지 98.56%.
- 달력의 기간 표시를 마무리한 뒤 관련 기록·리포트 시험 31개를 추가 재실행해 통과했다.
- Edge/Chromium 실제 브라우저: 로그인·홈·자유대화·연습·기록·기기 등록·리포트 기간 선택을 320/390/768/1440px에서 확인. 28개 조합 모두 가로 넘침 없음.
- 같은 7개 화면을 320px에서 글자 200% 확대해 가로 넘침 없음 확인.
- 설정 시트 Escape 닫기·초점 복귀, 자유대화 칩 선택, 연습 목표 선택, 빈 리포트 생성 비활성화, 등록 코드 자동 초점 이동, 키보드 초점 표시, 종료 팝업 닫기를 확인.
- 대화의 양쪽 말풍선, 아이 정보, 아이 기기 코드 화면도 합성 응답으로 렌더링 확인. 브라우저 실행 오류 없음.
- web Docker 이미지 빌드 성공. `mujoong-google-local`의 web만 새 이미지로 교체한 뒤 6개 서비스 모두 healthy 확인.
- 실제 HTTPS 주소에서 글꼴 200 응답(2,057,688바이트), Google 시작 경로 302 → `accounts.google.com`, 설정 시트 초점 복귀를 확인.

API·로그인 경로·요청 본문·저장소·DB는 변경하지 않았다. 브라우저 검증은 합성 데이터로 진행했으며 실제 Google 계정 로그인과 유료 AI 호출은 이번 검증에 포함하지 않았다.
로컬 증빙은 `build/ui-v1.5/`에 보관하며 환경 파일·인증서·API 키는 커밋하지 않는다.
로컬 실행에는 기존 Google OAuth 구성에 `build/ui-v1.5/compose.web-preview.yml`을 마지막으로 덧붙였다. 로컬 개발 기동 스크립트도 이 파일이 있으면 같은 web 이미지 override를 유지하도록 연결했다. 이 로컬 실행 파일들은 버전 관리 대상이 아니다.

## 기본 스마트폰 프레임과 숨기기 설정

별도 환경 설정 없이 보호자 화면에 스마트폰 테두리를 기본 표시한다. 웹 서버 환경에 `MUJOONG_PHONE_PREVIEW=false`를 명시하면 숨긴다. `true`를 명시해도 기본값과 같이 표시한다. 설정은 서버 기동 환경에서 읽으므로 바꾼 뒤 웹 서버를 다시 시작한다.

너비 560px·높이 640px 이상에서만 4px 두께의 둥근 어두운 테두리와 그림자를 표시하고, 화면 내부를 스크롤한다. 모바일·작은 창에서는 설정에 관계없이 기존 전체 화면을 유지한다. 안쪽 너비는 기존 480px을 유지한다.

글자·터치 크기나 화면 배율은 줄이지 않는다. 하단 탭·팝업·설정 시트·토스트 위치를 프레임에 맞추며, 아이 기기 화면·API·로그인·음성 연결·보안 헤더는 변경하지 않는다. iframe 허용을 위해 보안 정책을 완화하는 방식은 쓰지 않는다.

### 2026-10-20 확정·병합 검증

- 최신 main `78e62c9`와 CSS 브랜치를 합친 소스에서 타입 검사·린트·빌드 성공. 프런트 74개 파일·994개 시험 통과, 줄 커버리지 98.56%.
- 확정 프레임은 8px에서 4px로 줄였고 하단 탭의 안쪽 곡률·여백을 맞췄다. 고정 탭·스크롤바 위에 장식 테두리를 그려 모서리가 끊기는 현상을 보완했다. 장식은 클릭을 가로채지 않는다.

- 최초 반영은 선택 활성화 방식이었으나, 확정 디자인을 팀원도 바로 볼 수 있도록 기본 표시·명시적 false 숨김으로 변경했다. 기존 모바일 미디어 조건·테두리 굵기·하단 여백은 그대로 유지했다. 로컬 개인 env·인증서·브라우저 화면 이미지는 커밋하지 않는다.
