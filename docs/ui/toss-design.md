# 보호자 웹 덮개 「말랑 파스텔」

보호자 웹(/parent)의 생김새를 따뜻한 파스텔로 바꾼다. 화면 구조 · 문구 · 접근성 규칙(화면 설계 v1.5j)은 그대로 둔다. 토스 디자인 시스템(TDS)의 큰 단추 · 회색 채움 입력 · 눌림 축소 관례를 빌려 왔다.

## 바뀌는 곳

- `frontend/src/shared/styles/tokens.css` — 색 · 곡률 토큰 값
- `frontend/src/shared/styles/toss.css` — 덮개 전체. `app/parent/layout.tsx`에서 맨 마지막에 불러온다. 되돌리려면 이 import 한 줄을 지운다.
- `frontend/public/brand/mujoong-character.png` — 무중 오리 캐릭터(320px, 원형으로 잘라 씀)
- 로그인(S-01)의 「생성형 AI를 사용하는 서비스예요.」 안내를 지웠다(화면 설계 v1.5e의 01 AI 고지 글 삭제와 같음).
- `/device`(아이 기기)는 손대지 않는다.

## 색

| 역할 | 값 |
|---|---|
| 바탕 | `#FFF8F1` 크림 |
| 채움(입력 · 칩) | `#FFF1E6` |
| 주 단추 면 | `#D9472A` (흰 글자 대비 4.5:1 이상) |
| 글자 · 링크 강조 | `#C8432A` |
| 로그인 브랜드 글자 | `#E5502F` (큰 글자) |
| 선택 바탕 | `#FFE9E2` |
| 제목 글 | `#3D2A22`, 보조 글 `#9A7F72` |

밝은 코랄 `#FF6B4A`는 흰 글자 대비가 2.9:1이라 글자 · 단추 면에 쓰지 않는다.

## 모양

- 카드: 흰 면, 곡률 28px, 옅은 코랄 그림자. 판정 카드는 곡률 22px, 그림자 없음
- 정보 위계: 카드 라벨은 13px 코랄, 값(아이 이름 · 기기 상태 · 활동 상태)은 22px 굵게
- 단추: 높이 56px, 곡률 22px, 주 단추는 코랄 그림자, 눌림 때 0.97배 축소. 화면 끝 주 단추는 하단 탭 위에 붙어 따라온다(sticky)
- 입력: 흰 면 + 옅은 코랄 테두리, 초점 때 주 색 테두리. 칩은 알약 모양
- 하단 탭: 집 · 말풍선 · 별 · 달력 선 아이콘(CSS mask), 선택 탭은 코랄 알약 배경
- 로그인: 캐릭터 · 브랜드 · 소개 · 시작 단추를 가운데에 모은다
- 빈 상태: 진행 중인 활동이 없으면 카드 오른쪽에 캐릭터

## 지키는 것

터치 영역 44px 이상, 보이는 초점 2px, 상태 색은 점 · 바탕 · 테두리에만 쓴다(AC1.4.15).
