# personas.md (초안)

> 초안. 화면 설계 v1.5j(2026-10-08)와 개발 명세 1008에서 뽑았다. AI-DLC Edit File 모드에서 붙여넣기용이며 번호 · 절 구성은 AI-DLC가 다시 매긴다. 화면 설계가 기준이다.

## 보호자 (주 사용자)
- 6~12세 아이 한 명을 둔 보호자. 폰 웹(Next.js /parent)으로 쓴다. 구글 계정 하나로 로그인.
- 원하는 것: 아이와 AI의 대화를 준비하고(배경 네 칸), 진행을 보고, 끝낸 뒤 기록 · 생활 팁 · 연습 목표 후보를 보고, 상담용 리포트(대화 원문 PDF)를 전문가에게 직접 전달.
- 하지 않는 것: 아이 여러 명 관리, 동의 항목 선택, 기록 부분 삭제, 기기 해제. 아이를 바꾸려면 계정 삭제 뒤 새로.

## 아이 (기기 쪽 사용자)
- 6~12세. 화면 없는 음성 기기(지금은 웹 /device로 대체). 조작은 「켜기」 뿐. 말로 참여하고 "무중아 그만할래"로 끝낸다.
- 보호 규칙: 평가 · 판단을 유도하는 입력란 없음(FR-B02), 승인된 안내 문구만, 정답 직접 제시 금지(Cue).

## 운영자 (데모 준비)
- 데모용 기기 준비, 시드 데이터, 배포. 화면은 없다.
