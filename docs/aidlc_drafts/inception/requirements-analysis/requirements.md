# requirements.md (초안)

> 초안. 화면 설계 v1.5j(2026-10-08)와 개발 명세 1008에서 뽑았다. AI-DLC Edit File 모드에서 붙여넣기용이며 번호 · 절 구성은 AI-DLC가 다시 매긴다. 화면 설계가 기준이다.


## 의도
6~12세 아이의 화용 능력(상황에 맞게 말하기)을 집에서 돕는 AI 음성 대화 서비스. 보호자는 폰 웹에서 활동을 준비 · 관찰 · 기록하고, 아이는 별도 음성 기기에서 AI '무중'과 자유대화 · 연습을 한다. 결과는 대화 기록 · 생활 팁 · 연습 목표 후보로 돌아오고, 상담용 리포트는 대화 원문 PDF다. 진단 · 치료 효과 판단은 하지 않는다.
