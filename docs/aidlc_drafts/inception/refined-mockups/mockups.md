### S-03 · 03 아이 정보 (처음 등록 · 보기 · 수정)
목적: 아이 정보 한 화면. 계정당 아이 하나라 선택 · 추가 · 삭제가 없다. 처음엔 빈 입력 카드(등록), 그 뒤엔 보기 카드 + 「정보 수정」(카드 안 편집). 아이를 바꾸려면 계정 삭제(P7) 뒤 새로.

그림 변형 · 상태: 처음 등록(빈 입력 카드 · 뒤로 없음) / 보기(카드 + 기기 상태 줄) / 수정 중(카드 안에서) / 저장 실패(이전 값 유지)

## LANE 2 · 기기 (등록 · 종료 표현)

### S-05 · 05 우리 집 기기 (두 줄 + 판정 카드)
목적: 우리 집 기기. 서로 독립인 두 줄(기기 등록 · 기기 네트워크 현황)과 둘을 합쳐 한 문장으로 말하는 판정 카드, 종료 표현 입구. 조합은 행별 상태 표. 보호자 폰 인터넷은 따로 보이지 않는다(공통 오류 토스트).

그림 변형 · 상태: 두 줄은 서로 독립 · 조합은 아래 표 / 판정 카드 = 두 줄로 계산(04 탭 잠금과 같은 규칙) / 보호자 폰 인터넷은 따로 안 보임(공통 오류 토스트)

**구역별 상태**
| 구역 · 요소 | 상태 · 조작 | 보이는 것 · 결과 | → |
|---|---|---|---|
| 기기 등록 | 없음 | 기기 등록 · 없음 · 판정 카드에 「기기 등록」 · 탭 잠김 | 05a |
| 기기 등록 | 완료 | 완료 (7F3K) | — |
| 기기 네트워크 | 등록 뒤 표시(회색) | 등록 전엔 비어 있음 | — |
| 기기 네트워크 | 안정(초록) | 안정 · 지연 0.3초 · 판정: 시작할 준비가 되었어요 | — |
| 기기 네트워크 | 불안정(노랑) | 불안정 · 끊김 n회 · 지연 n초 · 판정: 지금은 시작할 수 없어요 + 공유기 가까이 · 탭 잠김 | — |
| 기기 네트워크 | 끊김(빨강) | 끊김 · hh:mm부터 · 판정: 지금은 시작할 수 없어요 + 전원 · 와이파이 확인 · 탭 잠김 | — |
| 기기 네트워크 | 응답 없음(회색) | 응답 없음 · 마지막 hh:mm · 판정: 지금은 시작할 수 없어요 + 기기를 다시 켜 보세요 · 탭 잠김 | — |
| 판정 카드 | 두 줄 합산 | 등록 없음 → 기기 등록 / 안정 → 시작할 준비 / 그 밖엔 → 지금은 시작할 수 없어요 + 사유 | — |

**요소**
| 요소 ID | 종류 | 표시 | 누르면 |
|---|---|---|---|
| ROW-REG | 줄 | 기기 등록(없음 · 완료) |  |
