# interaction-spec.md (초안)

> 초안. 화면 설계 v1.5j(2026-10-08)와 개발 명세 1008에서 뽑았다. AI-DLC Edit File 모드에서 붙여넣기용이며 번호 · 절 구성은 AI-DLC가 다시 매긴다. 화면 설계가 기준이다.


## 공통 규칙
- 오류 · 로딩: API 실패 · 네트워크 끊김은 화면 아래 토스트 '연결이 원활하지 않아요' + 「다시 시도」. 로딩 중엔 단추를 흐리게. 스켈레톤 없음.
- 탭 잠금: 홈의 대화 기기 칸이 안정(초록)이 아니면 자유대화 · 연습 탭 잠김. 잠긴 탭을 누르면 이유 토스트 → 05. 진행 중 활동이 있으면 두 탭 모두 → 12.
- 끝내기: 「끝내기」 → P1 → 17 마무리 중(기기가 인사하고 멈추는 1~3초) → 정리 중 → 정리 끝. 30초 안에 기기 확인이 없으면 서버가 끝낸 것으로 처리(보호자 단추 없음).
- 자동 종료: 공백 4분이면 '2분 더 말이 없으면 끝나요', 6분이면 SILENCE. 아이 종료 표현(기본 '무중아 그만할래' + 추가 최대 5개)이면 CHILD_STOP.
- 연결 끊김: 자동 재연결, 40초 넘으면 P2 → 17(사유 연결 끊김).
- 리포트: AI 요약 · 평가 없이 아이 정보 + 날짜별 대화 원문 PDF. 28 범위 → 만드는 중(몇 초) → 30 저장 전 확인 → 저장 · 공유.
- 동의: 4항목 전부 필수, 변경 · 철회 화면 없음. 약관 버전 개정 시 다음 실행에 재동의.
- 로그인 유지: 토큰 만료 → 01 → 재로그인 → 04. 알림 진입: 푸시를 누르면 04가 최신 세션 재조회 → 12 / 17.
