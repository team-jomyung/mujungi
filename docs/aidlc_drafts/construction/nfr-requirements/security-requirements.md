# security-requirements.md (초안)

> 초안. 화면 설계 v1.5j(2026-10-08)와 개발 명세 1008에서 뽑았다. AI-DLC Edit File 모드에서 붙여넣기용이며 번호 · 절 구성은 AI-DLC가 다시 매긴다. 화면 설계가 기준이다.

- 인증: 구글 OAuth 하나. 서버 세션(Spring Session JDBC) + HttpOnly 쿠키 + CSRF. 토큰 만료 → 01 → 재로그인 → 04.
- 권한: 보호자는 자기 계정의 아이 · 기기 · 기록만. 전문가 · 공동 보호자 계정 없음.
- 동의: 4항목 전부 필수. 활동 시작마다 현재 동의 재확인. 약관 버전(policy_version) 개정 시 재동의.
- 아이 데이터: 전사 · (화면 기준) 원음은 계정 삭제까지 보관. 삭제는 core_data_deletion_request로 접수하고 처리 완료를 알림. 리포트는 보호자가 직접 전달하며 앱이 자동 전송하지 않는다.
- 기기: 기기 토큰으로 WSS 접속(화면 기준). 코드 8자리는 1회용 · 만료. 기기 해제 없음(계정 삭제 때 풀림).
- AI 안전: 출력 게이트(분할 → 전사 → 검사 → 승인 음성만), 승인된 안내 문구, 정답 직접 제시 금지, 보호자 원문 · 판정 기준은 대화 모델에 전달하지 않음.
- 비밀: 키는 환경 변수. 저장소 · 로그 · 문서에 계정 비밀번호 · API 키 금지. 원음 · 전사 원문은 일반 로그에 남기지 않음.
