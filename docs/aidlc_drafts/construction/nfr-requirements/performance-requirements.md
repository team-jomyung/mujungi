# performance-requirements.md (초안)

> 초안. 화면 설계 v1.5j(2026-10-08)와 개발 명세 1008에서 뽑았다. AI-DLC Edit File 모드에서 붙여넣기용이며 번호 · 절 구성은 AI-DLC가 다시 매긴다. 화면 설계가 기준이다.


수치는 목표가 아니라 측정 항목이다(ADR은 수치 미정, 11/2 측정). 화면 설계의 시간 규칙은 사용자 경험 규칙이라 유지한다.

|---|---|---|---|

## 시간 규칙(화면)
- 시작 때 기기 응답 없음 20초 → 08 · 18로 돌아감.
- 참여 대기 무응답 → P3(기록 없음). 공백 4분 경고 · 6분 자동 종료.
- 끝내기 뒤 기기 멈춤 확인 30초. 연결 끊김 재연결 40초 → P2.
- 리포트 만들기 몇 초(배경 진행 없음). 결과 정리는 종료 뒤 60초 안 READY(TS-N08).
