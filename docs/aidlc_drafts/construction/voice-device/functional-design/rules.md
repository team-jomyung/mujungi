# rules.md (초안) · Unit `voice-device`

> 초안. 화면 설계 v1.5j(2026-10-08)와 개발 명세 1008에서 뽑았다. AI-DLC Edit File 모드에서 붙여넣기용이며 번호 · 절 구성은 AI-DLC가 다시 매긴다. 화면 설계가 기준이다.


화면 설계의 분기표와 상태 표가 그대로 업무 규칙이다. 한 줄이 테스트 한 건(개발명세 TS)이다.

## D-00 · D0 아이 기기 웹 · 처음 켜기
상태: 코드 표시 / 등록 대기 / 등록되었어요(3초)

**분기**
| 단추 · 사건 | → |
|---|---|
| 보호자가 등록을 마치면 | T19 대기 |
| 브라우저 데이터 삭제 → 새 코드 | D0 (보호자 다시 등록, 옛 Device 행 해제) |

## D-19 · T19 아이 기기 웹 · 상태 화면
상태: 꺼짐 → 「켜기」 / 대기 / 듣는 중 / 생각 중 / 말하는 중 / 마무리 → 대기(자동) / 연결 끊김 · 다시 연결 중 / 마이크 허용 안 됨 / 화면 켜짐 유지(Wake Lock)

**분기**
| 단추 · 사건 | → |
|---|---|
| 「켜기」 (마이크 · 소리 허용 → 기기 연결) | 대기 |
| 「끄기」 | 꺼짐 (기기 연결 끊김) |
| 보호자가 활동 시작 | 대기 → 듣는 중 ~ |
| 아이 종료 표현 · 보호자 끝내기 | 마무리 → 대기 |
| 연결 끊김 · 복구 | 대기 |
| 브라우저 데이터 삭제 · 다른 기기 | D0 (다시 등록) |
| 마이크 · 소리 허용 거부 | 마이크 허용 안 됨 → 「켜기」 다시 |
| 탭이 뒤로 가거나 화면 꺼짐 | 연결 유지 시도 → 끊기면 다시 연결 중 |
