# 보호자 입력을 자유대화 전·후에 활용하는 방식

## 바뀐 동작

아이의 이름·나이·관심사는 기존처럼 대화 시작 시 전달됩니다. 여기에 보호자가 입력한 배경을 제한된 주제와 출처로 변환하여 참고합니다. 예를 들어 “친구가 그만하라고 했는데 계속 블록을 쌓았다고 들었어요”는 블록 놀이·친구·아이에게 들음으로 전달됩니다. 원문이나 특정 행동에 대한 주장은 전달하지 않습니다.

AI는 “블록 놀이에 대해 이야기해 줄래?” 같은 중립적인 질문을 사용합니다. 보호자가 알려 주었다고 밝히거나 답을 강요하지 않고 아이가 다른 이야기를 시작하면 따라갑니다. 고정된 주제 목록에 없는 내용은 일반적인 일상 질문으로 이어집니다. 주제 추출은 키워드 방식이므로 모든 자유 서술의 뜻을 이해하지는 않습니다.

대화 후 분석에서는 개인정보를 정리한 보호자 원문과 실제 아이 발화를 함께 사용합니다. 보호자 정보와 아이가 직접 말한 내용은 별도로 표시합니다. 보호자의 궁금한 점은 사건의 증거로 쓰지 않습니다. 실제 아이 발화가 없거나 불확실하면 아이가 말했다고 저장하지 않습니다. 문장 항목은 출처 문장의 일부로 확인되는 내용만 보관하므로, 뜻이 비슷해도 AI가 바꿔 쓴 문장은 제외될 수 있습니다.

## 유지되는 부분

- GPT-Live·Jev·음성 안전 검사와 참여 확인을 유지합니다.
- 연습대화에는 보호자 배경 주제를 추가하지 않습니다.
- 자유대화 결과에서 목표를 확인하고 담은 뒤 연습을 시작하는 기존 흐름을 유지합니다.
- 데이터베이스 구조나 기존 데이터를 초기화하지 않습니다.
- AWS Terraform을 변경하지 않습니다.

## 확인할 화면

기기 화면을 켜고 보호자 화면의 자유대화 입력에서 배경·출처·궁금한 점을 입력한 뒤 시작합니다. 참여 확인에 대답하고 주제 관련 중립 질문이 나오는지 확인합니다. 짧은 “응”만으로 분석 자료가 충분해지지는 않으므로 실제 내용을 여러 문장 말한 뒤 종료하고 기록을 확인합니다. 보호자 진술과 아이 발화를 같은 사실로 합쳐 표시하지 않는지 살펴봅니다.

자동 시험은 내부 전달 값·실제 WebSocket 요청·출처 검증·화면 안내를 검증합니다. 실제 모델이 매번 어떤 질문을 하는지와 실제 마이크·스피커 동작은 별도 사용자 확인이 필요합니다.
