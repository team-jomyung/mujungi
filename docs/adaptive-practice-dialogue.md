# 상황 반응 조절형 연습대화 적용 설명

시작 목표·범위 안내, 수행 사실에 근거한 마무리, 회차당 최대 3개 선택 보완은 [연습 시작 안내와 행동 돌아보기](practice-goal-opening-and-recap.md)에 정리했다.

이 문서는 2026-10-22 사용자가 제시한 설계를 현재 구현에 반영한 내용을 설명한다. 이전 `flexible-practice-dialogue.md`의 작업 이력보다 이 문서를 현재 동작의 기준으로 본다.

## 아이가 경험하는 흐름

참여 확인 → 선택적 이전 대화 돌아보기 → 짧은 새 상황 안내와 상대의 첫 대사 → 아이 반응에 맞춘 역할 대화 → 필요한 도움만 제공 → 상황 복귀·마무리 → 동의와 시간에 따라 변형 또는 종료 → 기록 저장.

돌아보기는 목표의 근거가 된 실제 아이 발화가 확인될 때만 제안한다. 아이가 동의하면 검토를 통과한 질문을 한 번 들려주고 이야기를 듣는다. 기억·답변 내용에 점수를 매기거나 목표 수행으로 판정하지 않는다. 거절, “바로 연습할래”, 불확실한 동의, 무응답 때는 건너뛴다. 보호자 메모나 가상 장면을 실제 아이의 경험으로 단정하지 않는다. 근거가 없거나 옛 대본에 해당 질문이 없으면 바로 새 상황으로 간다.

## 도움을 나누는 기준

| 반응 | 동작 | 남기는 주요 기록 |
|---|---|---|
| 목표 기능에 필요한 내용을 전달함 | 예시 문장과 달라도 받아들이고 상대 역할로 답함 | 바로 전달 / 이후 합의·마무리는 별도 |
| 필요한 정보가 일부 빠짐 | 상대가 필요한 정보 하나만 자연스럽게 확인 | 확인 질문 뒤 해결되면 `AFTER_REASK`, `REASK_RESOLVED` |
| 확인 질문 뒤에도 정보가 부족함 | 도움을 받을지 제안하고 동의한 경우에만 코치 전환 | 도움 수락·거절, 역할 전환 |
| 장면 자체를 이해하지 못함 | 쉬운 상황 재설명을 먼저 제공 | `SITUATION_EXPLAINED`, 재설명 횟수 |
| 표현 방법을 직접 물음 | 요청한 부분 하나에 한해 짧은 코치 도움 | `FOCUS_HELP`, 예시 제공 여부 |
| 인식이 불확실하거나 판정이 보류됨 | 잘 못 들었을 수 있음을 확인하고, 표현을 교정하지 않음 | 반복돼 진행할 수 없으면 판독 실패 또는 판단 보류. 능력 부족·성공으로 바꾸지 않음 |

자연스러운 확인 질문으로 해결됐으면 별도의 문장 따라하기를 추가하지 않는다. “파란색”처럼 짧은 답도 직전 요청과 상대 질문의 맥락에서 필요한 기능을 수행하면 받아들인다. 판정기는 승인 후 실제 기기로 전달된 상대·코치 발화와 아이 발화를 구분해 최근 맥락으로 받으며, 아직 전달되지 않은 말이나 현재 아이 답을 이전 대화로 섞지 않는다.

첫 확인 뒤에도 정보가 부족하면 무한히 같은 질문을 반복하지 않고 도움을 제안한다. 재설명 한도, 집중 도움 90초, 목표당 10분, 변형 동의와 종료·휴식 처리는 유지한다. 8분 배분은 운영 예시이며 새로 강제한 제한이 아니다.

## 진행 기록과 다음 회차 연결

실시간 서버는 기존 장면 실행·사실·도움 기록 표를 그대로 사용한다. 확인 질문 뒤 해결, 상황 재설명, 코치 도움, 예시, 역할 복귀, 변형 생략과 기술 실패를 구분한다. 목표 표현 수행과 장면 정상 완료는 같은 의미로 취급하지 않는다. 기록은 기존 정산 경로를 통해 Core의 활동 기록에 저장된다.

다음에 같은 담은 목표로 연습을 시작하면 같은 보호자·아이·목표의 이전 장면 최대 3개를 읽는다. 상황 생성·독립 검토에 정리된 도움 유형과 이전 장소·주제·관계를 전달한다.

- 확인 질문으로 해결: 상황 안에서 확인하는 대화를 허용하고 별도 문장 연습을 전제하지 않는다.
- 재설명이 필요했음: 같은 목표를 유지하되 상대·활동·필요를 더 단순하게 제시한다.
- 코치 도움이 있었음: 익숙한 맥락에서 먼저 스스로 대화할 기회를 준다. 도움을 처음부터 강제하지 않는다.
- 입력·재생 장애: 이를 아이의 능력 부족으로 해석하거나 난도를 낮추는 근거로 사용하지 않는다.

이 기록은 다음 상황을 만드는 참고 자료이며, 아이의 현재 반응보다 우선하는 고정 진단이 아니다. 다음 회차에 목표를 자동 선택하거나 아이 동의 없이 변형을 강제하지 않는다. 새로운 상황의 Neo4j 연결·구조 보존·중복 검사는 기존 경로를 유지한다.

## 이전 대화의 출처와 안전

돌아보기 근거는 담은 목표가 고정한 후보 버전의 인용과, 같은 소유자의 원본 활동 기록에서 같은 순번의 아이 발화를 대조해 확인한다. 불확실한 음성, AI 발화, 일치하지 않는 인용은 제외한다. 최대 2개 인용만 생성·검토 입력으로 사용하며 이름·연락처 정리를 거친다. 보호자 메모는 이 경로의 근거로 읽지 않는다.

`reflectionPrompt`는 새 상황 대본의 선택 필드다. 검증된 아이 발화 근거가 있을 때만 BASE 장면에 허용한다. 독립 검토와 기존 금지 표현·이름·연락처·정답 누설 검사를 통과해야 한다. VARIANT나 근거 없는 대본에 있으면 거절한다. 기존 기록과 대본은 지우지 않는다.

연습의 실제 음성 출력 요청은 `session.commentary.append`로 구분한다. 일반 방향 지시·안전 교정은 `session.instructions.append`를 유지한다. 생성 역할 발화가 승인 낭독으로 바뀌는 것은 아니다. 생성 발화는 모두 기존 Jev 검사 대상이며, 승인 낭독은 기존 원문 일치 검사를 통과해야 한다. 요청 수락을 기기 재생 완료로 처리하지 않는다.

## 검증

- 관련 자동 시험: Core 137개 + 실시간 서버 588개 = 725개.
- 실제 AI 판정: 짧은 색 답변의 기능 전달, 상황 혼란, 표현 도움 요청, 돌아보기 거절 4개 사례 모두 기대 판정 확인.
- 실제 AI 생성: 돌아보기 질문·자연스러운 새 상황 안내·상대 대사 생성과 독립 검토 승인, 합성 자료 시험 약 7.1초.
- 실제 음성 생성: 돌아보기 선택 안내 음성 생성, Jev `ALLOW` 확인.
- 시험의 음성·대화 자료는 합성 자료다. 사용자의 브라우저·실제 마이크·스피커를 포함한 전체 시험과 구분한다.

## 직접 확인 순서

1. 보호자 화면과 기기 화면을 새로고침하고 기기를 다시 켠다.
2. 목표 하나로 새 연습을 시작한다. 기존 진행 중 세션·생성 대본을 이어가지 않는다.
3. 돌아보기 제안이 나오면 “바로 연습할래”로 건너뛰기를 확인하거나, 다른 시도에서 동의하고 짧게 이야기한다.
4. 새 상황 안내 뒤 일부 정보만 말해 확인 질문을 유도하고, 짧은 답으로 해결되는지 본다.
5. 별도 시도에서 “누구랑 뭘 하는 상황이야?”와 “뭐라고 말하면 돼?”에 다른 도움을 주는지 확인한다.
6. 대화를 정리하고 마지막 친구 답변 재생·정상 종료·기록을 확인한다. 같은 목표의 다음 시작에서 앞선 도움 이력이 상황 생성에 들어간다.

AWS Terraform 수정, 원격 push, main 병합은 이 작업에 포함하지 않는다. 데이터 초기화와 운영 배포도 수행하지 않는다.
