# 시작 안내와 아이 발화가 겹칠 때의 처리

## 실제 시험에서 발생한 문제

참여 확인 뒤 목표 시작 안내를 생성하던 중 아이 발화의 전사가 도착했다. 서버가 아직 음성을 모으고 있던 안내를 즉시 닫아 불완전한 구간(`GATE_EMPTY`)으로 폐기했고, 연습은 `PRACTICE_OUTPUT_FAILED`로 종료됐다. Jev 검사에 도달하기 전의 실패이며, 장면은 0개로 저장됐다.

단독 AI 음성 생성·검사에서는 재현되지 않았고, 실제 입력과 출력이 겹치는 실행기 경로에서 드러났다. 이 경합을 실행기와 실제 DB를 연결한 회귀 시험에 추가했다.

## 수정한 동작

- 시작 안내가 진행 중인지 연습 흐름이 실행기에 알려준다. 분기 라우터도 이 정보를 실제 흐름으로 전달한다.
- 이때 시작된 일반 발화는 안내 음성 수집을 조기에 닫지 않고, 대기 중인 Jev 검사도 일반 대화의 새 턴으로 무효화하지 않는다.
- 발화가 끝날 때 이미 다음 단계로 바뀌었더라도, 시작 안내 중 나온 발화였다는 표지를 유지한다. 이를 새 장면의 목표 답변으로 판정하지 않는다. 발화 기록은 남긴다.
- 이미 재생되던 목표 안내가 아이 음성으로 중단된 경우 출력 장애로 종료하지 않는다. 같은 안내를 계속 반복하지 않고 검토된 상황 안내로 이어간다.
- 친구 역할의 실제 대화 중 끼어들기는 기존 처리를 유지한다. 시작 안내의 예외를 자유대화나 모든 생성 음성에 적용하지 않는다.

## 종료·휴식과 안전

안내 중 들어온 발화도 기존 종료·휴식 판단을 계속 거친다. 명확한 종료는 기존 종료 경로로 보내고, 휴식·모호한 종료 표현은 기존 J6 확인 경로에서 출력을 멈추고 판단한다. 다음 안내가 끝날 때까지 기다리게 하지 않는다. 이미 멈춘 뒤 도착한 Jev 허용 결과가 음성을 다시 재생시키지 않는다.

음성·전사 대응 검사, 금지 패턴 검사, 승인 대본 원문 일치 검사, Jev 검사, 출력 세대·연결·상태 재확인과 시간 제한은 유지한다. 실제 음성 누락이나 검사 실패를 허용으로 바꾸지 않는다.

## 직접 확인 순서

1. 보호자 화면과 `/device`를 새로고침하고 기기를 다시 켠다.
2. 목표 하나를 선택하고 새 연습을 시작한다.
3. 참여 의사에 답한 뒤 시작 안내가 나올 때 짧게 “응, 알겠어”라고 말한다.
4. 연습이 종료되지 않고 상황 안내와 친구 역할 대화로 이어지는지 확인한다.
5. 별도 시도에서 안내 도중 종료·휴식을 요청해 출력이 멈추는지 확인한다.

자동 회귀 시험은 겹치는 입력·안내 수집·Jev 대기·재생 중단·종료·휴식·DB 장면 기록을 확인한다. 사용자의 실제 마이크·스피커를 포함한 재시험과 구분한다.

관련 실시간 서버 회귀 시험 629개가 통과했다. 실패·오류·시험 건너뜀은 0개이며 실행 이미지용 빌드도 통과했다. 기존 일반 역할 대화의 Jev 대기 중 끼어들기, 금지 패턴 차단과 승인 대본 불일치 거절 시험을 함께 유지했다.

AWS Terraform 수정, 데이터 초기화, 원격 push와 main 병합은 수행하지 않는다.
