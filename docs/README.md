## 과거 기록을 읽을 때

- [ERD v0.2](erd/ERD_v0.2.md)는 당시 스냅샷이다. 현재 DB 전체 구조는 이후 마이그레이션까지 적용한 결과다.
- [연습 상황 도입 작업](practice-scene-start.md), [유연한 연습대화 작업](flexible-practice-dialogue.md), 날짜가 붙은 오류 분석·검증 보고서는 해당 수정 당시의 기록이다. 최신 흐름과 상충하면 현재 흐름 문서와 실제 분기 코드를 확인한다.
- `docs/units/`, `docs/aidlc_drafts/`, `aidlc/` 아래 산출물은 설계·구현·검증의 이력이다. 예전 버전명과 시험 수치를 현재 값으로 바꿔 쓰지 않는다.
- 연습 안내 문서에 남긴 과거 시험 결과 및 계약 안내의 U1 대조표는 보존 기록이다. 이번 변경에서 해당 시험들을 다시 실행했다는 뜻이 아니다.

## 문서 변경 검증

문서의 정책 수치·프롬프트 버전은 연결된 소스와 대조하고, 상대 링크와 변경 파일 범위를 검사한다. API나 스키마의 실제 계약 변경이 필요하면 문서만 바꾸지 말고 구현·소비자·시험을 별도 범위로 함께 검토한다. 이번 작업은 Markdown 안내만 바꾸며 실행 설정, 안전 검사, Jev 모드, 알림 브랜치, AWS Terraform은 변경하지 않는다.
