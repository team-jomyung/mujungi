# 연습 음성 생성·재생 제한 시간 분리

## 실제 실패 기록

2026-10-22 01:50 연습 시도는 JOIN_ACCEPTED 뒤 ACTIVE로 전환됐지만 장면 실행 행이 생기기 전에 PRACTICE_OUTPUT_FAILED로 종료됐다. 참여 거절이나 아이의 종료 요청은 아니다.

- 참여 확인: 01:50:58.510 KST.
- 승인 대본 전사 확정: 01:51:12.063 KST. APPROVED_VERBATIM_SKIPPED / ALLOW이며, 승인 대본 원문 일치 경로다.
- 기술적 종료 요청: 01:51:18.549 KST. 참여 확인 약 20초 뒤다.
- 종료 완료: 01:51:20.604 KST. 저장된 연습 장면은 0개.

이 시도는 이전 음성 서버에서 실행됐다. 앞서 준비했던 입력 겹침 수정의 로컬 서버 적용은 01:51:34 KST에 완료됐으므로 그 수정본의 실제 검증 결과로 볼 수 없다. 이전 컨테이너 교체로 이 시도의 상세 음성 송신·기기 재생 로그는 현재 컨테이너에 남아 있지 않다. 승인 전사가 존재한다는 사실만으로 기기에서 음성이 실제 들렸다고 판단하지 않는다.

## 재현한 코드 문제

PracticeConversation은 음성을 요청할 때 20초의 슬롯 안전 시계를 걸고 재생 STARTED 사실을 무시했다. 따라서 생성과 안전 검사에 시간을 쓴 뒤 정상 재생을 시작해도 최초 20초가 되면 실패할 수 있었다.

수동 시계 시험에서 생성 12초 → 재생 시작 → 8초 경과만으로 OUTPUT_FAILED가 되는 것을 수정 전 코드에서 재현했다. 이는 실제 종료 시각과 일치하는 결함이지만, 이전 실제 시도의 기기 재생 시작 여부까지 증명하는 것은 아니다.

## 수정

- 음성 생성 단계의 기존 제한 시간을 유지한다.
- 현재 슬롯과 일치하는 최초 재생 STARTED 신호가 오면 생성 시계를 취소하고 동일한 설정 길이의 재생 시계를 시작한다.
- 재생 시계에는 별도 이름을 써 늦게 도착한 생성 시계 만료 사건을 무시한다.
- 중복·다른 슬롯의 STARTED 신호는 시간을 늘리지 않는다.
- 시작·완료 신호가 오지 않으면 기존처럼 제한 시간 뒤 실패한다. 실제 완료 전 장면을 완료로 기록하지 않는다.
- 목표 전체·집중 연습 제한, 중단 요청, 승인 대본 원문 일치, 안전 검사 및 생성형 발화의 Jev 검사는 유지한다.

## 검증

수정 전 새 재현 시험 1개가 예상대로 실패했다. 수정 후 생성·재생 시간 분리, 중복 STARTED, 다른 슬롯 STARTED, 연습 흐름·입력 겹침·Jev 연계·종료 관련 시험 276개가 오류·실패·생략 없이 통과했다. 실행 파일 빌드도 성공했다.

실제 마이크와 기기의 재생 시작·완료·후속 응답·정상 종료·결과 저장은 별도 실제 테스트가 필요하다. 이전 상황 생성 실패 2건과 그 뒤 성공한 상황 1건은 별도 준비 단계 결과이며, 이 음성 타이머 수정으로 상황 생성 실패까지 해결됐다고 주장하지 않는다.

AWS Terraform 수정, 원격 push, main 병합은 하지 않는다.
