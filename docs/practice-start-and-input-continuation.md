# 연습 시작과 대화 중 끼어들기 보완

## 무엇을 고쳤나

### 상황 생성과 시작 대기

상황 생성 지시를 장소·활동·아이의 선택·상대의 한 대사 순서로 명확하게 했다. 실제로 읽는 안내에도 같은 맥락을 남기되 정답은 미리 말하지 않도록 했다.

생성된 상대 대사가 내부 상황 설명에 빠져 있으면, 이미 생성된 그 대사를 내부 설명에 인용해서 포함한다. 이 처리는 새로운 사건이나 아이의 답을 만들지 않으며, 아이가 듣는 상황 안내문을 임의로 바꾸지 않는다. 포함한 최종 대본을 독립 AI 검토와 기존 서버 안전 검사에 다시 제출한다. 거절·불확실·안전 위반이면 사용할 수 없다.

생성·별도 검토·보완을 모두 15초 안에 끝내려던 제한은 30초로 변경했다. 웹의 연습 시작 요청도 기존 일반 요청의 10초보다 길게, 최대 35초까지 기다린다. 그 밖의 웹 요청은 10초를 유지한다. 생성이 즉시 끝난다는 의미나 모든 생성이 반드시 성공한다는 의미는 아니다.

### 아직 재생되지 않은 AI 음성과 아이 말이 겹친 경우

이전에는 서버가 모으던 음성이 완결되기 전 아이 말이 오면 미완성 음성을 폐기하고, 그것을 연습 재생 실패로 처리해 전체 연습이 종료됐다.

이제 역할 대화를 이어가는 구간에서는 미완성 음성을 그대로 폐기하되, 연습 실패 대신 아이가 발언권을 가져온 중단으로 처리한다. 미완성 음성과 뒤늦은 나머지는 재생하지 않는다. 아이의 확정된 말을 판정하고 현재 상황에 맞춰 다음 답변을 생성한다. 새 답변도 안전 검사와 Jev를 통과해야 재생한다.

이 분기는 목표 달성·동의·코치 설명 완료·끝맺음 완료를 만들어내지 않는다. 상황 안내·동의·코치 설명·끝맺음처럼 듣기 전에 다음 단계로 넘어가면 안 되는 출력은 이 분기의 대상이 아니다. 명시적인 종료·휴식은 별도 우선 경로로 계속 처리한다. 실제 기기 재생 장애·안전 차단·공급자 장애를 일반 끼어들기로 바꾸지 않는다.

## 다음 답변의 근거

다음 답변은 새로 들어온 아이의 말과 현재 연습 상황을 기준으로 한다. 폐기한 미재생 음성을 아이가 들었다고 가정하지 않도록 친구 역할 지시도 보완했다. GPT-Live 내부의 과거 생성 내용을 지울 수 있다고 주장하지는 않으며, 실제 자연스러운 응답 여부는 기기 시험으로 확인해야 한다.

## 검증 범위

미완성 음성 수집 중 일반 발화·종료·휴식, 늦게 도착한 나머지 음성 폐기, 다음 응답의 Jev 필수 경로, 끼어들기 후 목표 판정 재개를 시험한다. 상황 대사 보완 후 독립 검토 거절이 계속 유효한지도 확인한다. 웹은 준비 대기와 일반 요청의 시한이 분리되는지 확인한다.

AWS Terraform과 main 병합은 작업 범위에 포함하지 않는다. 로컬 데이터와 키는 유지한다.

## 확인 결과

- 실시간 대화 관련 시험 635개, 상황 생성·Luna 시험 142개, 연습 시작 API·중복 요청 시험 28개, 웹 시험 93개가 통과했다. 합계 898개이며 실패·오류·건너뜀은 없다.
- 웹 타입 검사·변경 범위 정적 검사·배포용 빌드와 두 서버 실행 파일 생성이 성공했다.
- 실제 AI의 시험용 상황 생성은 독립 검토 APPROVE와 서버 검사를 통과했다(약 7.6초, 생성·검토 2회). 실제 사용자 데이터베이스에는 쓰지 않았다.
- 실제 GPT-Live에 시험용 합성 질문을 전달하자 질문에 맞는 놀이 선호 답변과 음성 268,800바이트가 생성됐다. 실제 Jev는 ALLOW였다(287ms). 이것은 기기 스피커 재생 검증이 아니다.
- 수정한 실제 마이크 끼어들기 → 다음 답변 → 돌아보기 → 종료·결과 저장의 전체 흐름은 로컬 적용 후 사용자의 기기로 확인해야 한다.
