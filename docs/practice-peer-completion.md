# 목표 수행 뒤 친구 역할의 답변과 마무리

## 변경 이유

이전에는 아이가 목표 표현을 말하면 판정 직후 다음 목표나 종료로 넘어갔다. 예를 들어 “무슨 놀이를 하고 싶어?”라는 질문이 목표를 충족해도 친구가 자신의 놀이 의견을 답할 기회가 없었다.

## 변경한 흐름

목표 수행 판정 → 필요하면 코치에서 친구 역할로 복귀 → 친구 역할의 짧은 답변 생성 → 기존 안전 검사와 Jev 검사 → 기기 음성 재생 → 재생 완료 확인 → 기존 변형 제안·다음 목표·종료.

- 처음 수행한 경우, 되묻기 뒤 수행한 경우, 도움 뒤 수행한 경우에 모두 적용한다.
- 새 대본을 생성하는 기능이 아니다. 승인된 상황과 같은 GPT-Live 세션의 대화 맥락을 사용해 상대 역할의 마무리 답변을 생성한다.
- 친구가 놀이 의견을 물었을 때 자신의 의견을 답하고, 요청·거절에는 그 뜻을 존중해 반응하도록 지시한다.
- 추가 질문이나 답변 요구, 아이의 대사를 대신 말하기, 상황 설명 반복, 성공·점수·평가 표현을 금지한다.
- 아이 발화 원문이나 판정 코드·확률을 추가 지시문에 삽입하지 않는다. 상대 역할·상황·기회 문장만 제한된 길이로 사용한다.
- 답변은 한두 문장으로 제한하며, 새로운 무응답 시계나 수행 판정을 열지 않는다.

## 안전·종료·저장

`SCENE_WRAP/PEER_REPLY`라는 내부 소단계를 추가했다. `speakGenerated(PEER, ...)`를 사용하므로 승인 대본 읽기로 위장해 Jev를 생략할 수 없다. 정책 파일과 검사 기준은 변경하지 않았다.

기존 생성·재생 시간 제한과 중복 사건 차단을 그대로 사용한다. 최종 차단·송신 실패·재생 실패·시간 초과·재생 중단이 발생하면 정상 완료로 표시하지 않는다. 같은 마무리 답변을 무한 반복하지 않는다. Jev의 기존 제한된 재지시 처리만 유지한다.

정상 장면의 종료 저장은 친구 답변 재생 완료 뒤로 미룬다. 아이의 종료·휴식 요청은 답변 재생보다 우선하며, 외부 종료 시에도 열린 장면 기록을 닫는다. 목표 수행 시점 분류(IMMEDIATE/AFTER_REASK/AFTER_HELP)는 기존 의미를 유지한다.

## 검증

관련 Core 129건과 Realtime 506건, 총 635건 통과(실패·오류·시험 생략 0). 패키징 통과.

통합시험에서 다음을 확인했다.

- 수행 판정 뒤에도 세션이 ACTIVE이고 장면 종료 시각이 아직 없음.
- 새 친구 답변은 PRACTICE_PEER 모드로 검사되며, Jev 승인 전에는 기기에 전달되지 않음.
- 승인 뒤에도 기기 재생 완료 전에는 종료하지 않음.
- 재생 완료 뒤 종료·DB 저장·정산 결과의 계약을 유지함.

추가 회귀시험: 도움 뒤 친구 복귀, 변형·복수 목표, 중복 완료 사건, 종료 요청, 외부 종료, 실패·차단·중단·시간 초과, 긴 상황 정보에서도 지시문 안전 규칙 보존.

실제 마이크 답변과 스피커 청취를 포함한 사람의 자연스러움 평가는 별도로 필요하다. 자동 통합시험은 공급자·기기 대역을 사용한다.

추가로 실제 공급자에 합성 상황의 마무리 지시를 보냈으나, 아이 음성을 넣지 않은 점검 세션에서는 응답 음성을 확보하지 못했다. 이 실호출은 성공 증거로 계산하지 않는다. 실제 발화가 포함된 로컬 연습에서 답변 내용과 청취를 확인해야 한다.

AWS Terraform, DB 스키마, 웹 화면, 안전 정책은 변경하지 않았다. main 병합과 원격 push는 이번 범위에 포함하지 않았다.
