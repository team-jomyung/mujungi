# 보호자 맥락·목표·연습·리포트 변경 검토 안내

## 변경 범위

보호자 메모의 제한된 주제·출처를 자유대화 전 참고에 사용하고, 대화 후 분석에서 보호자 정보와 실제 아이 발화를 구분한다. 목표 후보의 실제 증거 인용과 새 연습 표현 제안을 분리한다. 실제 AI 연결에서 확인한 분석·연습 준비·리포트 오류를 보완했다.

- 생년월일 입력과 최초 등록일 기준 검증, 13세 이후 계속 이용 허용. 기존 PR #47의 변경이 이 브랜치의 선행 커밋에 포함돼 있다. 두 PR을 중복 병합하는 대신 검토자가 의존 관계를 확인해야 한다.
- 운영 Java에서의 목표 순서 처리, 생성·검토 스키마, 검토 완료 기본 장면의 시간 예산 처리 보완.
- 표시용 상대 이름과 실제 그래프 관계 코드의 동등한 값 연결. 다른 상대 관계를 임의로 바꾸지 않는다.
- 도입 실패가 연습 완료로 표시되지 않도록 기술 실패·종료 화면을 구분.
- 리포트의 missing 자료형을 boolean으로 제한하는 구조화 응답. 기존 서버 출력 검증은 유지.

## 이번 연습 도입 추가 수정

승인 대본을 수집하는 도중 아이 입력 전사가 도착하면, 공통 음성 흐름이 대본의 앞부분을 조기에 확정했다. 전체 대본과 일치하지 않는 짧은 조각이 폐기돼 연습이 중단되는 문제를 시험으로 재현했다.

승인 대본을 수집하는 동안에는 아이 입력 도착만으로 음성 구간을 확정하지 않는다. 입력 기록·종료 요청 처리와 전체 대본 일치 검사를 유지한다. 생성형 역할 발화의 Jev 검사 및 실제 기기 재생 중 끼어들기 처리는 바꾸지 않는다. 불일치 대본의 재생 금지, 종료 요청 처리, 기존 생성형 발화 차단을 회귀시험으로 확인한다.

## 실제 확인 결과와 한계

- 리포트 생성·PDF 저장은 사용자가 확인했다.
- 실제 자유대화 분석에서 보호자와 아이 출처가 분리됐고, 새 목표 ‘놀이 의견 묻기’ 1개를 생성·저장했다. 정상 로그인 화면에서 담기와 새 상황 저장·독립 검토 통과까지 확인했다.
- Neo4j는 ACTIVE, poc-v1이다. 기술에 연결된 ‘뜻을 짚어보기’ 목표의 실제 상황은 graphContextUsed=true로 저장됐다.
- ‘놀이 의견 묻기’는 skillRef=NONE이므로 해당 상황의 graphContextUsed는 false다. 모든 목표가 그래프를 사용하는 것으로 설명하면 안 된다.
- 첫 대화 질문은 놀이에 대한 넓은 질문이었다. 보호자 메모의 친구 주제를 첫 질문부터 충분히 우선했다고까지 평가하지 않는다.
- 연습 참여는 통과했지만 도입 음성이 중단된 사례가 남아 있다. 이번 입력 겹침 수정은 시험을 통과했으나 **수정본의 로컬 이미지 적용과 실제 장면 재생 확인은 아직 완료하지 않았다**.
- 자유대화의 Jev 응답 INVALID_JSON 1회도 관찰했다. 이를 허용으로 바꾸거나 안전 검사를 끄지 않았다.

## 검증 근거

- 입력 겹침 재현: 수정 전 신규 회귀시험 실패, 수정 후 관련 시험 288개 통과. 패키징 통과.
- 앞선 리포트 보완 관련 시험 31개, 그래프 관계 연결 관련 시험 68개 통과.
- 앞선 변경 단계의 전체 검증: Core 1,748개, Realtime 1,880개, 계약 322개, 프런트 1,007개. 각 변경 시점의 시험이며 현재 최종 커밋 전체를 모두 재검증한 숫자는 아니다. 서로 겹치는 시험 수를 합산하지 않는다.

AWS Terraform, 로컬 비밀값, Jev 정책은 이번 변경에서 수정하지 않는다. main 병합과 배포는 이 작업에 포함하지 않는다. 실제 장면 재생 확인이 남아 있으므로 PR은 초안으로 제출한다.
