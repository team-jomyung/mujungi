# 연습 도입 출력과 목표 후보 근거 수정

## 확인된 원인

2026-10-21 로컬 시험에서 “응, 연습하자”는 참여 동의로 수락됐다. 이후 GPT-Live가 승인된 장면 설명 대신 상대방의 대사를 생성했고, 원문 일치 검사가 음성을 차단했다. 따라서 아이가 그만하자고 말한 것이 아니다.

기존 연습 흐름은 도입 출력 실패를 장면 건너뛰기로 처리하고, 마지막 목표에서 `CHILD_STOP / PRACTICE_COMPLETED`로 닫았다. 종료 화면은 활동 종류와 상세 사유를 구분하지 않아 자유대화 종료와 아이의 중단 요청으로 잘못 표시했다.

## 수정한 동작

- 낭독 차례에는 상대 역할을 새로 연기하지 않고 승인된 `speech` 문장만 읽도록 지시한다. JSON은 데이터로 취급하고 다른 문장을 덧붙이지 않는다.
- 원문 일치 검사, 음성 구간 검사, Jev 검사는 완화하지 않는다. 지정 문장과 다른 출력은 계속 차단한다.
- 첫 장면 도입을 재생하지 못하면 `DISCONNECT / PRACTICE_OUTPUT_FAILED`로 종료한다. 장면이 진행됐거나 연습을 완료했다고 기록하지 않는다.
- 화면에는 연습/자유대화 종류와 정상 완료/음성 재생 실패를 구분한다. 종료 상세 사유가 없는 구버전 또는 대체 응답에서도 아이가 하지 않은 중단 발화를 추정해 표시하지 않는다.
- 상세 사유 전달에는 두 고정 코드만 허용한다. 내부 진단 원문은 웹 응답에 전달하지 않는다. DB 스키마와 AWS Terraform 변경은 없다.

## 목표 후보의 실제 근거와 제안 구분

아이의 실제 발화(`evidence.quote`)는 기존처럼 CHILD 발화의 전체 문자열과 순서 번호를 정확히 확인한다. 보호자 메모나 AI 발화를 아이의 말로 사용하지 않는다.

앞으로 연습할 표현(`targetExpression`)의 따옴표는 새로 제안한 대사일 수 있으므로 실제 발화 인용과 구분한다. 이 구분은 서버 호출자가 지정하며 모델 출력이나 보호자 입력으로 바꿀 수 없다. 제안 문장은 따옴표 안까지 금지 표현과 숫자를 검사하고, 의미 안전 분류도 통과해야 한다. 관찰 근거·후보 이름·제안 사유는 기존의 엄격한 인용 검사를 유지한다.

AI가 힌트를 준 다음 나온 아이의 발화를 혼자 스스로 알아차린 능력으로 일반화하지 않도록 지시문도 보완했다.

## 검증 범위

자동 회귀시험, 실제 GPT-Live 낭독 요청, 저장된 대화의 정상 작업자 재분석, 목표 선택과 연습 상황 생성, Neo4j 사용 메타데이터를 확인한다. 실제 공급자 직접 시험은 합성 이름과 합성 상황만 사용하며 앱의 음성 안전 게이트나 Jev를 우회해 아이에게 재생하지 않는다.

실제 마이크/스피커를 사용한 브라우저 시험 결과와 서버 생성 시험 결과는 구분해서 기록한다.
