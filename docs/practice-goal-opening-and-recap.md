# 연습 시작 안내와 행동 돌아보기

실제 시험에서 발견된 시작 안내·아이 발화 겹침 문제의 보완은 [시작 안내와 아이 발화가 겹칠 때의 처리](practice-introduction-input-overlap.md)에 정리했다.

## 바뀐 흐름

참여 확인 → 오늘 목표·범위 안내 → 선택적 이전 대화 돌아보기 → 승인된 새 상황 안내 → 상대 역할 대화·필요한 도움 → 마지막 상대 답변 → 실제 수행 돌아보기 → 종료 인사·기록 저장 순서다.

목표가 여러 개라면 각 목표를 시작할 때 순서와 전체 개수를 알리고, 그 목표의 정리 후 다음 목표로 넘어간다. 다음 목표에 앞선 목표의 성공이나 도움 여부를 가져오지 않는다. 변형 장면에서는 같은 목표의 시작 안내를 반복하지 않는다.

한 번의 연습에서 선택하는 목표는 1~3개다. 담아 둔 목표 목록 자체를 3개로 줄이지 않는다. 3개를 선택하면 나머지 체크박스가 비활성화되며, 선택한 것을 해제하면 다른 목표로 바꿀 수 있다. 화면 안내와 서버 검증·API 명세에도 같은 상한을 둔다. 서버로 4개 이상 직접 요청해도 상황 생성이나 AI 호출 전에 거절한다. 미확인 시작 요청을 재확인할 때 원래 선택·키를 보존하는 규칙은 유지한다.

## 시작할 때

선택한 목표 이름을 실제로 말하고, 그 목표로 짧은 역할놀이를 하며 필요하면 도움을 받을 수 있다고 안내한다. 쉬거나 끝내는 선택도 알린다. 정답 표현을 미리 알려주거나 성공을 약속하지 않는다. 상황 설명·친구의 첫 대사는 이 안내 뒤 기존 검토된 대본으로 별도로 재생한다. 시작 안내는 추가 참여 시험이 아니므로 별도 답변을 요구하지 않는다.

## 끝날 때

친구 역할의 마지막 반응을 먼저 들려준 뒤 무중이로 돌아본다. 점수나 능력 평가, 막연한 칭찬 대신 목표 이름과 확인된 행동을 연결한다. 다음 사실을 구분해 전달한다.

| 기록된 사실 | 돌아볼 내용 |
| --- | --- |
| 바로 뜻을 전달함 | 해당 목표에 맞게 전달한 행동 |
| 상대의 확인 질문 뒤 전달함 | 확인 질문을 듣고 필요한 정보를 전한 행동. 코치 도움으로 바꾸지 않음 |
| 코치 도움 뒤 전달함 | 도움을 받은 뒤 해 본 행동. 혼자 했다고 표현하지 않음 |
| 도움은 받았지만 수행 미확인 | 도움을 받으며 연습한 사실. 성공·실패로 단정하지 않음 |
| 시간 제한·음성 인식 불확실성 등으로 중간 정리 | 오늘 여기까지 연습했다는 사실. 능력 부족이나 목표 달성으로 바꾸지 않음 |

판정 기준 원문과 아이 발화 원문을 새 공급자 지시문에 붙이지 않는다. 서버가 확정한 수행 시점과 도움·중간 정리 표지, 길이를 제한하고 JSON 문자열로 구분한 목표 이름만 사용한다. 이 말은 수행 판정을 새로 만드는 기능이 아니다. 기존 판정의 정확성 한계는 그대로 존재한다.

이 사실들을 바탕으로 서버가 짧은 안내·정리 문장을 정한다. GPT-Live가 상황이나 행동을 자유롭게 덧붙이지 않고 해당 문장만 읽게 요청한다. 출력 경로는 생성 발화이므로 Jev 검사와 재생 확인을 생략하지 않는다.

## 중단과 안전

아이가 끝내거나 쉬고 싶다고 하거나, 보호자가 종료하거나, 연결·재생 장애가 발생하면 돌아보기를 강제하지 않는다. 즉시 기존 종료 처리를 우선하고, 실제 수행·도움·중단 사실은 기존 장면 기록과 보호자 기록 화면에서 확인한다. 정리 음성 도중 중단해도 같은 말을 다시 요구하지 않는다.

시작 안내와 돌아보기는 생성 발화이므로 기존 Jev 검사를 통과해야 한다. 승인 낭독 경로로 바꿔 검사를 우회하지 않는다. 기존 상황 대본의 원문 일치 검사도 유지한다. 생성 요청 수락은 재생 완료가 아니다. 기기의 실제 완료 표식을 받은 뒤 다음 단계로 넘어가며, 재생 누락·차단·시간 초과를 성공 종료로 처리하지 않는다.

## 확인할 방법

1. 보호자 화면과 `/device`를 새로고침하고 기기를 다시 켠다.
2. 목표 하나로 새 연습을 시작하고 참여 의사를 답한다.
3. 목표 이름·오늘 범위 안내 후 기존 상황 안내와 친구 대사가 이어지는지 듣는다.
4. 목표에 맞게 답하고, 친구의 반응 뒤 구체적인 돌아보기와 종료가 이어지는지 확인한다.
5. 별도 시도에서 도움을 요청한 경우와 중간에 끝낸 경우를 확인한다.
6. 기록 화면의 수행 시점·도움·종료 사유가 실제 진행과 일치하는지 확인한다.

자동 시험과 합성 자료로 실제 AI 음성 생성·Jev 검사를 확인한다. 실제 사용자의 마이크·스피커를 포함한 전체 확인은 위 순서의 직접 시험과 구분한다.

## 검증 결과

- Core 관련 시험 165개, 실시간 서버 관련 시험 598개, 연습 화면 시험 52개: 총 815개 통과. 실패·오류·시험 건너뜀 0개.
- 프런트엔드 타입 검사와 수정 범위 코드 검사 통과.
- 실제 GPT-Live에서 시작 안내·수행 정리·도움 뒤 수행 정리·수행 미확인 정리의 합성 사례 4개 모두 음성이 생성됐고 Jev `ALLOW` 확인.
- 생성 요청 수락만으로 종료하지 않는 것, 정리 음성 차단·시간 초과, 중단 시 즉시 취소, 다음 목표에 앞선 수행을 넘기지 않는 것, 서버 직접 요청의 4개 선택 거절을 포함한다.
- 같은 목표에서 수행한 장면과 도움을 받은 다른 장면이 섞여 있으면 두 사실을 함께 말한다. 일부 수행을 모든 장면의 완료로 확대하지 않는다.

AWS Terraform, 데이터 초기화, main 병합과 원격 push는 수행하지 않는다.
