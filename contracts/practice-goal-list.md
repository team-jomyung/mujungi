# 연습 준비 목표 목록 — JIRA-293

- 활성 즐겨찾기는 보호자별 최대 5개다. 기존 추천 목표와 생성 목표를 합산한다.
- 추가·복원·기존 목표 재담기는 기존 보호자 쓰기 잠금 안에서 한도를 확인한다. 동시 요청으로 6개가 되지 않는다.
- 이미 즐겨찾기인 항목의 동일 요청과 즐겨찾기 해제는 한도와 무관하게 허용한다.
- 삭제한 즐겨찾기를 복원하여 한도를 넘으면 `409 FAVORITE_LIMIT_REACHED`를 반환한다. 복구 시한 안에 다른 즐겨찾기를 해제한 뒤 재시도할 수 있다.
- 과거에 이미 5개를 초과한 데이터는 삭제·자동 해제하지 않는다. 기존 항목을 표시하여 해제할 수 있게 하고 새 추가는 거절한다.

웹에서는 즐겨찾기를 상단에 표시하고 일반 담은 목표는 페이지당 5개씩 이전·다음으로 탐색한다.
목록 조회 API는 전체 목록을 유지하며 페이지 구분은 웹에서 수행한다. 체크와 시작 요청은 전체 목록 ID를 기준으로 하므로
페이지를 이동해도 선택이 유지된다. 삭제·즐겨찾기 변경으로 마지막 페이지가 없어지면 유효한 마지막 페이지를 표시한다.
연습 한 번에 사용할 목표 개수는 기존 정책(1개)을 유지한다. DB 스키마·마이그레이션은 변경하지 않는다.
