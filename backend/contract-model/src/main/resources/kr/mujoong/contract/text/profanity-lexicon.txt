# 공통 욕설 어휘 사전 (JIRA-266 · contracts/deviations.md FT-1023-b)
#
# 읽는 곳: kr.mujoong.contract.text.ProfanityLexicon(contract-model). core-api는 아이 이름 입력 거절(CHILD_NAME_NOT_ALLOWED)에,
# realtime-activity는 세션 지시문의 이름 대체와 1차 출력 사전 PROFANITY 범주에 같은 사전을 쓴다.
#
# 출처: 2026-10-23 실키 시험 사고(아이 이름이 욕설로 저장되어 AI가 그대로 부름)를 막으려고 개발 팀이 직접 고른 시드 목록이다.
# 외부 목록을 복사하지 않았다. 대표 어휘(씨발 · 병신 · 개새끼 · 좆 · 존나 · 지랄 · 미친놈 등)와 흔한 소리 · 글자 변형,
# 초성 줄임, 한영 자판 변형만 담았다. 완전한 목록이 아니다 — 제브(PROFANITY 라벨)가 뒤를 받친다.
#
# 형식
# - '#'로 시작하는 줄과 빈 줄은 주석이다. '@version <값>' 한 줄이 판이다(바꾸면 판을 올린다).
# - [block] 아래 낱말은 금지 항목, [allow] 아래 낱말은 금지 항목을 품은 일반 낱말(판정 전에 지운다)이다.
# - 낱말은 판정과 같은 정규화(NFKC · 라틴 소문자 · 공백 · 문장부호 · 숫자 · 기호 제거)를 거쳐 비교한다.
#   그래서 '씨.발' · '씨1발' 같은 끼움 변형은 따로 적지 않는다. 숫자로 쓴 변형('18')은 숫자를 지우므로 잡지 못한다(알려진 틈).
#
# 넓히는 법
# 1. [block]에 낱말을 더하기 전에, 띄어 쓴 일반 문장에서 낱말 경계를 넘어 걸리는지보다 '낱말 안에 품은 일반 낱말'이 있는지 본다
#    (예: '시발' ⊂ '시발점'). 있으면 그 일반 낱말을 [allow]에 함께 더한다.
# 2. 일반 문장에서 흔히 쓰는 말(예: '꺼져'(불이 꺼져) · '졸라'(엄마를 졸라) · '닥쳐'(위기가 닥쳐) · '미친'(미친 듯이) · '걸레')은
#    단독으로 넣지 않는다. 1차 출력 사전은 걸리면 응답을 버리므로 오탐이 대화를 끊는다.
# 3. 더한 뒤 ProfanityLexiconTest의 차단 · 오탐 목록에 예를 더하고 시험을 돌린다.
