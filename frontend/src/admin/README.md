# JIRA-279 관리자 프론트엔드

서비스 개발자가 사용하는 조회 전용 관리자 화면이다. 기존 보호자·기기 화면 및 백엔드/DB는 변경하지 않는다.

| URL | 기능 |
| --- | --- |
| `/admin` | 대시보드, 날짜별 대화 수, 자유/연습 평균 시간, 종료 현황 |
| `/admin/activities` | 전체 활동, 보호자 → 기기 → 아이 조회, 전사 원문 및 장면 결과 |
| `/admin/quality` | 연습 실행, 도움 종류, 도움 반응, 수락률, 장면 상세 |
| `/admin/costs` | 대화별·시작 실패·대화 외·연결 미확인 사용량과 USD 예상 비용 |

대시보드에 비용 카드를 추가하지 않는다. API·비용 목록의 상세는 선택한 행 바로 아래에 펼치며, 다른 행을 선택하거나 페이지·필터를 바꾸면 기존 상세를 닫는다.

## 로컬 미리보기

Node 22에서 `frontend`를 작업 디렉터리로 사용한다. PowerShell:

```powershell
$env:MUJOONG_ADMIN_PREVIEW = 'true'
npm run dev -- --hostname 127.0.0.1 --port 3001
```

`http://127.0.0.1:3001/admin`에서 확인한다. 이 서버는 합성 데이터만 사용하며 실제 계정 로그인이나 외부 AI 호출을 하지 않는다. 상단의 화면 상태 선택에서 빈 데이터, 로그인 필요, 권한 없음, 조회 오류, 로딩 상태를 확인할 수 있다. 운영 빌드에서는 미리보기 환경 변수를 넣어도 미리보기가 켜지지 않는다.

스위치는 서버 컴포넌트에서 읽으며 `NEXT_PUBLIC_*`를 쓰지 않는다. 기본은 비활성 상태이며 `/admin`에는 연결 준비 안내만 표시한다. 실제 관리자 API는 아직 연결 전이다.

## 표시 기준

- 시간: 전체 초를 먼저 반올림한 뒤 분·초를 나눈다. `45 → 45초`, `59.6 → 1분 0초`, `60 → 1분 0초`, `89.6 → 1분 30초`, `null → 미확인`이다.
- 비용: `Intl.NumberFormat("en-US", { style: "currency", currency: "USD" })`로 달러 기호를 표시한다. `ko-KR`의 `US$` 표시는 사용하지 않는다.
- 1달러 이상은 소수점 2자리, 1달러 미만은 최소 2자리·최대 6자리다. 원본 값을 합산할 때 화면 반올림을 적용하지 않는다.
- 6자리로 표시했을 때 0이 되는 양수만 `< $0.000001`로 표시한다. `0.0000004 → < $0.000001`, `0.0000005 → $0.000001`, `0.5 → $0.50`, `12.345678 → $12.35`, `0 → $0.00`, `null → 미확인`이다.
- 금액 열은 오른쪽 정렬과 `tabular-nums`를 적용한다. 작은 금액 문구는 공통 문구 모듈에 둔다.
- 합성 데이터의 음성 예시는 연결 초 ÷ 60 × $0.05/분을 사용한다. Luna 예시 금액과 이 음성 단가는 화면 검증용 가정이며 실제 적용 단가나 청구 내역을 뜻하지 않는다.

## API 연결 담당자에게

`data/types.ts`와 `data/http.ts`는 **프론트엔드 제안 계약**이다. 현재 서버에 아래 API가 구현되어 있다고 가정하지 않는다. 백엔드 담당자와 다음 여섯 묶음을 확인한 뒤 어댑터/파서를 맞추고, 웹 서버에 `MUJOONG_ADMIN_API_ENABLED=true`를 설정한다.

| 확인 묶음 | 백엔드와 정할 내용 |
| --- | --- |
| 1. 인증·권한 | 기존 보호자 세션 쿠키 사용, 관리자 판별 방식, 모든 관리자 경로의 서버 인가, 세션 만료·권한 회수 처리 |
| 2. 경로·응답·오류 | 아래 제안 경로와 DTO, 필수·nullable 필드, 공통 오류 `{code, message, traceId}`, 관리자 전용 오류 코드 |
| 3. 필터·시간·집계 | 한국 날짜 양 끝 포함 여부, 조회 상한, 활동 시작 시각과 API 호출 완료 시각 구분, 평균·수락률 분모 |
| 4. 페이지·목록·전체 합계 | 정렬 기준과 페이지 크기, AI 품질·대화 외 비용의 서버 페이지네이션, 기간 전체 합계와 현재 페이지 소계 분리 |
| 5. 사용량·비용·정밀도 | USD 금액 필드, 수집 범위·상태·미확인 값, 단가 버전, 합산 정밀도와 반올림 시점, 전송 형식 |
| 6. 원문 접근·감사 | 실제 대화 원문의 열람 권한·범위, 누가 어느 원문을 열었는지 남기는 감사 정책 |

| 제안 GET 경로 | 응답 DTO |
| --- | --- |
| `/api/admin/me` | `AdminIdentity` (role `ADMIN`) |
| `/api/admin/overview` | `Overview` |
| `/api/admin/activities` | `Page<ActivitySummary>` |
| `/api/admin/activities/{id}` | `ActivityDetail` |
| `/api/admin/guardians` | `Page<GuardianSummary>` (기기·아이 포함) |
| `/api/admin/quality` | `Quality` |
| `/api/admin/costs` | `Costs` |
| `/api/admin/costs/{id}` | `CostDetail` |

### 필터와 집계의 현재 제안

- 공통 필터: `from`, `to` (YYYY-MM-DD, 양 끝 포함, Asia/Seoul), `timezone=Asia/Seoul`, `type`, `query`, `guardianId`, `childId`, `status`. `ALL`은 쿼리에서 생략한다.
- 화면에서 한 번에 선택하는 기간은 최대 366일이다. 서버 조회 상한은 별도 합의·검증이 필요하다.
- 목록 `page`는 0부터, `pageSize=8`이다. `total`은 필터 적용 후 전체 개수다. 활동은 시작 시각, 비용은 호출 완료 시각 내림차순을 기대한다.
- 현재 제안 DTO의 `Quality.records`와 `Costs.otherCosts`는 배열이다. 현재 화면은 품질 목록을 브라우저에서 나누고 대화 외 비용은 모두 표시한다. 서버 연결 전 두 목록의 페이지 응답을 협의해야 하며, 현재 배열을 확정 계약으로 보지 않는다.
- 활동 집계는 시작 시각 기준, 비용 기간 합계는 호출 완료 시각 기준이다. 비용 상세는 해당 활동의 전체 기간이므로 조회 기간 소계와 다를 수 있다. 페이지 이동이 기간 전체 집계 값을 바꾸면 안 된다.
- 평균 시간은 종료 시각이 확인된 활동의 경과 시간 평균이다. 시작 실패는 평균/시작한 대화 수에서 제외하고 종료 현황에는 별도 표시한다.
- 수락률은 명시적 수락 ÷ (명시적 수락 + 거절)이다. `REQUESTED`, `UNCLEAR`, 빈 값은 분모에서 제외하며 분모가 0이면 `null`이다. 서버와 최종 합의해야 한다.
- 도움 실행 종류 `EXPRESSION_EXAMPLE`과 `FOCUS_HELP.exampleGiven`을 구분한다. 장면의 도움 제안 반응과 실제 실행 기록도 구분한다.

### USD 금액과 사용량의 현재 제안

- 모든 금액 필드는 `estimatedUsd`, `collectedUsd`, `activityUsd`, `failedStartUsd`, `nonActivityUsd`, `unlinkedUsd`로 USD 단위를 명시한다. 원화 환산은 하지 않는다.
- 현재 합성 데이터와 제안 파서는 숫자형 USD를 사용한다. 실제 백엔드 전송 형식은 미확정이다. **USD 소수 문자열을 우선 제안**하며, 마이크로달러 정수와 비교하여 6자리보다 작은 비용의 보존·합산 정밀도·반올림 시점을 함께 정해야 한다. 합의 후 어댑터와 파서를 수정한다.
- 실제 비용의 단가 적용·합산은 서버가 담당하고 프론트는 응답의 금액과 계산 설명을 표시한다. JSON 숫자의 이진 부동소수 오차를 청구 계산의 정밀도 기준으로 삼지 않는다.
- 비용·토큰·평균 등 확인되지 않은 수치는 `null`이다. 0은 확인된 0이다. 캐시 읽기/쓰기는 입력의 세부 항목, 추론은 출력의 세부 항목이므로 다시 합산하지 않는다. 음성은 시간으로 표시한다.
- 수집 상태 `COMPLETE/PARTIAL/UNKNOWN/NOT_COLLECTED`는 화면 표시 DTO다. 서버 내부 상태와 다르면 어댑터에서 명시적으로 매핑한다.
- `NON_ACTIVITY`는 특정 대화와 무관한 호출, `UNLINKED`는 연결을 확인하지 못한 호출이다. 실제 활동 ID가 있는 시드 생성은 해당 활동에 귀속하는 제안이다. 합성 예시는 실제 공급자 청구 내역이나 서버 동작을 증명하지 않는다.

### 세션과 오류

기존 보호자 로그인 세션 쿠키를 브라우저가 same-origin 요청에 전송하며 JS는 쿠키 값을 읽지 않는다. 최초 `/me` 승인 뒤 조회하고, **모든 관리자 엔드포인트에서 서버가 관리자 권한을 검사해야 한다.** 프론트 화면 가드는 서버 인가를 대체하지 않는다.

- 401: 로그인 안내 → `/parent/login`. 로그인 뒤 `/admin`은 수동 재접속한다.
- 403: 접근 권한 없음. 로그인 화면으로 자동 반복 이동하지 않는다.
- 어느 조회에서든 401/403을 받으면 진행 중인 관리자 조회와 기존 데이터를 제거한다. 취소된 이전 요청의 오류가 새 화면을 차단하면 안 된다.
- 공통 오류는 알려진 `code`로 고정 문구를 고른다. 본문 `traceId`를 우선하며 없으면 `X-Trace-Id`를 읽는다. 원시 `message`는 화면에 출력하지 않는다. 모르는 코드·잘못된 JSON이어도 HTTP 상태를 유지한다.
- API 실패·형식 불일치는 오류를 표시한다. 합성 데이터로 자동 대체하지 않는다.
- 기간·조회 조건 변경 시 이전 결과를 제거하고 늦은 응답을 무시한다.

실제 원문 API 연결 전 열람 권한·범위와 감사 기록 정책을 백엔드 작업에서 확정한다. 관리자 등록·권한 수정 UI는 이번 범위가 아니다.

## 구성과 검증

`common/`은 공통 표시·문구·UI·조회 설정을, `features/`는 4개 화면을, `data/`는 교체 가능한 조회 계층을 담당한다. 공통 코드를 먼저 만든 뒤 화면을 분리하며 기능끼리의 직접 참조는 공통 컴포넌트로 옮긴다. 주석과 시험 이름은 한국어로 작성한다.

관리자 전용 TanStack QueryClient는 자동 재시도·포커스 복귀 재조회·재연결 재조회를 끈다. 조회 키에는 모드·미리보기 상태·날짜 기준과 조회 결과에 영향을 주는 필터·페이지·상세 ID를 포함한다.

최초 조회와 오류 후 재시도 중에는 로딩을 표시한다. 정상적인 재조회 중에는 기존 결과를 유지한다.

```text
npm run lint
npm run typecheck
npx vitest run tests/admin tests/lint/eslint-boundary.test.ts --coverage
npm run build
```

확인 항목:

- 시간·달러 경계값과 화면 간 표시 일관성.
- 4개 화면의 날짜 선택, 상세 펼침, 페이지 이동과 로그인 필요·권한 없음 상태.
- 운영 빌드를 실행한 뒤 `MUJOONG_ADMIN_PREVIEW=true`여도 합성 화면이 나오지 않는지.
- 결과 보고에서 합성 데이터 미리보기와 운영 빌드 검증을 구분하고 실제 관리자 API 연결 전임을 명시한다.
- 달러 전환으로 바꾼 시험 기대값과 변경 이유를 보고한다. 원화 필드의 USD 전환, 합성 USD 소계의 부동소수 비교, 표시 경계값 고정이 해당한다.

미리보기 데이터 소스만 가정한 단가로 합성 예시 값을 만든다. 화면에는 별도의 수동 비용 계산기를 두지 않는다. 실제 관리자 인증·DB 조회·비용 합산의 통합 검증은 후속 백엔드 연결 단계에 남아 있다.
