# 무중 비밀 키 형식 — grep -E 패턴, 한 줄에 하나 (U1 3.5 Step 49 · SEC-10 · NFR9.10 · CD-1)
# scripts/verify/a-secrets.sh가 gitleaks가 없을 때(또는 함께) 추적 파일과 무시되지 않은 미추적 파일에 grep한다.
# '#'로 시작하는 줄과 빈 줄은 패턴이 아니다. 이 파일 자신은 스캔 대상에서 뺀다(패턴 문자열이 걸리므로).
# 값의 '모양'만 적는다. 실제 값은 어디에도 쓰지 않는다.
#
# AWS 접근 키 id
(A3T[A-Z0-9]|AKIA|ASIA|AGPA|AIDA|AROA|AIPA|ANPA|ANVA)[A-Z0-9]{16}
# GitHub 토큰(개인 · OAuth · 사용자 · 서버 · 갱신) · 세분 개인 토큰
gh[pousr]_[A-Za-z0-9]{36,}
github_pat_[A-Za-z0-9_]{50,}
# OpenAI류 API 키(sk-, sk-proj- 등). 앞 글자가 단어 문자 · 하이픈이면 키가 아니다(task- 등)
(^|[^A-Za-z0-9_-])sk-[A-Za-z0-9_-]{20,}
# 개인 키 PEM 머리글
-----BEGIN ([A-Z]+ )?PRIVATE KEY-----
-----BEGIN OPENSSH PRIVATE KEY-----
# Slack 토큰
xox[abprs]-[A-Za-z0-9-]{10,}
# Google API 키
AIza[0-9A-Za-z_-]{35}
# 자격 정보가 든 URL(scheme://user:password@host). 자리표시자(${...} · <...>)는 비밀이 아니므로 비밀번호 칸에서 뺀다
[a-z][a-z0-9+.-]*://[^/[:space:]:@"'$<]+:[^/[:space:]@"'$<{}]+@[A-Za-z0-9.-]+
